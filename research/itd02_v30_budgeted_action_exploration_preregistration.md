## Research hypothesis and authorized candidate

Explore if a simple, **fixed, public-count** action-choice mechanism that selects previously untried second actions in a recently encountered (cue,actual-first) public context can uncover the ambiguity at a measured cost, and whether the resulting legal feedback improves **native V22** decision regret over an equally funded conventional alternative.

Only native architecture used: unchanged original eight-cell V22 ring, protected source bank V26, and fast shared V22 learner. The additional action choice is an **external hand-coded exploration policy**, NOT learned exploration, intrinsic motivation, autonomously invented causal state or cognitive self-improvement. It may inspect current cue/actual-first, predictions for its three legal actions, and counts of previously selected public rewards within the 12 new mapping observations. It may NOT inspect the evaluator-only A/B law, unselected reward, preferred_action(), latent regime ID, counterfactual source-vs-target truth, or action-regret report before selecting.

Candidate NOVELTY: for a given (cue,actual-first), choose the second action with the **smallest count of observed selected target-stage feedback within this context**; among tied actions select maximum current V26 active predicted reward, ties by ACTIONS declared order. Counts are **per target-stage public sequence** (zero initialized at cold start, derived from current 12 selected rewards), not from 576 old-source pretraining. The model never receives a stage-switch signal; the external experiment constructor starts this opt-in policy after 12 common public feedback events and discloses that boundary as a **privileged setup assumption**, not native detection.

## Exact frozen experiment and comparator budgets

Use the original V29 `selected_map()` twelve ordered public context/actions and `law(kind,case,mapping)` for the evaluator-only A, B and identical B0 control. Cold-start the same immutable original 576-event source checkpoint for each arm; execute the twelve original selected events in each world identically via the usual public first/second actions, source frozen, fast learned.

For every independently initialized experiment arm, freeze the next three **public cue/first contexts** in order: original `observed[0]`, `observed[4]`, `observed[8]`. No candidate chooses its context or learns a world label. Use budgets **0, 1 and 3** extra legal selected terminal observations; budget1 uses the first context, budget3 all three. The actual selected-second action must be chosen *prospectively* by the policy using only live public model predictions and recorded action counts. Only after choosing does the evaluator deliver actual A/B/B0 reward. These extra events are a new information and resource budget and are never back-propagated into the source-frozen bank.

Mandatory controls, under **exact same 12 base events, frozen context order and extra event budget**:
1. NOVELTY count-first V26 active-score tie-break (main candidate).
2. GREEDY native V26 active-score argmax without novelty, same model updates.
3. Deterministic ROUND-ROBIN action at each probe: `ACTIONS[(index_of_original_selected+1)%3]`. This control has access only to the already observed selected action, not evaluator truth.
4. Fixed-seed uniform RANDOM action, seeded `3001` using a local deterministic generator independent of evaluator kind.
5. Conventional 80-feature full matrix online RLS/CUSUM with its own greedy predictions and a per-context-count novelty version using its **public prediction** score; each extra selected reward gets the same one-step RLS update.
6. Fixed constant zero and running mean prediction baselines for resource/sanity; never call these intelligent exploration.

For native NOVELTY, GREEDY, ROUND-ROBIN, RANDOM, keep independent V26 protected dual model and fast V22 weights, with identical pretrained source and 12 common events. For conventional controls, keep independent RLS instances with same 12 events. No reward-only offline replay, no post-hoc choice from all three second-action rewards. Evaluator must record *prospective chosen action*, its then-predicted selected reward, and actual public returned reward; only afterwards model updates.

All 36 candidate counterfactual rewards are **evaluator-only after policy freeze**, never used for selecting/training any probe. Cross-host canonical full case+choice+regret SHA on Windows 2022 and Ubuntu 24.04 must agree, with resource wall/memory excluded from digest.
