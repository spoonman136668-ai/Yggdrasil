## Arms and implementation details

All arms have the same C1B **32-unit** 2-layer nonlinear factorized categorical neural model, same 3-block input dimensions, class vocabulary and target, Adam `0.02`, 24 epochs, minibatch 64, init seed **17 for Pycolab and 31 for MiniGrid** (previously selected on historical TRAIN-only development; never DEV), L2=.0001 and same original bounded updates. Common base learned weights count equal across arms; learned gate adds **2 scalar logits** to the base weight count and must report its full cost, not falsely claim equal parameter count or resource parity.

- `history_masked`: two previous public feature blocks fixed to zero for FIT, SELECT and DEV.
- `history_visible`: both history blocks fixed full-scale 1 for FIT, SELECT and DEV.
- `trained_history_shrink`: conventional fixed half-scale both history blocks (0.5) for FIT, SELECT and DEV, same weights/epochs. This is a fixed, strong shrinkage control, not a learned gate.
- `learned_two_gate` (candidate): two logistic-sigmoid trainable scaling logits, one per previous public frame/action block, initial gate **0.5**. Learn on FIT gradients ONLY, with gate penalty **0.002** per gate; update gate logits with independent Adam lr **0.005** and same batch chronology. Gate gradient is exact chain rule through the tanh predictor to the already-learned network input, plus analytic penalty `0.002 * gate*(1-gate)`. Gate logits clipped to [-8,8] each update solely for numerical safety. No teacher, hidden source, oracle error, policy-based labels or DEV selection. These two gates are globally learned source-local scalars, not task-specific dynamic attention or native memory.
