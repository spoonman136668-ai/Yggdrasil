## Research question and only candidate

Can an **external public-reward novelty detector** let the existing original V22 FAST local learning influence current action choices while retaining protected original SOURCE and returning safely to it after an actual source-world reappearance? This is an engineered public-only selector, **not** a native-distributed learned gate or native self-improvement. No native original weight update/feature, V24/V25/V26 controller, source bank or V30 exploration policy may be modified.

V32A fixed state (source initially active, FAST probation allowed):
- For each **actually selected terminal reward**, calculate SOURCE pre-feedback absolute prediction residual `es=abs(y-source_score(selected))` and FAST pre-feedback residual `ef=abs(y-fast_score(selected))`, both from existing protected V26 bank; **do not** use unselected outcome, world ID, stage tag, elapsed segment count or hidden first-action labels.
- If current policy SOURCE: switch to FAST after the reward iff `es >= 1.50`. This is called **source surprise probation**, not evidence that FAST has lower loss. No minimum time or automatic release.
- If current policy FAST: increment a consecutive slow-support counter when `es + 0.20 <= ef`, else reset it to zero. Return to SOURCE when counter reaches **2**, then reset counter. The source stays protected and unchanged; FAST remains trainable on all legally observed rewards.
- Evidence flag is external hand-coded scalar selector metadata; it never copies weights, invents extra learned parameters, invokes privileged full-world head, sees alternate unselected rewards or relabels a reward family. It may select only one existing original protected SOURCE or original FAST readout after the feedback; original V26 internal selector still updates independently but is not the V32 active policy.
- Original native 8 cells, 163 learnable scalars per ring / 326 total stored, four neighbor transport hops and checkpoint max **12,288 bytes including selector metadata** remain absolute safety guards. Cross-host restorable canonical full checkpoint with digest and fail-closed corruption is mandatory.
