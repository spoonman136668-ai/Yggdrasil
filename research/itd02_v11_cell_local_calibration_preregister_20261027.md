## Structural hypothesis

The original eight-cell `LocalTaskRuntime.observe` updates all eight local roles and all shared expert weights from all eight genuinely observed public outcome bits. Keep it **byte-for-byte unchanged**, including eight targets, K=3 experts, D=7 neighbor features, eight cell roles and original ring. Add one independent *learned residual calibration scalar* for **each of eight cells**, so that individual cells can adjust their output probability without demanding additional shared-genome updates. No explicit public observation/action key table, no global oracle, no new communication edge and no learned preassigned answer.

Each cell i starts with scalar residual `r[i]=0` bounded in [-2,2]. On a real public selected action/consequence, before original native fitting, compute original native predictions `p[i]` from the original legal pre-feedback public input (8 local binaries); cell-local calibrated probability `q[i]=sigmoid(logit(clamp(p[i],1e-6,1-1e-6))+r[i])`, with the exact original p[i] returned when r[i]==0. Then execute original full8 native.observe and original ring-memory feedback with **all eight bits**. Only after legally accepted learning, each cell independently updates `r[i] ← clip(r[i]+0.05*(public_outcome_bit[i]-q[i]),-2,2)`. No masked targets, no source-private data. The existing original native score readout uses these calibrated predictions on the same original local public two-phase inputs, leaving all original native/shared learning updates and score fusion unchanged. Exactly 8 trainable scalars are added, not 15/48 per-context lookup entries. Preserve fit/frozen separation; checkpoint v11 (not backward-compatible with v8), hash and restore all 8 residuals, no pending-replay. An identical zero-initialized system must make exactly the original v8 decisions before feedback.

## Frozen 5-arm acting comparison (new disjoint synthetic families)

Predeclared 6 families IDs **260–265**, six permutations of `(TurnAround, GoForward, Backup)` in original action-order lexicographic permutation enumeration, new source-only seeds **1237 and 1277**. 12 trials/arm, three phases of **48 genuinely chosen action/public feedback events each**:
1. initial familiar public LRV/MRV: optimal actions first two permutation members a,b;
2. unfamiliar docked_LRV/docked_MRV: optimal b,c;
3. reversal LRV/MRV: optimal c,a.
Every phase alternates its public labels by `(step+seed)%2`. Environment-only hidden optimal mapping returns **+10 or -3 for the action actually chosen**, and public next observation `Nothing`. No ideal target, phase mapping, seed law, or unchosen reward is accessible to any learning actor. Native v8 and v11 choose entirely through their existing `choose()`, learning from their own 144 feedback events per trial. Other independently acting arms: public context/action count mean, EMA(alpha 0.5), and last-six rolling mean, each with predeclared source-blind cyclic exploration of first three visits and one source-blind probe every ninth visit; every probe earns actual feedback. No cross-arm training.
