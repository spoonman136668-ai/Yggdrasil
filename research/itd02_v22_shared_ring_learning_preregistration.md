## Frozen separate opt-in candidate design
- Use original fixed **eight-cell ring**, original cue site and actual first-action site, exactly the original V18 `forward_local` source-only delivery of seven named public channels at **4 hops**, original fixed receiving gains 0.92. Each cell independently constructs its **own local 20-feature readout** [1, 7 delivered channels, 12 local cue x local action products]; **never** provide a global first/second/cue tuple to a model or import the toy reward law. No direct source encoding at a selected reward output.
- Each of eight cells stores exactly **20 bounded learned weights**; three original second-action sites have **one local selected-action bias each**. Total **8x20+3 = 163 trainable scalars**. A cell emits exactly one learned scalar, its local feature dot-product, and forwards it by four synchronous rounds of **(own+left+right)/3** via the original ring edges. A selected action head reads only its final incoming scalar and its own learned bias.
- Public terminal reward arrives at the **actually selected second action** only. Error credit is propagated backward four original ring edges using the same symmetric local averaging, originating only from that selected head. Each cell updates only its **own 20 weights** from local public signals and locally delivered credit, one normalized supervised update `eta=1.0`, `denominator=1+sum_i(local_credit_i^2 * local_feature_i^2)+1` including selected bias gradient. The selected action bias alone changes. Other action biases NEVER update, but experience can improve them indirectly through *shared learned cell state*.
- **Matched 163-scalar no-sharing control:** same exact eight cells, 20 weights per cell, seven channels, same four-hop input transport, identical output message propagation and selected bias count; before each selected action readout, fixed source-side cell ownership `cell_index % 3 == selected_action_index` restricts which learned cells' final scalar contributions that action may use, normalized over that set, so **no learned cell weight ever receives reward from >1 second-action type**. This is a deliberately hand-designed source-only negative sharing control, not a deployable comparator. The all-cell shared candidate has no such partition. Report that readout routing differs, despite matched learned scalar count and public feedback. No action-weight copying, central pooling, shared update oracle or full-history dictionary.
- Use bounded finite weights [-16,16], same V18 public second-step reward domain [-5,10], strict 2-step public transition, immutable original model identity, max 8192-byte SHA-256 checkpoint, exact cold restore and frozen evaluation.
