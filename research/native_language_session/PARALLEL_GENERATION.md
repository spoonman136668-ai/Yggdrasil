# Parallel native response-byte generation component

The generator predicts output length and byte bits from the complete input.
Every field sees the same input. Generated bytes never feed another field.
Host evaluation is serial; "parallel" describes conditioning independence,
not an observed speed advantage.

Each variable bit uses the project's existing native text learner with generic
0/1 labels. Constant fields retain the empirical value shared by all examples.
Length is an empirical constant or native classifier over observed lengths.
At least one bit field must be native-trained. The full response strings are
discarded after training; only their SHA256 digests remain for reporting whether
an observed candidate occurred in training. Those digests never select output.

This is a bounded generation readout component. It does not establish language
understanding, useful learned novelty, compositional transfer, general dialogue,
LLM-class capability, efficiency, genome compression or functional regeneration.
No external inference model, grammar template, conventional replacement brain,
response-bank repair, or autoregressive next-token objective is added.

Limits: 2–8 complete examples; 1–128 UTF-8 bytes/input, <=512 training-input bytes
total; 1–16 UTF-8 bytes/response; <=128 bit fields plus a length field; <=1 MiB
checkpoint/request. Training is from scratch. Generation is read-only. Padding
is zero only for supervised output fields; learned length controls emission.

JSONL operations:
- `{"op":"train","examples":[{"input":"aaaa","response":"aA"},{"input":"zzzz","response":"bB"}]}`
- `{"op":"generate","input":"aaaa"}`
- `{"op":"checkpoint"}`
- `{"op":"restore","checkpoint":<returned object>}` in an empty process.

The result includes the generated candidate's raw hex, length, UTF-8 status,
native field scores, and `seen_training_response`. Invalid generated bytes are
preserved with `valid_output:false`, `response:null` and no replacement text.
CLI `ok:false` marks invalid candidates. `language_proof:false` always remains.
Digest absence is byte-sequence novelty only; it does not establish correctness,
meaning or genuine unfamiliar transfer.

Complete checkpoints retain every native field model, constants, source and
encoding/schema pins, training digest and response digests. They carry integrity
checks, not authenticated training provenance or scientific authority.

Engineering tests use invented inputs. They check training-pair fit, variable
length/UTF-8, complete state and new-process parity, read-only inference,
bounds/corruption/foreign-source rejection and invalid-candidate preservation.
A forced bit intervention tests mechanical assembly of an absent response only:
it is explicitly NOT learned novelty or a transfer experiment.

Required qualification still includes focused/affected-interface tests, the
complete final regression, build, source identity and regenerated source-index
validation. Wingless's known-stale index is checked before expensive full race
regression; a preparation run that fails it is not qualification. The final
qualified source must execute and pass the full suite with no exclusions.

Original scientific negatives, frozen cohorts and thresholds are unchanged.
Before a language proof, freeze legitimate real-language development tasks,
equally informed trained controls, no-state/untrained/shuffled-label comparisons,
genuine unfamiliar holdout, paired retention and all-in cost accounting. No new
controller, queue, scheduler, runtime installation, protected-main promotion or
FORGE takeover is included.

Yggdrasil source: original R7 local cells via immutable text-selector blob
`fd53e676118b48baa16ef31cd2e306ecd29f4015`. Original local plasticity,
consolidation and bounded-neighbor dynamics supply all variable-field scores.
Native banks grow with output width; at the stated limit there can be 264
original colony models (2,112 local cells). This does not establish compact
inheritance, useful specialization or developmental regeneration. The established
DG-1 genome/phenotype lineage remains intact and is not replaced by this readout.
