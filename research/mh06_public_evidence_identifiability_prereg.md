## Identifiability result to check, not a new scientific trial
Given two equally likely hidden regimes with identical public cue/action transcript and **no public reward or other discriminating observation after the return**, any no-oracle memory-bank selector receives the same information in either regime. Under a paired counterfactual comparison its expected correct-regime selection probability is **exactly 1/2** (or at most the larger regime prior for unequal priors). An old bank's evaluator-only accuracy does not itself provide a regime cue to the live learner. Source publicly emits only cue, action and **subsequent** reward; no phase label. Claiming zero-feedback return recognition from those inputs is mathematically unidentifiable. No new MH-04 F/G or MH-05 H/I evaluation and no external original first use.

## Engineering-only shadow probe and fixed guards
1. Introduce a pure, external read-only `MH06PublicEvidenceGate` that consumes a public cue and optionally its subsequently observed action/reward, plus two *local bank forecast values*, with no hidden target law, regime label, source-owner oracle or checkpoint mutation. It starts abstained, never chooses on cue alone, and cannot condition an action on the reward that has not occurred.
2. For development unit fixtures only, map signed bounded bank score `s` to a Bernoulli reward likelihood `p=clip((clamp(s,-1,1)+1)/2, 0.05, 0.95)`. Accumulate log likelihood ratio of actual public signed reward using score forecasts from each bank; require **at least 2 distinct cue-action witnesses** and absolute accumulated log-odds **>=ln(19)** to nominate a bank. These are engineering constants, not tuned on source outcomes, and are **not** claimed to be calibrated real V32E probabilities.
3. Reject invalid cue/action/reward, non-finite score, duplicate feedback, out-of-order observation, missing cue, injected oracle regime, malformed inputs. If both banks agree or public evidence is balanced, retain abstention; no fallback truth-label leak. The only test examples use fixed hand-assigned numeric forecasts, not any generating reward world, trial seed or historical outcome trace.
4. Test the exact 50% paired no-reward identifiability result on fixed public transcripts, including arbitrary cue-only choices and unbiased randomized choices (analytically averaged, no RNG). Test post-feedback distinguishing evidence, abstention under ambiguous evidence and fail-closed negative inputs. Verify original source blob unchanged. **No new model training, reward generation, live source action, novel scientific trial, checkpoint rewrite, native bank switching or evaluation of old MH-05 cohorts.**
5. Source-first branch-local hosted GitHub qualification: generate G29 index in an isolated derived-only child, then on exact final SHA run focused MH-06 tests and the mandatory complete root test suite and G29 provenance on Ubuntu/Windows, with four pre-existing Windows POSIX skips permitted.
