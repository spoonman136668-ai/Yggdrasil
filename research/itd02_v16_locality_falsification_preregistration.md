## Locked hypothesis and decision
V15's source-public three-phase port fan-out and 64-slot action-head tables fit observed toy contexts but do **not** demonstrate local communication-mediated *learned* transfer. Its three-input public tuple is converted by a global deterministic index; each selected action head updates one table slot, while the original native genome and ring memory remain frozen.

Predeclared diagnostic: run **36 leave-one-public-history-out** mechanical tests. For each legal public history (4 cues x 3 actual first actions x 3 actual second actions), build a fresh V15 adapter. Train **one pass** on the other 35 distinct toy histories only through `start_observation -> actual accept_public_transition`. Train/test use exclusively the V15 preregistered public-only synthetic reward fixture, `REWARDS[(cue_index + first_action_index + second_action_index) % 3]` (NOT the original world); do not fit on the held-out tuple. Evaluate the held-out second-action reward using **only** `local_scores()[selected_action]`, excluding the original frozen native model's unrelated fixed contribution. Require matched original native identity, learned-head budget and cold checkpoint.

Prediction: all 36 held-out local scores remain exactly **zero** since the one-to-one neighbor code routes each unseen tuple to an unvisited table slot. The 24 heldouts with nonzero toy rewards therefore get **zero transferred reward estimate**, despite the other 35 contexts having supplied learning feedback. Mean held-out reward error is diagnostic, not an independently sourced scientific metric. Negative controls: audit every site has 36 distinct local neighbor words, distinguish chosen-action identity, ensure no other head/slot receives credit, and show that the local-only readout is invariant under perturbations to native ring internal trace or memory state that are *not inputs* to `local_scores`. Verify local words change when one of six neighbor bits changes and stay unchanged when non-neighbor port bits change. This establishes the source-local lookup behavior, not a general theorem about future architectures.
