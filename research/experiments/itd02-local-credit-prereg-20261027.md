# ITD-02 online per-action local credit (prospective 2026-10-27)

Only source-free development. Frozen reference is the isolated action-conditioned v5 experimental source acba63a352b90035bb9ee264df89c00358aa4a3b; original draft PR #582 a39171a76d0d7817e3563682bb139a9d7ecf37c4, parent #574 unchanged. No FSA, original-world tasks, controllers, or promotion.

**One new mechanism:** each of three legal actions maintains one scalar action-specific locally earned residual, trained ONLY on its own actual chosen public consequence. Each residual is stored at the corresponding one of three original action sites (0,2,5), bounded [-13,+13]. On feedback to action a at reward r, compute pre-outcome native prediction q(a) using current public observation and unchanged source-local traces; update ONLY the selected action's local credit as `credit[a] = clamp(.75*credit[a] + .25*clip(r-q(a),-13,13),-13,13)`. For decision, add `0.15*credit[a]` only to that action's native value. No knowledge of unchosen-action outcomes, no privileged source state, no extra cell connectivity, no original core genome modifications; native model still genuinely observes one legal actual public outcome. This is a minimalist action-local residual baseline, not compositional long-memory proof. New bridge checkpoint v6 includes exactly three bounded credits, rejects v5, seals/retains state across cold process and blocks frozen training. No hidden online labeled oracle.

**Necessary engineering controls:** changing one action's consequence updates only that action's credit; all three can diverge; identical present observation with different learned credit history produces different *relative action values*; frozen/no-learn mode leaves credit unchanged; atomic rollback and cold-process v6 restoration; original topology and memory parameters fixed.

**Precommitted matched learning:** entirely fresh public-only hidden evaluator fixtures families 110..117, seeds 108..115, 64 matched trials × 90 initial + 90 unfamiliar, public rewards -3/0/+10, source-blind exploration and genuine chosen-action credit only, frozen v5 versus candidate v6, independently acting conventional count-mean/EMA(0.5)/rolling-six. 46,080 public feedback steps per source per OS, Ubuntu/Windows exact-source pinned, original non-Atlas suites + v6 tests. Fail promotion if initial OR unfamiliar native mean not improved, native behind conventional baselines, resource/cold restore, G29, retail hardware, FSA owner-world not accepted. No retuning these families.
