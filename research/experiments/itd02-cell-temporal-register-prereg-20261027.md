**One bounded native-cell memory hypothesis:** preserve the original eight-cell LocalTaskRuntime, all its trainable genome parameters and neighbor topology. Add exactly **eight nonlearnable bounded per-cell temporal registers** to the opt-in bridge, initialized to zero. Once per *accepted learning* public transition, each cell updates its own register to `0.75*previous + 0.25*(2*public_input_bit-1)`, using only its current binary public bit. No reward rule, other cell register, hidden world source or global controller may enter the update. Registers persist across successive actual public transitions, are bounded to [-1,1] and must be checkpointed with a v4 schema, v2/v3 restore denied. For native action evaluation, use the original two-phase local predictor outputs and a **fixed bounded 0.10 contribution from the local prior register at the reward output site**, with original score coefficients (-3,0,+10). This allows previous public experience to affect future action ranking without copying or learning hidden state. Do not claim this is learned recurrent internal cognition; it is a deterministic local state baseline. If the prior register at a reward site cannot carry useful information because the two-phase input keeps that site zero, the test must report this failure.

**Engineering qualification:** assert no extra trainable parameters, neighbor-only input, one register update per accepted learning transition, frozen evaluation no state mutation, original atomic rollback safety, state identity and cold-process checkpoint restoration, strict v4 schema, original non-Atlas tests, same 8 native cells, resource accounting.
