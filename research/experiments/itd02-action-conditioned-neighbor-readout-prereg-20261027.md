# ITD-02 native-cell retained history × candidate action readout (preregistered 2026-10-27)

Frozen source original PR #582 a39171a76d0d7817e3563682bb139a9d7ecf37c4, parent PR #574, unchanged. Development source v5 c4d7ed610eccb4c4745050e78990b9089f6d4792. Source-free synthetic tests only.

**One falsifiable mechanism:** v5 retains eight locally trained (deterministic, not parameter-learned) neighbor-conditioned register scalars. Replace the action-independent scalar readout by a strictly two-neighbor *action-conditioned register/readout*: for each hypothetical public action encode its phase-0 binary input using existing source-legal _temporal_public_bits; at each original reward site, use only the two immediate neighbor traces at those locations and the two current candidate-specific input bits. Score the candidate native action with `0.10 * sum(reward_weight[site] * (trace[left]*(2*candidate_bit[left]-1) + trace[right]*(2*candidate_bit[right]-1))/2)`. No full-ring/global vector features inside a reward head; each reward site accesses its own original neighbor indices only; no new trainable parameters or public data. No changes to original native observe, ring adjacency, checkpoints v5, 8 bounded temporal traces, trained model or independent public feedback count.

**Pre-test necessary structural check:** after training a frozen native source-free sequence, two different legal candidate actions must produce different local trace addenda for some same public observation, and at least one legal pair of histories with an otherwise identical immediate public observation must produce different *relative action scores* (not just a common offset). Verify same original local context, finite bounded scores, source-only memory and frozen evaluation; do not make source reward law available to candidate score.

**Precommitted efficacy test:** New synthetic evaluator-private task families 102..109, seeds 100..107; 64 paired public family/seed trials with 90 initial and 90 unfamiliar/reward-shift episodes. Original v5 vs isolated action-conditioned readout, with independently acting conventional full-history, EMA(0.5), rolling six. Four jobs × source Windows/Linux, 46,080 selected public feedback events/source/OS, −3/0/+10, matched source-blind exploration, true fresh interpreter restore, raw trial retention. Reject if either phase mean original-native reward fails to improve, if no genuine action-specific effect, if original tests fail or if native is not sufficiently competitive with conventional controls. Exact G29, genuine original owner/FSA science and retail Windows resource tests remain blocked. No merge or coefficient tuning on this heldout split.
