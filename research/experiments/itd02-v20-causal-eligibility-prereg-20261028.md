# ITD-02 V20 — preregister causal eligibility before algorithm changes (2026-10-28)

**Frozen source:** V19 draft PR #603 exact fb3dc5b2f563081a802267e8e7c39f52ccb6f3a3; its V18 parent PR #601 exact 46097b7fd03e40ceec6b74918430b7f6c11cc53e. Branch is isolated research only; no existing protected ref or original model mutation, FORGE/CKB-plane control or paid model API.

**Problem grounded in V19:** 72/72 first exposures have exactly zero selected-head causal gradient with respect to the 56 intermediate gains; original V18 nevertheless performs 1,104 initial gain updates. After fitting, 825 updates occur at flat causal sensitivity and 191 oppose local loss descent. This does not imply that suppressing these updates must improve heldout tasks.

**One falsifiable candidate:** retain original V18 eight-cell neighbor topology, seven public tag channels, four-hop delivery, learned output heads and scalar budgets exactly (56 intermediate gains + 60 selected local reward-head scalars = 116). Replace only receiving-cell gain update rule: use source-public selected-action reward error multiplied by a locally transported, independently checked causal eligibility derivative to the selected output head; if derivative is zero, intermediate gain must not change. Do not use source world law, unchosen action labels, global context lookups or a central learned answer oracle. Record how this derivative is computed using only permitted original-ring messages; a centrally calculated finite difference is an evaluation witness, NOT an admissible training rule. Establish an explicit cold-start mechanism because zero initial head weights imply zero causal eligibility; treat permanently frozen early gains as failure, not success.

**Mandatory preliminary structural proof BEFORE heldout:** source-frozen V18 and prospective candidate produce identical initial selected-head outputs; all 72 first-exposure zero-gradient cases yield exactly zero intermediate gain writes; after selected-head training and nonzero local eligibility, update direction decreases independently measured local selected-head loss, including tests at multiple scales. Check failure modes for unselected-head updates, information leakage, zero-gradient stagnation, illegitimate source data, non-neighbor transport, corrupted checkpoint, NaN inputs, and original native source modifications.

**Matched evaluation:** use a fresh, locked synthetic world set that has not appeared in V12–V19, split initial learning, retention and genuinely unfamiliar-family transfer, plus non-additive compositional controls that are not trivially linear. Compare (A) exact V18, (B) V18 frozen-intermediate, (C) V20 causal-eligibility candidate, (D) equivalent-data strong conventional public-only interaction/recency learners, separately acting when action performance is measured. Matched observed information, training steps, source-blind actor policy or explicitly measured on-policy differences, CPU, peak RSS, checkpoint bytes, native message counts, true selected reward and uncertainty. Source-only engineering qualification on Linux and Windows. Claim no benefit unless V20 has material improvement over both V18 and frozen intermediate, and remains competitive with conventional controls. G29, FSA first-use, owner-world transfer and retail-device acceptance remain separate.

**Current state:** preregistration only; no V20 algorithm implementation, CI outcome, performance result, acceptance or promotion yet.
