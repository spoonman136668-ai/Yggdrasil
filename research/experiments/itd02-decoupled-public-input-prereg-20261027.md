# ITD-02 joint-public-code / independent native reward sites — preregistered research candidate (2026-10-27)

Status: **source-free dev-only hypothesis**. No protected external science, FSA admission, new controller or merge. Frozen original: Yggdrasil PR #582 `a39171a76d0d7817e3563682bb139a9d7ecf37c4` (draft), parent #574 remains unchanged.

## Causal motivation and exactly one intervention
Unmodified original native action-conditioned public input represents one observation bit at one of five OBS_SITES `(1,3,4,6,7)` plus one action bit at the three original reward output sites `(0,2,5)`. Reward targets are at those exact same action sites, and original readout weights them `(-3,0,10)`. Frozen-source Windows/Linux diagnostic [#40588085228](https://github.com/spoonman136668-ai/Yggdrasil/actions/runs/40588085228) shows a trained same-site action/reward shortcut.

**Candidate:** Encode all 5 observations × 3 public actions as 15 distinct, deterministic **two-/three-hot codes confined solely to the original five observation-input sites**, never setting the three reward-output sites for native *inputs*. The map, fixed before any experiments: `Backup` = first 5 lexicographic 2-of-5 patterns, `GoForward` = first 5 lexicographic 3-of-5 patterns, `TurnAround` = last 5 lexicographic 3-of-5 patterns. Observation index within each action bucket selects its corresponding pattern. Every one of 15 joint codes must be unique; no oracle/reward mapping in encoding. The original `LocalTaskRuntime`, native eight-cell neighbor topology, 5 observation/3 action public enum, 8 retained gates + 9 action-head weights and native reward-target site labels are unchanged. Target `public_outcome` still uses successor observation and exactly one of the original three reward-label target sites. Memory ring public observations unchanged; no transformer/tokens/extra cells or paid API.

**Custody:** This changes native input **semantics** despite leaving size unchanged. Candidate `NativeTaskRingBridgeDev.SCHEMA` must increase from `source_only.v2` to **`source_only.v3`**. Reject restoration of previous v2 checkpoints rather than silently reinterpreting historical training. Pass original expected checkpoint tamper, frozen training veto and crash-checkpoint tests. Candidate can be a separate draft only, never an in-place migration of owner data.

**Prediction/cost:** Direct action-input bit to the reward site is exactly zero for all 15 codes, but neighbor features now carry the joint observation×action code and may be less individually discriminative. There are no added trainable coefficients or native predictor messages. For any target output site, only its neighbor two binary inputs are available; 15 global codes does **not** imply every local site can distinguish all 15 contexts. Therefore a performance loss is plausible and must be reported.

## Locked fair on-policy test

Prospective *previously unvisited* synthetic evaluator-private families **62..69**, seeds **60..67**: 8×8=64 matched native and conventional trials per implementation, stages 90 initial contexts + 90 unfamiliar contexts/reward law change, four independently acting learners (native and 3 conventional controls: full history selected-action reward mean, EMA 0.5, rolling-six). Rotate source-blind exploration at the first 3 observation visits and every ninth thereafter with all three actions. Reward convention is **three category**: +10 for private optimal action, 0 for one deterministic nonoptimal action, −3 for the remaining action. Every on-policy candidate consumes only its actually chosen public reward and successor. Per source/OS exactly 64×180×4 = **46,080 public action/reward events**. Run original v2 and candidate v3 with SHA-pinned checkouts on Ubuntu and Windows. Keep original-v2 source code/Atlas unchanged.

Frozen test after phase one in a truly new interpreter, byte/identity/transition proof, all original applicable non-Atlas tests and specific 15-code/safe-schema tests. Record native actual training reward both phases, last24, frozen unseen context reward, action balance, native prequential predicted scores, per-run CPU, peak checkpoint bytes, exact public message and trainable capacity. Full trial-level signed evidence; beware different process clock/RSS from hosted runners. The conventional control independently selects its own actions and receives the same task law/clock budgets, not replay-only.

**Precommitted verdict:** reject if candidate loses mean initial **or** mean unfamiliar selected-action reward against original, if it trails conventional learners without a meaningful margin improvement, if original tests/custody fail, or if its additional resource costs are unacceptable. A pure source-decoupling/bit-map structural pass does not justify promotion.
