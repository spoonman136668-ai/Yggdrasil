## Scientific question, scope and falsifier
Can a model with access to natural previous PUBLIC observation/action history achieve a **prospective** improvement in predicting authentic next PUBLIC observations over an adequately trained **complete-current-PUBLIC-only** comparator using the same original source exposure and proper loss on entirely new reset clusters? An advantage is evidence of predictive value of past public history under this sampling protocol, **not** proof of causal identifiability, 45-weight self-organization, genuine physical cell messaging, unfamiliar-family transfer, or lesion recovery.

## Required public data interface and prospective target
For every original source step record the FULL unaltered current-public source array `O[t]`, announced public native action `a[t]`, true NEXT complete public `O[t+1]` after action and public history (past observations/actions only), all source/episode boundaries. Preserve full Farama uint8 `7x7x3` and masked Pycolab uint8 `10x7` in their own native ordering and byte representation; they must not be treated as a common latent semantic embedding. Match exact raw full current PUBLIC bytes and action for alias diagnostics (not 23-number feature matches).

**Proper target:** original-next-public byte value at each of the respective 147 or 70 public byte positions, one of 256 integer categories. Models must output normalized probabilistic `p(value | past-public, current-public, action)` per position. Primary loss is averaged per-position categorical negative log probability (nats/public byte), averaged per episode and then equally across independent reset clusters, with probability floor `1e-12`. This is a proper score for **per-byte marginals**, NOT full joint-frame likelihood; retain exact observed next-frame/action digests as custody. Unlike S4C1 eight any-change bits, categorical true next value differentiates e.g. door `2 -> 0` from `2 -> 1`. Do NOT convert full-public frames to S4C1's lossy eight change bits or use post-result source-label adapters.

This target greatly enlarges output/readout capacity relative to the original 45-weight/eight-state candidate. **Before training, verify that each model and its full 256-category-per-byte decoder is feasible and account for ALL readout parameters/compute. If a 45-coefficient Ygg candidate cannot implement this output at the frozen capacity/resource limit, its architectural superiority arm is BLOCKED rather than adding an unaccounted decoder.** The conventional history-opportunity experiment may still be evaluated as a separate question if preregistered comparisons are themselves complete and correctly qualified.
