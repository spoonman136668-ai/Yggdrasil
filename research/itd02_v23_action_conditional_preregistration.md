# ITD-02 V23 — locked action-conditional native-learning falsification protocol

Immutable parent: Yggdrasil draft PR #606 source c17567365db1c0e401843c3151d375361af15806. Preserve candidate and all protected originals. No FORGE/controller/steering integration.

**Rationale:** V22's original synthetic leave-one-history-out neighbor-sharing error is lower than matched partition and V20, but 35-observation conventional pooled public-interaction ridge is nearly exact. Four hops on eight cells give effectively global communication. Additionally V22 is a reward regression on externally assigned contexts, not acting source-native online learning. A new training procedure must not count the same heldout contexts as independent evidence.

**Independent preregistered gate:** Lock fresh families unavailable in V17–V22, with new nonlinear action-dependent reward mechanisms and test-time changes. Use genuine chosen public actions, exact source-legal feedback only for each learner's selected action, and actor-separated training for V22, V22 equal-163-scalar partition, frozen V20, and strong conventional online interaction/EMA controls. Equalize visible public input stream and *report* differences in per-policy action feedback; optional fixed-policy paired replay may enforce equal feedback but must be clearly distinguished from acting. Require blinded changed-family transfer, retention/return to original family, multiple initial seeds and full CPU / peak RSS / checkpoint / forward and backward message counts. Fix metrics and promotion threshold *before* source changes. Audit original native model identity, no hidden target oracle in actor, cold checkpoint, selected-only reward updates, public validation, and Linux/Windows qualification.

**No-go rule:** No promotion unless V22 achieves material reward and retention improvement against both its partition ablation and conventional controls in *independently acting* new families, without prohibitive retail-PC cost. Synthetic comparison alone cannot establish first-use, G29, retail science or native autonomous self-improvement. Negative outcomes remain preserved. Next model code only after exact action/observation interface and evaluator-custody check.
