## Frozen task, data boundaries, algorithm and controls

Eight separately `Box` allocated native Rust `Cell` states; original ring `RING[i]=[(i-1)%8,(i+1)%8]`, original four known public cues (`LRV`, `MRV`, `docked_LRV`, `docked_MRV`), original physical sites **1,3,7,4**, original three actions at native sites **0,2,5**, four synchronous neighbor-only hops. Each cell owns a **private persistent 3×4 float plastic matrix**, its original identity, two direct original neighbor indices, local 4-channel cue state/next-hop buffer, local scalar reward/next-hop buffer and temporary score buffer, no source answer labels or global learned weight matrix. On each observation the cue pulse enters ONLY its original physical input site and propagates four hops at original **0.92** attenuation, reading only previous-hop original two neighbors. To score each candidate action, each cell forms its local scalar from **its own** four cue activations and **its own** weights for that action; a four-hop original-neighbor-only scalar diffusion delivers that action score to **its original action site**, where the score is read, without reading other cells' private weights directly. The native executable exposes three public scores, not true answer, no background source labels. On public action+feedback, a signed scalar reward pulse enters ONLY the chosen action's original site; it propagates through four original neighbor-only hops and only each cell's own locally present cue activation and locally received reward credit updates its own selected-action weights. Rate **0.20**, no learned global oracle, bounded weights ±8. Repeat discrete steps; no tokens, transformer, backpropagation across cells, unseen reward leaks, or original learner edits. Full update rule and exact transport schedule fixed in Rust source and must not be revised after score observation.

**Synthetic public contextual bandit (known-public first engineering benchmark, not novel-world transfer):** four balanced observed cues, three available public actions, independently computed reward +1 iff action matches hidden-to-Rust cue-dependent mapping **(0,1,2,1)**, else -1. The mapping exists ONLY in the Python experimental environment; Rust library may accept ONLY cue index, candidate action, selected action and a signed scalar reward, NEVER the correct action or mapping. Each of 5 fixed training schedules permutes the order of all **12 cue/action pairs, 20 repeats each = 240 original online exposures**, using deterministic local seeded shuffle before training; rewards delivered to all arms after choosing the fixed scheduled action, so every arm receives exactly the SAME 240 inputs, action and public reward, not on-policy differing observations. Evaluation is frozen 4 cues×24 balanced = **96 reward-BLIND prediction-only** opportunities; no feedback/updating during evaluation; frozen weights/counters and checkpoint bytes identical before/after. Evaluable policy is argmax of its three action scores. Distinct 5 fixed deterministic schedules seeds `(11,23,37,51,79)`, identical on Linux/Windows. Before training and after training, measure accuracy and exact score snapshots. No private user data or Q1–Q3 first use.
