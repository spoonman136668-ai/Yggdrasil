## Candidate constraints
- Exactly original ring of 8 cells, neighbors only i-1/i+1; source-public cue pulse injected only at original corresponding observation cell and actual first-selected action pulse only at original corresponding action cell. Seven fixed public tag channels, no global encoded cue/first/second tuple, no direct cue broadcast to output heads, no source-law import.
- Four synchronous edge-only forward hops, with 8x7 **trainable receiving-cell relay gains** initially 0.92, clipped to [0.25,1.50]. Each cell receives only its immediate neighbors at each hop; its final channel signal may reach every site after four hops (effectively global reach). Do not claim learned routing as opposed to locally learned gain modulation.
- Each second-action reward head reads ONLY 7 messages delivered to its original action site, plus bias and 4x3 local cue/action products. 3 x (1+7+12) = **60 trainable head scalars**, plus **56 plastic relay gains** = **116** learned scalars total. Reward updates only the actually selected second-action head, using bounded normalized local error, no source-law answer table. Reward-error feedback is locally retransmitted from that selected action site along original ring edges for four synchronous hops; each intermediate cell updates only its own relay gains from locally delivered credit and locally present cue/action signal. Crediting from globally broadcast reward without physical hops or learning the original native genome fails this contract.
- Strict two-step actual-action history, only public cue/action/reward, no hidden evaluator fields, frozen original native genome/memory, bounded finite weights and checksum checkpoint <= 8192 bytes; restore and continued learning byte-compatible, frozen inference immutable. Diagnostic no-transport and frozen-intermediate controls are separate.

## Frozen toy families and test protocol
Exactly 36 legal (4 public cues x 3 actual first actions x 3 selected second actions). For **36 leave-one-history-out folds**, each arm trains 16 fixed ordered epochs on the *other* 35 contexts, independently reinitialized each fold. One terminal source-PUBLIC reward only per two-step episode; heldout history never fitted. Test only after cold restore and frozen evaluation.

**Task family A (non-additive):** `target = -1 + C[cue] + A[first] + B[second] + 1.2 * U[cue] * V[first]`, with frozen arrays C=(-0.8,0.3,1.0,-0.2), A=(-0.5,0,0.5), B=(-0.5,0,0.5), U=(1,-1,1,-1), V=(1,0,-1). All are synthetic external harness constants, never available to the candidate or strong control except via training examples. Task family B is the original V17 *additive* target (same without the U*V term), for a no-regression diagnostic.

Run matched arms: (1) full candidate, (2) identical candidate but **relay gain updates disabled during training**, (3) unchanged V17 source-public additive learner, (4) strong conventional multivariate ridge least squares on explicit public history, cue×first interaction terms, and second action, trained on exact same 35 examples (regularization 1e-6). Conventional control may freely use the public fields but not hidden world data; its advantage is explicitly measured, not dismissed as illegitimate.
