# Original-native input action/output reward site overlap — prospective diagnostic (2026-10-27)

Read-only from unchanged draft PR #582 `a39171a76d0d7817e3563682bb139a9d7ecf37c4`. Source-free development evidence only; no genuine external source, no FSA first use, no merges. Prior source-frozen prequential decoder negative-control run [#40587489962](https://github.com/spoonman136668-ai/Yggdrasil/actions/runs/40587489962) found canonical reward output site decoder superior to all five output label permutations but excessive native `Backup` ranking and modest reward category bit calibration.

**Architectural hypothesis:** `public_bits(obs, action)` encodes the selected action at original `ACTION_SITES=(0,2,5)`, which are also the output-reward category readout cells for `REWARDS=(-3,0,10)`. The original local predictor's same-cell/self-bit feature may create an action-identity signal in the corresponding reward-output prediction irrespective of whether the public action actually earned that reward.

**Single controlled intervention (evaluation only):** In the same *frozen source native predictor snapshot*, compare `native.predict(public_bits(observation,action))` with `native.predict` of the same public observation pulse but with **only the chosen action bit cleared**. This observation-only counterfactual is intentionally outside the supported real action-conditioned interface, so it must NEVER be used to choose an action, train the model, claim real-world value, or propose deletion of action conditioning. It isolates feature-to-site sensitivity, not actual credit-learning causality.

Use fresh synthetic family IDs **54..61**, seeds **52..59**, 64 identical resource-bounded trials with 80 original context and 80 changed/new context actual source-free public experiences, single original `NativeTaskRingBridgeDev`, legal chosen-action events and 3 public reward categories (-3,0,10). An evaluator-private task law selects +10 for optimal, 0 for neutral, -3 for last; source-blind scheduled exploration supplies coverage. Probe all five public observations × three action identities at stages **before any training**, **after 80**, **after 160**. Record pre/post counterfactual output-site changes at own action/reward site and at two other output sites, and changes in *reward decoder value*; stratify by identity of bit activated and stage. Count experiments and compare across Windows/Linux. Assert exact source and original checkpoint cold restore, no changes to native code or accepted branch.

**Negative control:** for the same native trained model and public observation, the observation-only baseline input must be identical across the three hypothetical actions. The action-bit perturbation can still affect neighbor cells (and should be measured). The output reward readout labels shall not be permuted/retrained. A positive own-site delta is a causal input-bit sensitivity finding, *not proof that the model's reward learning failure is caused by this feature*: confounding across predictors/contexts and trained roles remains possible. Do not claim a superior learning mechanism or a passed external scientific test.

A separately preregistered genuine action-learning candidate with heldout testing and independent on-policy conventional controls is required before changing the original native learning or decoder. Keep source authority read-only.
