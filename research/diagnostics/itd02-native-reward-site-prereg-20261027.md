# ITD-02 original-native reward-site decoder negative controls (2026-10-27)

Source: exact unchanged Yggdrasil #582 head `a39171a76d0d7817e3563682bb139a9d7ecf37c4`. Development-only diagnostic. No original simulator or FSA first-use. Native source, core, checkpoint format, prior experiments and accepted branches must not be changed.

**Falsifiable question:** Is the source-declared reward-site mapping `REWARDS=(-3,0,10)` → `ACTION_SITES=(0,2,5)` reflected by the genuine original eight-cell `LocalTaskRuntime.predict` output bits after ordinary public action/observation feedback? The original decoder computes `-3*p[site0]+10*p[site5]` with three **independently predicted sigmoid sites**, not a normalized categorical distribution. Prior frozen-source prequential action ranking exhibited strong Backup bias. This diagnostic must separate decoder-site calibration/rank from the memory policy and the finite dataset.

**Fixed test before evidence**:
- Fresh synthetic public observation/evaluator task families **46..53** × seeds **44..51**, 64 paired family/seed fixtures; 90 original context episodes and 90 changed/familiar+new context episodes per case.
- Precisely three public reward labels: optimal chosen action +10; deterministic evaluator-private neutral alternative 0; third -3. This deliberately tests the *previously unexercised zero-reward output cell* and is not comparable numerically with the earlier two-label task family.
- Original native model chooses every step; a fixed bounded forced-action schedule supplies exploration at public-only observation-visit indices 0,1,2 and one in 9 subsequently, selecting rotating available actions independently of the reward law. Mark forced actions and do not describe result as independent all-greedy on-policy.
- Log **pre-outcome** action-conditioned native predictor probabilities for three reward sites separately for each of the three available actions; assert original `native_reward_scores` equals source-declared site readout. Then only the evaluator computes outcome; original native and memory update on the actually selected public step. No teacher advantage to the model.
- Measure per-site chosen-event target-bit mean squared error (Brier) and bias against true site bits, rates of actual -3/0/+10 rewards, native scorer action-rank accuracy, native decoded Backup/GoForward/TurnAround action frequencies and the fused/actual source policy. Record all data per family/seed and both stages, cross-platform identical behavioral output and source-only cold interpreter state retention.
- **Negative readout controls:** all six predeclared permutations of the three output sites. All six are evaluation-only analyses on the *same predictions and public outcomes*; never retrain/choose actions with alternative readouts. Report permutation-by-permutation rank and pre-outcome selected-event scored error and avoid selecting the winning permutation as a model without prospective validation.
- Report memory-only and native-only ranking, original fused and forced-choice accuracy separately. Test that input action-bit at site5 could be structurally confounded with public reward +10 output site5, without asserting causation from a correlation. No re-labeling hidden source.
- If canonical mapping has ranking weakness or a site exhibits reward-bit miscalibration, record **diagnosis only**. No parameter changes or decoder promotion. A separate preregistered learning-mechanism hypothesis with different task families, full conventional acting controls, G29, custody and retail-hardware gates is required for any promotion.

Decoding three independent sigmoid outputs as probability of a mutually exclusive reward category is not sound. Therefore do not call the raw weighted sum a calibrated expected reward; evaluate raw site bits directly. Scope: engineering diagnostic, NOT external-world evidence or scientific first-use.
