LIMITS AND CONTROLLED NEGATIVE WITNESS
--------------------------------------
(1) A pair of binary interventions x1,x2 has 2^2=4 distinct binary
two-stage action sequences; the original LR-92AU scientific *development*
task has 2^4=16 DISTINCT atomic intervention identities. Any direct
16->4 mapping necessarily aliases actions. Moreover a two-stage
action/transition is not automatically semantically equivalent to
one simultaneous four-bit do-intervention.

(2) The demonstrated illustrative map:
  (mask&1, (mask>>1)&1)
collapses four atomic masks into each of four native pair codes.
For a synthetic deterministic causal effect y=(mask>>2)&1 and an equal
prior over the four masks in each encoded class, two masks yield 0 and
two yield 1. An alias-only first-forecast policy has an exact Bayes-optimal
expected Brier 0.25, versus 0 if the full atomic intervention identity
is supplied. The 0.25 gap is an ANALYTIC INFORMATION BOUND constructed
for that example; it is NOT a native model observation, claimed gain or
general Brier lower bound for every possible source law.

(3) Separately, paired binary views that share the first coordinate
have exactly 2^3=8 configurations; a hypothetical independent 4-bit
PUBLIC CONTEXT would have 16 states, impossible to encode injectively
in those paired views *alone*. IMPORTANT: LR-92AU's actual four bits
are four do-action bits, NOT four context-view bits. Do not conflate
this hypothetical context-source limit with the actual action mismatch.

No admissible action-identity-preserving native adapter has been proven
