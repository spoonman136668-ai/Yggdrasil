## Exact static source diagnosis, not a witnessed simulator failure
- `CausalTaskDistribution.sample_fresh_task(task_id=None)` defaults **every** fresh task to `task_id=-1`, irrespective of private weather/causal configuration.
- `MetaHighwayEnv` records per-task performance by this key. Optional adaptive sampler updates fixed arrays by task ID; `-1` aliases their final slot. Default uniform sampler update does not corrupt a numeric array, but source attribution still collides.
- `MetaHighwayEnv.reset` can resample a new task at `episode_count >= context_length` when `is_meta_testing=false`; `set_task` reset clocks and installed task can be replaced even if the evaluator intended A→B→A continuity.
- The existing EXT-MHE01 public packet fence correctly strips task identity/hidden weather from **learner-visible** data. That means identity must be verified separately as private, source-owner provenance, never injected as a new learner cue.
