THE FROZEN EXPERIMENT
---------------------
240 genuinely fresh procedural worlds, 81 static, 81 one-step, 78 two-step.
Three independent seeds. All are within a PREPROGRAMMED 80-state grammar:
16 static base truth tables x (1 static + 2 lag1 + 2 lag2 masks).
Output noise flip p=0.35. Initial context0 training 112 outcomes,
context1 64 chosen actions, then 256 independent validation outcomes in
context1 and 256 COLD context0 evaluations AFTER context1 learning.

The baseline, new policy and original gate on the candidate tape observe
the same actions, consequences and inherited within-world context0 data.
Active policy chooses highest predictive-entropy action; balanced alternative
uses 64 alternating interventions. First-order EIG also has its own actions.
RF32 uses identical candidate-tape fitting labels but differing prior
capacity and whole-process cost; its scores are descriptive only.

New rule: if fit-only P(lag2)>=0.55 use the lag2 mixture posterior;
otherwise predict using the independent retained first-order posterior.
Old rule: if the winning family mass >=0.55 condition on that winner
(static/lag1/lag2), otherwise first-order fallback.
No oracle family label was used in either rule.

DO NOT TREAT THIS AS A NEW MECHANISM DISCOVERY
----------------------------------------------
The existing family gate achieves essentially THE SAME q1 prediction as
the new policy. For lag2, both 64.0775%. This experiment therefore
does not validate the proposed gate as an *improvement* over the previous
family-gated learner.

The so-called sham history control is structurally NON-DISCRIMINATING:
for masks 1 and 2, flipping the previous binary action is mathematically
compensated by swapping mask labels 1 <-> 2. The sham therefore attains
near-identical scores without disproving genuine history dependence.
A genuinely history-destroying control must be preregistered on new,
disjoint structures before a causal mechanism claim is entertained.
All tested structures are in the programmed grammar; this is NOT
generalization to an unfamiliar mechanism family.
No weights persist across worlds. Only within-world context retention
was measured, not lifelong cumulative learning.
