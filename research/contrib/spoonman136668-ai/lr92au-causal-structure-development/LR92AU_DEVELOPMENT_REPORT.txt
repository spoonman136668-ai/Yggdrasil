DESIGN AND ACTUAL INFORMATION BOUNDARY
--------------------------------------
Four independent binary do-action variables => 16 possible interventions.
Unknown causal mechanism consists of a subset of TWO or THREE parent variables
and an arbitrary generated Boolean conditional table (every parent essential).
No catalog of complete truth tables, no predeclared operator identity is
provided to the learner. The learner integrates 15 parent-subset Bayesian
hypotheses with Beta(1,1) public-response likelihoods and a fixed complexity
prior. It retains only the last 32 observed intervention/outcome records and
chooses actions by posterior expected information on parent identity plus a
precommitted coverage bonus. This is finite human-engineered structure-learning
and not spontaneous invention of an unrestricted causal ontology.

Two disjoint previously unused DEVELOPMENT seeds 77033101 / 77033102,
three families pair/triple/sparse_random, four worlds each = 24 worlds.
Each world has an unannounced A/B/A switch, with evaluator-only phase lengths
20..28 observations each, noisy Bernoulli flips at 15%. The learner receives
only its selected intervention, then the resulting public label; switch times,
parent mask, response table, counterfactuals and noise draws are evaluator-only.
All methods receive the SAME NUMBER of actions and labels per world, but
DIFFERENT actions according to their permitted policies. That means equal
observation counts, not identical information; comparisons are of complete
online policies with matched interaction budgets. No future-label information.

CONVENTIONAL AND NEGATIVE ARMS
------------------------------
ConstructiveInfo: unknown-table parent posterior + information-seeking actions
  learned/history persistent=34 bytes; checkpoint=70 bytes
ConstructiveCoverage: identical fitted parent posterior and memory, but action
  selection by deterministic least-covered 16-action assignment
  learned/history persistent=34 bytes
FullTabularCoverage: conventional independent Beta(1,1) per exact action,
  fully fitted on all previously observed public labels; 64 learned bytes
SlidingTabularCoverage: last 32 public actions/labels, conventional
  independent Beta(1,1) per exact action, 33 persistent learned/history bytes
All four models are <=928 bytes, not a claim of matched byte totals or fully
matched runtime cost. Python heap/transient Bayes computations are greater
than these serialized persistent-state bytes and NOT resource-matched.
Source freeze prior to labels; no hyperparameter sweep or result-driven tuning.

INTERPRETATION / NEXT RESEARCH
------------------------------
The constructed-parent-set representation is a distinct and more general
mechanistic object than the previous eight fixed truth tables, and it
improves parent recovery vs a coverage intervention ablation on this exposed
development cohort. However active information selection does not produce
joint superior B-phase adaptation and A-return predictive accuracy, while
its measured computation is much higher than tabular. Preserve this negative
result. Do not retune the same 24 worlds. Next independent program (IF owner
wants) should test true persistence of learned relational objects across
