PURPOSE
-------
Test whether a conventional 14-bin learner requires correctly aligned prior
action history to learn a deliberately history-dependent causal relationship.
This is an evidence/negative-control gate, NOT the primary A->B->A study.
A previous end_episode() sham destroyed history; this gate instead replaces
the previous-two-action context with two older, already observed public
actions. Both learners receive the identical current public action, public
outcome, order, number of events, architecture, and 480-byte memory budget.

INTERPRETATION, LIMITS, STATUS
------------------------------
This validates that preserving aligned historical ACTIONS matters in a
synthetic mechanism intentionally defined by prior actions. It does NOT
validate A->B->A cold restoration, spontaneous regime recognition, held-out
unfamiliar structures, RF32, correct Bayesian change-point inference, or
native lifelong learning. This lagged-history ablation does not alone fully
satisfy the original prereg's stronger history-PERMUTATION sham requirement.
The fixed 64/64/64 prereg schedule still has a potential timing-information
confound. More fully fitted controls and independent prospective source
custody are required before even considering scientific first-use.
