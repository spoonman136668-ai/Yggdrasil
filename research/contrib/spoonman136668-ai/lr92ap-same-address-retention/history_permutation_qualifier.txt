PROSPECTIVE SHAM DESIGN
-----------------------
Fixtures are exactly the two ALREADY EXPOSED development seeds
73004303 and 73004304; all protected primary seeds are explicitly rejected.
For each seed, evaluate 1024 public action/outcome observations with 128
warmup and 896 scored prequential predictions, separately under:
1) history_xor: y = current action XOR previous action XOR second previous
   action with Bernoulli(0.15) observation noise.
2) action_only: y = current action with the same 0.15 observation-noise rate;
   this is a null control for spurious temporal advantage.

Both arms use the same FullHistory14 conventional model (480 persistent
learned/history bytes, below the 928-byte cap); the exact public action/y
tape and per-event update counts are identical within each pair.
Aligned arm receives actual prior two public actions. Permutation arm draws
two distinct prior POSITIONS from an online seeded shuffle of the preceding
up-to-32 ACTUAL public actions, never any future action or hidden y.
The randomizer is evaluator-side, seeded as fixture_seed XOR 0x34A7D19,
independent of public labels. It does not add learned parameters or memory.
This is a fixed randomized online history permutation, not label permutation,
not every possible permutation, and not an original independent science run.
