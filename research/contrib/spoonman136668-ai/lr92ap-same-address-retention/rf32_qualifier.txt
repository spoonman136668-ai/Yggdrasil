PURPOSE AND FAIRNESS
--------------------
Supply preregistered RF32 as a conventional predictive *reference*, NOT as a
memory-matched control. It is a standard scikit-learn RandomForestClassifier
with n_estimators=32, criterion=gini, bootstrap=True, no depth restriction,
min_samples_leaf=1, max_features=None (all three input features), fixed
random_state=73004300+address slot, n_jobs=1. Each public observation fully
refits the forest for that address on *all preceding observed* examples;
there is no warm_start or partial training. Predictions occur BEFORE the
current outcome is provided; refits occur AFTER the public outcome arrives.

The only predictors are the current public action and two *previous* public
actions (including episode-initial sentinel 2). No phase identity, phase
schedule, hidden outcome, unobserved counterfactual, future input, test label
or cross-address information is a feature. Each of the 16 active/retained
address slots has isolated training data and a fitted forest. End-episode
resets context but not learned examples. Exactly the same public tape as all
previous LR-92AP fixture controls is used (seeds 73004303/73004304 only).
Protected primary seeds 929209101/102/103 are never evaluated.

IMPORTANT BUDGET CAVEAT
-----------------------
Compiled 32-tree estimator with 192 samples serializes to 17,888 bytes in a
trusted local pickle diagnostic at each of the two fixture seeds, even though
its public tape-only restore envelope is 868 bytes. Thus the fully fitted
forest *exceeds the 928-byte candidate budget*. The 868-byte envelope omits
the compiled forest and is NOT a valid accounting trick to classify RF32 as
memory-matched. Report RF32 as out-of-budget predictive context only; NEVER
place it in the strongest *memory-matched* control set or declare native
resource superiority based on this reference.

No pickle data is loaded or used as a model checkpoint. SHA256-checked custom
snapshot stores learned public event rows plus 16 two-action contexts, and
restore refits the complete forest from those rows; deterministic replay and
single-address isolation are tested. No approximate gain claim.
