CONTROL IMPLEMENTATIONS
-----------------------
matched_tabular_controls.py.txt adds two executable conventional baselines:
* FullHistory14: 16 addresses x 7 reachable histories x 2 actions x 2 outcomes
  using uint8 counts, plus 32 bytes actual prior-action state; 480 bytes total.
  Counters saturate at 255; not a boundless full-history learner.
* FixedWindow14: exact most-recent-32 actual public observations PER address,
  each stored as a 5-bit (history,action,outcome) code; evictions subtract from
  the original temporal bin. 448 count bytes + 32 history + 320 packed ring +
  16 lengths + 16 head offsets = 832 persistent bytes (limit 928).
Both accept only public action and public consequence; prediction is read-only.
States restore deterministically from explicit incompatible magic and SHA256
checkpoint, with corrupt/invalid history and inconsistent window counts rejected.
Checkpoints include 4-byte version tag and 32-byte digest outside state budget.
