PURPOSE
-------
Provide the missing fully Bayesian posterior-over-run-length reference,
without confusing its HIGHER memory budget with the native 928-byte limit.
A constant hazard 1/64 is fixed before any scored fixture. Each address has
all observed candidate change-point positions, a normalized posterior mass
over each, and 7 temporal patterns x 2 public actions x 2 Bernoulli outcomes
with independent Beta(1,1) conditional likelihoods per contiguous segment.
No MAP collapse, no truncation of the posterior within its explicit 512-public-
event-per-address resource cap; predictions marginalize the posterior over
run lengths and a possible changepoint just before the next public outcome.
No future outcome, phase label, regime name, global clock or schedule input.
This is a conventional BOCPD generative model with known hazard and Beta
priors: not a trained hazard, not a distribution-free oracle, not an
unbounded production system, not new native model training.

RESOURCE ACCOUNTING
-------------------
The retained posterior grows by one change-point alternative per public
event per address; at 192 observations the SHA256-checked portable snapshot
is 13,428 bytes, strictly ABOVE the matched 928-byte state cap. Actual
in-process Python heap is larger. Therefore this is a conventional
OUT-OF-BUDGET REFERENCE, NOT eligible to be the strongest memory-matched
baseline. It cannot be considered proof of memory-efficient superiority.
The checkpoint is a versioned explicit binary format with SHA256; restore
validates mass, counts, history, length, and trailing bytes.
