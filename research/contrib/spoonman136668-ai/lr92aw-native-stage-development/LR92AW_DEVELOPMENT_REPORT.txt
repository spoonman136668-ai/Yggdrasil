DEVELOPMENT STUDY / FENCED INFORMATION
---------------------------------------
Two new development seeds 88041001, 88041002, 3 families (mediated/direct/
mixed) x four worlds = 24, independently deterministic 48-80 public episodes
per A, B, A-return phase. Phase boundaries not supplied to learner, no
reset/marker at a switch. Total 4564 staged public episodes PER learner.
All arms learn from EXACTLY the same 4564 witnessed public rows, same two
stage actions x1,x2 and same revealed s2 and y, after sequential forecasts.
Public (views,s1,x1,s2,x2,y) contains no evaluator phase labels, latent
Boolean truth tables, parent-set masks, noise draws, or future actions.
The first action x1 and second x2 are independently generated from fixed
seeded public action streams, not chosen by the learner. Accordingly this
study establishes NO improvement in intervention selection or action value.
Simulated structural relationships arise from variable-subset conditional
Boolean laws; successor B uses a different causal parent mask from A and
an independently drawn transition law; source uses 10% label noise.
Out-of-grammar unfamiliar original-world science and tokenless native
learning are NOT established by this simulator.

Arms, all conventional or negative controls:
  structure_bayes: beta-Bernoulli evidence-marginalized 4 transition and
    16 terminal candidate parent subsets, no preprogrammed truth functions,
    fixed complexity penalty exp(-0.65 * parent_count);
  tabular_full: Laplace-smoothed full 4-context transition and 16-context
    terminal fully observed empirical frequency reference;
  tabular_window32: same empirical table restricted to 32 recent episodes;
  no_learning: constant 0.5 prior, no updates.
Evaluator-only exact true generative Bernoulli law gives expected Brier
lower-bound, NOT an equal-information trained comparator. The method of
score aggregation is MACRO over 24 worlds, not weighted by episode lengths.
Persistent state size uses explicit source-locked checksum-bearing snapshot
bytes, NOT native checkpoint bytes, trained tensor bytes or Python heap.
