# AAI-11G — attainable-goal, oracle-relative causal benchmark protocol

**Scope:** prospective **benchmark contract**, not a new learner, retuning of an old failure, or scientific first-use. Stacked on [AAI-11F draft PR #1068](https://github.com/spoonman136668-ai/Yggdrasil/pull/1068) at immutable `36cc12381a4153048e5971899fa388a0aafd7480`. **Preregistration was committed before implementation** at `a233c79b81f5a20ec7da6cff697526a91f5e14b5`. This protocol was explicitly designed with historical AAI-11F/11D results already known: mechanical qualification is **not blind scientific validation**.

The source-exact [AAI-11F oracle audit](https://github.com/spoonman136668-ai/Yggdrasil/actions/runs/43656413130) independently proved the original AAI-11A/B/D requirement of 60% exact goal success **cannot be reached** under a 2-action causal simulator: only **144 of 288** original transfer episodes have a reachable all-three-mediator goal, even with an oracle. The original score would need 173 hits, 29 more than are mathematically possible. This audit **does not change** earlier failed reward-improvement tests, existing scientific decisions or original benchmark source. The old +0.08 actual terminal reward gain over the strongest eligible control remains mandatory.

## New prospectively frozen benchmark contract

On exactly the original three mechanical fixtures and same 4 unfamiliar laws C/D/E/F, compare a future model's actual public-action learning against **all eleven fully trained eligible original AAI-11A conventional controls** (8 tabular/kNN/symbolic-pair/ID3/logistic + 3 identical structural-grammar full/recent8/recent16). Select the strongest by **actual original mean terminal reward**, and independently select the best by **attainable-goal conditional success** so a future model cannot claim improvement over a deliberately weaker opponent. The original risk-free AAI-11D posterior learner is a **separate descriptive diagnostic**, not a new benchmark candidate or exemption from any eligible control.

For each actual episode, the scoring evaluator alone uses its private exact law and 0–2-action reachability to determine whether its all-three-bit goal **is reachable**. Score:

- **Primary actual reward:** mean number of goal-matching bits minus 0.05 per actual intervention, over **all 288 episodes**, both reachable and unreachable.
- **Reachable-goal recovery:** exact goals achieved / **144 oracle-reachable** episodes. The oracle upper bound is **100%** under this denominator, rather than 50% in the raw metric. For illustration, old graph_recent8 108/144=75%, old posterior-only 117/144=81.25%; these are previously observed source-only figures, not new evidence of learning superiority.
- **Unreachable-goal regret:** oracle best possible reward minus each model's *actual* terminal reward on **144 oracle-unreachable** episodes, penalizing models that ignore impossible-goal bit matching and make bad interventions. Also separately track reachable regret and per-law outcomes.
- **Cold A/B retention:** separate original A/B common public challenge scoring using the untouched simulator; source is independently restored and no new learning episode contaminates the frozen context.
- **Whole-process compute:** preserve per-model train/checkpoint/challenge/restore/action/update and source SHA for a future actual candidate compared with fastest matched conventional on each required OS. Source-only control timings are not a substitute for a fresh candidate-versus-control cost qualification.

**Mandatory preregistered future model DEV gates:** new actual terminal reward **>=+0.08** over strongest conventionally trained control; attainable-goal conditional recovery **>=+0.05** over the *best* of all eleven controls on that success metric; unreachable-goal oracle regret at most **+0.03** worse than the strongest-reward control; A/B reward noninferiority within **0.03**; full-process time <=**2.0×** fastest conventional per OS. Before using a benchmark to pursue science, it must exhibit >=**0.25** original reward oracle headroom and >=**0.10** reachable-goal recovery headroom against the best conventional. No threshold may be revised after results.

These mechanical future DEV thresholds are **prospectively fixed for future, independently sourced candidates**, not retroactive reevaluation of AAI-11A, B or D. The subsequent genuinely independent transfer science would still need **new scope-specific first-use authorization**, frozen controls/seeds/splits, 64 independent transfer clusters, original 16 DEV and 32 NEGATIVE clusters, 95% paired reward-effect CI with lower bound >0, fresh matched cold retention and interference, and science benefit over strongest matched conventional with separately evaluated resource cost. None is authorized or consumed by this benchmark.

## Source-only qualification

The evaluator only replays the unchanged original eleven conventional models and descriptive posterior-only ablation on the **three original mechanical fixtures**: the same 64 common A/B public observations, 2/4 actual do-action challenge trials per unfamiliar law, 12 original x/goal contexts per law/budget/fixture, independent 0–2 actual own interventions per trial. At every scored context an *evaluator-only* oracle and two independently checked reachability algorithms confirm the 144/144 attainable/unattainable partition. The oracle never supplies labels, new observations or actions to a learner. Baselines' original exact source score `graph_recent8=2.134027778`, original `posterior_planner=2.189756944` and raw goal .40625 must reproduce within 1e-6. The original source and all candidate source remain unchanged.

Only **if** these exact-score and headroom checks pass will the result be called `BENCHMARK_QUALIFIED_FOR_PROSPECTIVE_SOURCE_DEV`. That is a test-fixture design status, **not a new model or scientific PASS**. No new native Yggdrasil learning code, weight change, main mutation, merge, Forge/Wingless/Hybrid integration, owner loop, controller, runner, scheduler or queue, paid API, user Library file, or first-use scientific cohort. Reserved DEV 994000–994015, TRANSFER 995000–995063, NEGATIVE 996000–996031 all remain untouched, with `--primary` technically disarmed.

Even after successful source tests, **mandatory full exact-final native Yggdrasil regression on Linux and Windows** plus source-pinned G29 atlas and all preceding suites must pass before the engineering branch is considered qualified. All source/evidence and negative results stay on GitHub in draft PR form.
