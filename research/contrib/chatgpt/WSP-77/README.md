## Scientific question

Can gradientless direct numerical neural weight programming generalize from paid physical action/consequence experience to a **large, independently preserved, genuinely never-charged physical input set**, and beat equal-evidence readout-only, random hidden weight edits, equal-paid random/balanced action policies and a converged ordinary neural learner?

## Why six bits and six actions matters

Six public binary sensors and six independently controllable public action channels yield **64 visible states × six actions = 384 real state/action contexts PER world**. Every no-reset physical training trajectory has precisely 144 real charged actions, so it can visit **at most 144 of 384** distinct pairs. Regardless of the active policy, at least **240 state/action contexts/world** must remain genuinely unobserved for physical evaluator-only tests. There are **12 independently salted primary worlds** (seeds 5101–5112), at least **2,880 truly uncharged state/action outcomes** across them, and four frozen nested-conditional negative worlds (seeds 5113–5116). This corrects WSP76's almost-fully-observed 4-bit evaluation; it still does not prove generalization outside hand-designed Boolean physics.

Six-bit private source families: four action-conditional XOR, four conjunction, four coupled multi-sensor, four nested adverse six-bit; all source families have shuffled hidden sensor/action roles, independently salted source SHA256 and source-private two-action tasks. Every action toggles its own hidden sensor role, potentially conditionally changing lower-priority roles, so all **64 visible states are evaluator reachable**. The policy/learner never learns the private roles from source code; a 64-state evaluator BFS **after all training** verifies source controllability.

## Three independently paid physical action trajectories

Per source seed, three physically separate but source-identical simulated worlds each charge 96 real no-reset Stage-A actions (same visible actions and outcomes but **paid separately**), followed by 48 real no-reset actions chosen by (1) WSP76's unchanged source-blind **observed paid causal contrasts**, (2) seed-hashed uniform random, or (3) a precommitted six-action cycle repeated exactly eight times. **16 seeds × three paid copies × 144 real actions = 6,912 actual physical action/consequence charges**. No teleportation, free source reset, arbitrary state training oracle, revealed source family/roles or uncharged physics fact. Equal action count does not mean equal learned information; actual paid state/action coverage is recorded for each arm.

The observed physical-contrast score is unchanged in semantics: +12 if the current real state has another already-paid action and this action is uncharged; +8 for a never-paid state/action; +4 if real paid outcomes have shown at least two action-specific bitwise change signatures; +4 if two other real actions at this state yielded different consequences; +2/(1+B action count); only consider B action channels with count <=least B action count+1. Tie breaks are fixed SHA256. Every proposed B action is executed against the current REAL state and paid before looking at its consequence.

## Six-bit numerical neural weight substrate and qualification

Port the existing WSP69/70 gradient-free source-blind representation/weight writer to **12 numerical inputs** (six public state bits plus six one-hot action features), 32 fixed real ReLU hidden neurons, up to 12 real paid-residual-selected ReLU neurons constructed after charge48 and another up to12 after charge96. Six next-sensor output weights and inverse covariance are numerically edited by rank-one recursive ridge (lambda=0.5). At Stage A's 96 actions, freeze full numerical hidden/bias/readout/covariance snapshot. The new model keeps original per-bit prediction margin abs(y−0.5)>=0.27 and leverage<=2; forced inference reports all predictions too.

After each policy's 48 additional paid actions, use the same WSP74 bounded supervised **finite-difference direct hidden-weight editing** expanded to six sensor coefficients: rank up to eight grown ReLU units by real B residual, try +0.5/−0.5 changes to their six sensor input weights, accept up to four distinct coordinate changes only if charged A+B weighted six-output loss improves >1e−9. Reprogram all six numerical readout vectors by identical 144-row real recursive ridge update. This is direct weight editing **without backpropagation**, but is still supervised numerical optimization on real physical experience, not magically programming arbitrary intelligence from no data.

Cold inference consumes *only* numerical hidden weight matrices, hidden biases, six output weight vectors and covariance; no raw charged ledger, symbolic source oracle or lookup table. All 16 source worlds must pass exact cold numerical snapshot reconstruction and altered-hash rejection.
