# NCI-NOVEL-06 engineering core — no scientific evidence

This **isolated source-free contributor** implements a bounded mechanism sketch for the preregistered [NCI06 protocol](prereg.md). It is not connected to Yggdrasil's native action selector or the Amalgam cumulative learner and is **not** a first-use science executor.

- `operator_core.py`: a memory bank for up to 12 independently observed public primitive worlds, at most 128 binary state/action/outcome observations each; every frozen primitive is retained as a 64-entry public-context action table. Unknown/tied states abstain. The target sees exactly 96 fit and 64 validation observations and searches 24 explicitly declared three-primitive programs; it binds only with sufficient within-context paired-action coverage and validation evidence of improvement over the uncomposed primitive.
- `ExactCompositionBayes`: independently enumerates **the same full 24-program grammar**, with a Bayesian posterior fit on exactly the same 96 public target observations. This is a **non-oracle** comparator, not a deliberately weakened baseline. A perfect tie or an advantage for the exact comparator is an honest negative.
- `test_operator_core.py`: fabricated fixed unit-level public tuples only; tests composition mechanics, denial without paired actions, action/state input validation, bounded witness admission, cold binary checkpoint restore, retained primitive readout, source-lineage mismatch, a rehashed invalid binding, and equal-input exact Bayes. These tests do **not** invoke original external source worlds or reserved scientific/engineering seeds. Local developer engineering qualification is not a scientific dataset.

## Important limitations

The four gates are pre-authored, not autonomously invented; this version is **static-grammar operator composition**, not open-world novel mechanism discovery. It cannot reliably generalize primitive truth tables to unseen public contexts; it returns unknown when evidence is insufficient. Paired actions in a unit fixture do **not** establish source-authentic interventions. A SHA-256 checkpoint detects accidental corruption and binds stored training inputs; it is **not** a keyed signature, reviewer authority, or proof of source authenticity.

The frozen NCI06 prereg still requires strong fully fitted conventional/independent exact-symbolic baselines, separate unfamiliar source families, held evaluation, cold functional retention across unrelated tasks, cost/memory profiling, reproduction and independent owner approval. None have been qualified by this code. No old NCI05 primary seed or 21-world engineering cohort may be replayed. **ENGINEERING: focused tests only; SCIENCE: UNVERIFIED; DEPLOYMENT: NONE.** Keep PR #1345 draft and route any independently qualified mechanism to the existing Amalgam PR #1278 owner, not into a competing canonical learner.

## Structural expressivity falsifier and residual discovery (development-only)

A 24-item syntactic program roster collapses to **eight distinct three-input truth functions**. The remaining **248/256** functions are inexpressible by `CausalComposer`, regardless of added training. An example is the three-input multiplexer `B if A else C`, which has two unavoidable truth-table disagreements with the nearest of the eight fixed functions.

`residual_operator.py` is an **isolated successor mechanism**, not a change to the native/canonical learner: it infers a newly represented eight-bit local operator solely from supplied public state/action/outcome fit witnesses (96) using three previously frozen primitives; it must observe at least four paired public action contrasts, cover all eight primitive-signal combinations with at least three witnesses each, reject already known fixed masks, and show at least 0.04 absolute Brier improvement on its 64 validation witnesses against the best fixed program selected only from training. It leaves the bank's previous primitive checkpoint unchanged and cold restore rechecks the new binding against the embedded public witness tape. `ExactTruthTableBayes` is an independently enumerated **all-256-function** equally informed exact Bayesian comparator fit on the same 96 public witnesses. `test_residual_operator.py` verifies a synthetic, manually fixed outside-grammar multiplexer and negative controls, not scientifically scored unfamiliar-world transfer.

**Scientific boundary:** Choosing one of 256 possible truth tables is evidence of a larger representable class, not invention of an unanticipated computational primitive or superior intelligence. The toy intervention fixture does not authenticate causal action effects, the source truth table is never seen by the learner, and there is no protected original-world evaluation, reproducible prospective held comparison against fully trained conventional controls, accepted native memory modification or owner approval. Do not retune scored NCI06 thresholds from these fixture results; any new prospective experiment must have an independently frozen source and untouched sealed cohort.
