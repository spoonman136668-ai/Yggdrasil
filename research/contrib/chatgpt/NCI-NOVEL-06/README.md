# NCI-NOVEL-06 engineering core — no scientific evidence

This **isolated source-free contributor** implements a bounded mechanism sketch for the preregistered [NCI06 protocol](prereg.md). It is not connected to Yggdrasil's native action selector or the Amalgam cumulative learner and is **not** a first-use science executor.

- `operator_core.py`: a memory bank for up to 12 independently observed public primitive worlds, at most 128 binary state/action/outcome observations each; every frozen primitive is retained as a 64-entry public-context action table. Unknown/tied states abstain. The target sees exactly 96 fit and 64 validation observations and searches 24 explicitly declared three-primitive programs; it binds only with sufficient within-context paired-action coverage and validation evidence of improvement over the uncomposed primitive.
- `ExactCompositionBayes`: independently enumerates **the same full 24-program grammar**, with a Bayesian posterior fit on exactly the same 96 public target observations. This is a **non-oracle** comparator, not a deliberately weakened baseline. A perfect tie or an advantage for the exact comparator is an honest negative.
- `test_operator_core.py`: fabricated fixed unit-level public tuples only; tests composition mechanics, denial without paired actions, action/state input validation, bounded witness admission, cold binary checkpoint restore, retained primitive readout, source-lineage mismatch, a rehashed invalid binding, and equal-input exact Bayes. These tests do **not** invoke original external source worlds or reserved scientific/engineering seeds. Local developer engineering qualification is not a scientific dataset.

## Important limitations

The four gates are pre-authored, not autonomously invented; this version is **static-grammar operator composition**, not open-world novel mechanism discovery. It cannot reliably generalize primitive truth tables to unseen public contexts; it returns unknown when evidence is insufficient. Paired actions in a unit fixture do **not** establish source-authentic interventions. A SHA-256 checkpoint detects accidental corruption and binds stored training inputs; it is **not** a keyed signature, reviewer authority, or proof of source authenticity.

The frozen NCI06 prereg still requires strong fully fitted conventional/independent exact-symbolic baselines, separate unfamiliar source families, held evaluation, cold functional retention across unrelated tasks, cost/memory profiling, reproduction and independent owner approval. None have been qualified by this code.
