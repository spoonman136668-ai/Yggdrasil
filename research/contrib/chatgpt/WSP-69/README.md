## Proposed learning mechanism
We now build and edit **actual hidden layer weights**, not just neural readout weights. A fixed, source-independent bank of 32 random ReLU neurons and raw sensor/action skip inputs is used initially. At 48 and 96 physically charged actions, the learner ranks **training-only** public input contexts by current four-output prediction residual. The top 12 previously unrepresented source-blind contexts each become a new **ReLU neuron** whose numeric weights implement `max(0,1-0.5*Hamming((state,action),charged_context))` over the eight public bits. A newly constructed neuron fires for its observed physical input and nearby one-bit states with the same action. Its weights contain the context only, **not the physics label or the true outcome**.

After growth the four neural readout vectors are reprogrammed via rank-one recursive ridge edits (lambda=0.5), replaying only the public charged experiences actually observed. Between milestones, each charged observation directly edits the existing readout matrix. There is **no symbolic causal rule candidate search, WSP67 compiler, hidden source physics import, gradient update in the candidate, or evaluator test-label access**. Saved neural weights, biases, and covariance alone reproduce inference and abstention; the charged ledger is not stored inside the cold neural snapshot.

**Critical limitation:** choosing neuron centers from high-residual charged input contexts is hand-designed local prototype learning, and the ReLU shape is supplied. This is not discovery of a universal neural representation grammar. It may merely interpolate near observed training examples and can overfit. The evaluation explicitly scores never-observed physical transitions separately, and the random-prototype and exact memorization controls must not be omitted.
