## Purpose

The original six-input/three-output AAI-11P task had only six fixed causal equations and an impossible unconditional goal-success threshold. AAI-11G repaired that threshold, but repeated short-window and action planner methods did not clear the strong conventional reward gate. AAI-12P asks an earlier, more important question: **Does a broader structural causal environment offer a valid, information-identifiable task with meaningful intervention and oracle headroom against fully trained conventional methods?** A problem must pass this gate **before** proposing another native architecture/learner.

AAI-12P supplies 8 controlled binary x variables, 4 sequential observable binary mediators, 16 possible goals and 16 legal real one-bit set interventions, with **maximum 2 actual consecutive actions costing 0.08 each**. There are four genuinely distinct causal DAG template families: ordinary multistage causal chains; context-controlled operator switching and mediator inversion; compensatory 4-way interaction; and context-dependent inhibitory mediators. Each world has SHA-256-derived **immutable** rule indices, no seed scanning; all real do-actions recompute downstream consequences. **No latent labels, family, world ID, true law, privileged optimal intervention or counterfactual** enter learner observations. The evaluator alone may inspect the generating DAG and compute exact 0–2 action oracle reward/reachability.

Source-only worlds are deliberately *mechanical fixtures*, **not a 12-world science transfer study**: 4 structurally varied fit worlds, 12 disjoint transfer worlds, 2 fixed public fixture contexts, 8 preselected held-out (x,goal) public cases per target world, with 4 actual exogenous challenge action pairs per transfer world. Every conventional method starts from the SAME 64 actual public pre/post training observations across the four fit worlds. Each transfer condition is cold restored after identical 8 actual challenge observations; then every learner selects at most 2 of its own true actions and sees only its own actual consequences. Exactly **192 transfer + 64 familiar cold episodes per method**. A deliberately broken causal-association negative control rotates public post-action mediator results, preserving their multiset while damaging correspondence to interventions. Stop if broken evidence works better.

## Strong matched conventional benchmarks (all 8 preregistered)

`tabular_all`, `tabular_recent16`, `knn_recent32` (5-neighbor Laplace), `id3_depth5` (fully fitted deterministic information gain), `logistic_pair_fullfit` (intercept, all 8 unary and 28 pairwise terms; 250 full gradient epochs over all permitted public observations, with permitted online SGD after each actual observation), `causal_structure_recent8`, `causal_structure_recent16`, `causal_structure_all`.

The last three exhaustive source grammar fit methods see exactly the SAME public data and use 0/1/2 action planning. **Their structural program grammar explicitly includes every functional form the hidden simulator can generate**: XOR/AND/OR pairs over x and observed upstream mediators, conditional operator switching under x6, mediator inversion under x7, inhibitory m0 & NOT m1, 4-way XOR compensation, and context-flipped final mediators. Each causal structural baseline fits its complete source structural hypothesis list to observed mediator errors, using either the last 8/16 or all public observations. The model evaluates a causal DAG with smoothed predicted outcomes rather than receiving privileged true DAG IDs; therefore it is not deliberately excluded from the correct rule family. All eight are fully trained/fit on their matched available observations. The fastest and strongest are selected from real measured source results rather than prefixed or weakened.

The baseline benchmark compares exact original reward on **all goals** (including mathematically impossible ones), independent oracle-reachable exact-goal recovery, oracle regret and A/B retention. STOP and a blind deterministic one-action reactive policy serve as further task difficulty diagnostics, **not** eligibility substitutes.
