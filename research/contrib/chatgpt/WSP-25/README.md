# WSP-25 — local causal relationship correction

The frozen DEV hypothesis is supported: one self-selected validation intervention
revealed each deliberately hidden exception and wrote one numerical correction
instance. All 1,024 joint Z predictions were correct after the query. All 384
previously observed unique Z facts, 128 Y bucket states and 512 Y predictions
were preserved; all 128 checkpoints cold-restored and replayed idempotently.

This is an isolated public research fixture, not admitted Yggdrasil functionality.
The preregistration was committed remotely before implementation and primary use.
See `prereg.json`, `provenance.json` and the complete per-case `result.json`.

## What changed

The unchanged WSP-24 learner first acquires the six affine coefficients using its
original numerical experiment-selection policy. The wrapper stores four parent
coverage bits and four observed Z labels. Its first-unseen numerical selector then
chooses one joint intervention without receiving the hidden exception address.

A real mismatch proposes four binary detector weights from the observed X/Y bits.
The proposal must preserve every protected old Z label before a numerical gate
commits it. The resulting Z function XORs the old affine response with one active
exact-parent conjunction. The Y bucket and original affine weights are unchanged.
Already-protected contradictions latch a local Z fault instead of overwriting facts.

The generic correction template and learning rule are preprogrammed. The observed
exception's address and residual are acquired from actual feedback. This allocates
a new feature **instance**; it does not invent a new primitive type.

## Costs and limits

* 53 resident binary task scalars: base 37 + coverage 4 + remembered labels 4 +
  detector weights 4 + occupancy 1 + residual 1 + local fault 1 + query-used 1.
  Spare capacity exists from the beginning. Fixed growth configuration is not
  learned knowledge. Physical Python objects/checkpoint framing cost more than
  53 packed bits; the canonical checkpoint is 796 bytes per case.
* The static program contains a known causal order, the parent's finite affine
  prior/query planner and a generic exact-parent correction circuit. Source byte
  sizes and hashes are recorded, not treated as free learned capacity. Candidate
  lookup of true identity, exception address or outcome table is forbidden.
* 128 case runs represent 128 distinct causal functions but correlated authored
  alternatives, not 128 independently sampled natural tasks. There are 576 actual
  primary events: 256 initial observations, 192 original interventions and 128
  extra validation interventions. Negative arms add 256 feedback events. Control
  forks reuse the same actual transcript, not extra hidden information.
* Before final scoring, all four Z-parent points have been observed. This shows
  correction, retention and reuse across U contexts, **not unseen-parent
  extrapolation**. Symbolic and trained references tie; their representation,
  capacity and compute differ. No matched whole-process efficiency claim.
* Candidate takes zero gradient steps; the genuine trained reference uses 18,432
  full-batch Adam steps (144 per fit), maximum final BCE 0.0099848852. Local whole
  evaluation took about 0.90 seconds; exact environment/timings are in the result.
* A single false observation is indistinguishable from a true local exception at
  that moment. The noise negative preserves that failure. There is no general
  noise robustness, temporal-change recovery, arbitrary family discovery, general
  intelligence, SCIENTIFIC_PASS, integration, promotion or deployment claim.

## Reproduction and qualification

`python research/contrib/chatgpt/WSP-25/run_dev.py` runs the frozen comparison.
`python research/contrib/chatgpt/WSP-25/qualify.py` runs all original and
WSP01–17/WSP19–25 suites, this evaluator, permanent G29 and clean-source checks.
The existing WSP21 regression workflow is reused on hosted Ubuntu and Windows;
no runner, queue, workflow file, controller or scheduler is added. Exact final
candidate CI and source custody are reported on the draft PR. Earlier baselines
and all accepted/runtime state remain unchanged.
