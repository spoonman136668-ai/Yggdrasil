# NCI-NOVEL-05 frozen preregistration — adaptive causal-interaction birth
Date: 2026-11-20. Independent contributor, source-free development only. Not owner-authorized original-world first-use, canonical training, or merge.

## Hypothesis
Can a tokenless, public-intervention-only learner add previously unavailable higher-order causal interaction terms after witnessed contradictions, retain familiar knowledge across an A -> B -> A-return schedule, and outperform fully fitted, same-evidence conventional/exact controls rather than merely a deliberately weakened grammar?

## Frozen cohort
Public inputs: four binary context bits x0..x3 plus one binary first action a. One stochastic binary consequence, noise=0.06. Old source law is familiar XOR of x0 and action. Seven independently parameterized law families per seed: novel `fourfold`, `conj_pair`, `action_switch`, `parity_mix`; negative `unchanged`, `unidentifiable`, `degree_five`. Evaluator knows hidden law and draws noise; learner never accesses law identity. Input/action/consequence tapes are derived solely from frozen seed, family, phase, index, and action using SHA256, with unique version prefix.

One development pilot seed 809001 may be used for engineering fixes before source freeze. Primary seeds (unconsumed by this study) 809011, 809033, 809057, 809089, each with all seven families. Per world/arm: 128 OLD_TRAIN, 256 NEW_TRAIN, 64 VALID, 64 HELD_SHARED, 64 HELD_POLICY, 64 OLD_RETURN. Each episode is exactly one observed intervention (no private future input); no learner updates on VALID/HELD/OLD_RETURN.

## Learners and comparisons
CAND: Fit exact Bernoulli likelihood over the base sparse two-term ANF Boolean grammar with monomials of public degree <=2. If training-only last-64 predictive Brier >0.12 AND at least 6 paired public contexts differ only in x3, permit one prospective expansion to two-term ANF with monomials degree <=4, with a fixed penalty of 0.6 per monomial degree and unchanged evidence. Expansion uses only admissible witnessed public tapes, not hidden rule labels. Evaluate Bayesian-model-average forecast; identify a new causal relation only when posterior top mass >=0.95 and the selected expression contains x3.
Controls fitted to the same public OLD/NEW tapes and no hidden law: BASE-BMA (fixed degree<=2), FULL-BMA (pre-expanded exact same degree<=4 rule class/prior), ExtraTreesClassifier (128 estimators, min_samples_leaf=2, random_state=seed, full public inputs), and Jeffreys-smoothed full-context Beta table. Fit every control independently to its training tape. Select strongest control per world using VALID Brier before HELD. A prior-only arm supplies a no-learning negative. ExtraTrees receives the same data and may use greater compute; report train and evaluation wall/CPU, do not claim matched-compute superiority without separate qualification.
Policy chooses a maximizing action from each arm's forecast, tie to a=0; HELD_POLICY uses the same exogenous potential outcomes for all arms. Report old-return Brier from original OLD state; verify frozen OLD state bytes remain unchanged after NEW training. Do not call separate canonical Yggdrasil model.

## Frozen decision
Science development GO only if candidate improves HELD_SHARED Brier by >=5% relative to validation-selected strongest fitted control AND realized HELD_POLICY reward by >=0.01 in >=3/4 novel families, both per-family mean across all four seeds; candidate old-return Brier <= original frozen old-return Brier +0.02 in all four seeds; new-relation false positives 0/4 for each of the three negative families; and candidate beats BASE-BMA on HELD for >=3/4 novel families. Otherwise DEV_NO_GO. Full native scientific PASS requires separate owner-admitted source, dual-platform exact-SHA full regression and independent qualification.

Preserve negative results, all per-world scores and source provenance; no post-primary tuning. Report independently computed aggregate audit after primary without reusing learner source or rerunning primary seeds. One primary only. Deployment NONE. Amalgam PR #1278 owns sole canonical lineage and integration. Existing ENERGY/NCI-NOVEL-01 through -04 results unchanged.
