# CKAD-DISTINGUISH-V1 — prospectively frozen causal counterexplanation probes

This source-free development experiment directly follows the qualified **CKAD-SHARED-V2** cross-world operator-learning result and the read-only **CKAD-IDENT-AUDIT-V1** structural-certainty audit.

Its hypothesis is that **four interventions selected specifically to challenge a learned causal explanation** can reduce false confident predictions more efficiently than ordinary active selection or random auditing. It preserves the independently learned shared causal operator and uses fully new, SHA-seeded simulated worlds. The ground-truth program is never passed to a learner, probe selector, or comparator. Eight effects are acquired before the audit; the final four are chosen without viewing future outcomes, and all methods receive **12 total** synthetic effects per world.

The FIT phase uses 16 worlds with 16 genuine synthetic effects each to learn and freeze a shared causal operator. Evaluation uses 32 new transfer, 32 degree-three shifted-family, and 32 corrupted-initial-evidence worlds. Four separately instantiated effect actors per world support target disagreement probes, ordinary narrow active selection, random action selection, and random auditing. Target and random-audit receive **identical first eight witnessed actions and outcomes**; their only intentional difference is the final four probes.

The target uses the ordinary native posterior of the learned shared operator and an **independently enumerated 3,200-program broader hypothesis family** to select evidence likely to falsify its narrow learned model. All four post-fit observed consequences must match the *frozen* eight-effect prediction to admit target held readout. The broadened class is a supplied diagnostic prior, not knowledge of the true source family and not new primitive invention. When the narrow model contradicts actual effects it abstains; an independently calculated broad-consensus fallback is reported separately but is never promoted as accepted knowledge.

Controls: no-memory posterior on **identical target observations**, independent exact 1,920-program symbolic same-information learner, fully trained sklearn CART on each arm's 12 observations, and an expanded-gate conservative readout. All controls use their actual witnessed effects only. No active arm has access to source seeds, truth gates, held labels, or other arm future outcomes.

**Frozen metrics** are in `prereg.json` (commit `119e91177ed14256ce272709a0d39d8fbe290b08`). A positive science claim requires more than a low error rate achieved through refusing every question. The experiment therefore freezes both confident-error bounds and familiar/negative coverage requirements. Nulls and failures are retained; post-result tuning cannot change this result. This is fully synthetic, so `scientific_pass=false` and `accepted_native=false` are compulsory even when development thresholds pass.
