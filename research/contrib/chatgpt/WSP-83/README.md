## What is being falsified

WSP82 could *select* a single predicate from its frozen 135-gate library,
but could not learn a rule that requires XOR composition of two
independently meaningful lagged features. WSP83 preserves the original
135 public ReLU/Boolean atoms unchanged, searches exact singleton fits
first, then builds previously absent TWO-feature XOR compositions using
minimum structural-complexity fits on the SAME 384 paid public observations.
It physically writes two 0/1 numeric readout vectors and uses an additional
ReLU stage to compute XOR, then cold-restores numerical model weights.
It abstains if compatible minimum-cost candidates disagree.

This is **bounded feature composition**, not genuinely open-ended
invention of primitives: the researcher provided the 135 atoms, the XOR
operator, maximum composition depth two, feature complexity scoring,
source family and evaluation contexts.
