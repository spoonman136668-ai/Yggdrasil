# WSP-111 — Invent unnamed relation types from observed effects, then compose them twice (synthetic DEV)

**Scope:** isolated research experiment stacked on [WSP-110 draft PR #1075](https://github.com/spoonman136668-ai/Yggdrasil/pull/1075), exact parent `56dba1d4fa6a205788bde635238594935e7ea5de` / tree `0104fc5d61cd76027da1a265f71d3e2b72c19062`. This does not modify Yggdrasil's accepted cognitive architecture or its `main` branch, other research tracks, runner/controller/scheduler, private data, or production. No merging or promotion.

## What is different from WSP-110

WSP-110 directly programmed one million sparse factual weights and two reusable rule operators, but the new *output predicate types X/Y were prescribed*. Its numeric, symbolic, and fully trained conventional learning arms obtained **identical heldout outcomes**. WSP-111 keeps the exact one-million original observed facts yet **withholds the number, names and assignments of the newly inferred relation categories from every learner**.

The new output categories emerge from *intervention effect signatures* (three observable binary consequences in round one, two in round two). The system discovers the classes represented by repeated effect patterns, allocates new numeric relation identifiers as `32+rank` of the discovered effects (or `40+rank` in round two), and directly programs generated relations back into its sparse numerical parameter memory.

**Mechanistic limitation:** the raw source predicate vocabulary and 3-bit/2-bit sensory channels are supplied, and 3,000 supervised intervention response observations provide discovery evidence. Only the *new outcome-equivalent relation categories* are unnamed. This does NOT autonomously discover a wholly unanticipated real-world predicate vocabulary, independently select useful experiments or establish AGI.

## Frozen prereg before all WSP-111 world/learner/test labels

- `research/contrib/chatgpt/WSP-111/prereg.json` committed FIRST as **`06510947aaf34fc0200466c8b5e94ed89cb92542`**, before generator, oracle, learner, independent controls, evaluator or fixture source.
- Input: WSP-110 **raw original facts only** (NOT its exposed X/Y outcomes): **25,000** disconnected three-edge chains, **75,000** original source relation triples plus **925,000** isolated distractor triples = **1,000,000** native-sparse `uint64` parameter keys and **1.0 float32** presence weights, exactly **12 MB** initial factual storage.
- Support: **3,000** groups (IDs 0..2999), all given an observed 3-bit first intervention effect and 2-bit second intervention effect, generated from a hidden causal equivalence-class assignment with deterministic noise (per sensory bit 1/64 flips). Three relevant relation families, first four kinds, middle four kinds, third four kinds; latent first class assignment determined by predeclared SHA256 sorting, **not revealed to models**. First stage has four truly distinct latent effect signatures; the learner does not receive this list. Second stage maps hidden first relation and third relation type into a two-bit consequence, independently with 1/64 sensor flips.
- Transfer: **22,000 new heldout entity groups** (IDs 3000..24999), disjoint named entities from train. The raw input types and hidden laws recur, so this is new-*entity* transfer, not new causal-law transfer. These 22k first/second heldout consequence labels are NEVER opened in fixture regression or training.
- First generation: direct program 16×3 `float32` effect-probability weights from observed support feedback only, using Beta(1,1) posterior means, a fixed strict `>0.5` threshold. Group input relation-pair motifs by *inferred effect signature*, dynamically allocate novel relation IDs and program **25,000** first generation new relational weight keys. Relation type and membership are retrieved from numerical parameters, NOT oracle outcomes.
- Second generation: condition dynamically sized K×4×2 `float32` weights on the **previously inferred and stored first relation category** and the known third observed source relation. Learn only from 3k provided second feedback effects. Invent a new list of two-bit category IDs (number not supplied), and write **25,000** second generation relations as further native weight keys. Stage two must use **the model's own first invented relation**, never the hidden true class, as a causal precondition.
- Every model's full heldout effect signatures (both generations), original million-fact weight hash, both operator weight arrays, both derived numeric relation arrays, and all support observations get SHA256 sealed BEFORE withheld outcome labels or latent class assignments are read. No after-result source, hyperparameter, threshold, seed or support-set changes.

## Independent controls and negative diagnostics

- **Independent symbolic:** a separate 1,000,000-triple Python fact set, independent Python count-based effect reconstruction, dynamic groupings and two-stage inferred relation facts from the identical raw source, 3,000 feedback events, same Beta(1,1) rule. The numeric and symbolic 22k heldout predictions **must exactly agree**, otherwise engineering FAIL.
- **Fully trained conventional baseline:** five separate regularized logistic heads: three input-pair one-hot 16-way first-stage effect predictors and two second-stage inferred-class × third-relation predictors. Uses *its own predicted first-stage classes*, no oracle class values. All five heads strictly converge via reused qualified WSP110 Newton solver (`L2=0.01`, `gradient_inf<=1e-8`, max100 steps). Same 3k feedback labels and original 1m facts.
- **Negative controls:** zero effects/no new relations, and wrong-binding cyclic rotation of the first relation-pair weights and second third-relation bindings. Test effect exact-match accuracy, positive-bit TP/FP/FN/TN and F1, plus permutation-invariant **Adjusted Rand Index** (ARI) for the discovered latent first-class partition. A privileged latent oracle is an evaluator-only ceiling after sealing, never a matched learner.
- **Custody:** original million keys and factual 1.0 weights remain SHA identical before and after both operator generations. Hash-sealed complete cold snapshot restores 1m original keys, original presence weights, both operator tensors, both learned signature maps, and both complete sets of newly inferred relation keys with all 22k predictions exactly identical; tampering with stage2 keys must be rejected.
- **Efficiency and uncertainty:** report end-to-end CPU and wall, total direct and independent symbolic source storage, inferred relation parameter counts, posterior confidence operator sizes, per-arm training/inference and cold cost. No unsupported speedup claim. Distinguish deterministic synthetic effect noise from mechanism uncertainty and true real-world reasoning.
