## Material negative result: role reuse is unidentifiable under this prior

For perfectly established identical historical and new functions, the new function may be explained either by an actual reuse event or by an independent uniform sample that happens to choose the same function. With prior reuse `q=0.5` and 16 functions, the limiting reuse posterior is:

`q / (q + (1-q)/16) = 16/17 = 0.94117647`.

It can **never reach the proposed 0.95 reuse-event certificate**, even with arbitrarily many noise-free matching observations. This is a correct observational limitation, not a failure to retain a matching function. The 12-test gate verified a high-witness numerical case. The readout can still deliver sharply calibrated *functional* probabilities when enough evidence exists, but treating an equivalent function as proof of a shared causal history would be invalid.
