## Hypothesis and freeze

The user-proposed experiment is to load a large body of relational knowledge **directly as native weights**; program and discover compositional association mechanisms; then use those mechanisms to write more new knowledge into the same parameter system and repeat. This experiment deliberately tests the two-round minimum viable form, not AGI.

**Frozen before any WSP-110 implementation:** `research/contrib/chatgpt/WSP-110/prereg.json`, commit `0edfe39ebb7fff603b11e7d94c03e7f2c6ee178b`. No labels from original heldout group IDs 3000–24999 are used for source construction, training, model selection or threshold updates. No post-first-use tuning of generator, priors, regularization, masks, seeds, answer thresholds, support size or split.

## Exactly one million observed relational facts

The completely synthetic original memory contains **25,000 independent three-edge relationship chains** (75,000 original links) and **925,000 unrelated directed distractor links**, totaling **1,000,000 unique source/relation/target facts**. The 925k distractors are deliberately isolated from chain identities. Raw relationship types belong to left `0..3`, middle `4..7`, third `10..13`, distractors `16..31`; **NO** original relation-8 X or relation-9 Y facts exist. Facts are written once into sorted, unique `uint64` sparse associative parameter addresses with `float32=1.0` presence weights. This is genuinely **direct programming of a sparse numerical weight memory**, but it is **not** a dense neural model and resembles a compressed graph indexing scheme: **do not claim architectural intelligence novelty or learned language ability from this representation**.

Every chain is made of four unique opaque entity identifiers. Groups `0..2999` comprise **3000 same-information support examples**; groups `3000..24999` are **22,000 heldout chains with entirely new entity identities**. The two hidden ground-truth rule families are generated by deterministic SHA256 rules **independent of node IDs**: 6 active of 16 ordered (left, middle) relation pairs produce candidate X; then 2 active of 4 third-edge relation types produce candidate Y **only if the true X relation holds**. About 1/32 of groups are unidentifiable exception cases for X, and another about 1/32 are conditional Y exceptions; this prevents artificial 100% accuracy without revealing an exception indicator to learners. All stage labels for heldout groups are only opened **after predictions, operator state, original fact hash and both new relation layers are SHA256-sealed**.

## Program new rules and derived associations directly into native parameters

1. **Program 1 million raw factual weights.** Original `keys[]` (`uint64`) and `fact_weights[]` (`float32`) remain immutable; source hash checked after both knowledge-generation rounds and cold copy.
2. **Discover first compositional operator from support feedback.** For each of 16 possible (left, middle) source relation combinations, use the **same 3000 observed support X labels** to program a 16-float32 Beta(1,1) posterior-mean operator vector directly, **no gradient descent**. Predict true only at `weight > 0.5`. Traverse the million native factual weights, apply the learned operator and **write newly inferred relation-8 (X) facts into additional native parameter keys**.
3. **Discover a second reusable operator from support feedback.** From the same **3000 supervised support Y labels** (with conditioned X-positive examples), program four `float32` third-relation operator weights. To infer relation-9 Y, the model MUST retrieve its **newly predicted X weights** and compose them with a third raw relation — **never** call the hidden oracle X or any withheld Y label. Write resulting Y facts as a second new native parameter layer.
4. **Cold-check the combined knowledge.** Check SHA256 source immutability, exact derived X/Y key arrays and numeric operator weights after a full snapshot/restoration. Tampering with either original or newly induced parameters must be rejected.

## Full-strength and negative controls

- **Independent symbolic model:** a separate Python `set` of the **same one million original observed facts**, with independently programmed per-pattern counts from the **same 3000 support observations**, and two-stage compositional inference. Equality to numerical direct programming means **no superiority** even if both produce many correct inferred associations.
- **Properly trained conventional model:** two genuinely fitted regularized Bernoulli logistic heads using exactly the same support X/Y labels and identical raw facts; 16 input features for stage one, 4 for stage two (conditioned on support's true X), frozen `L2=.01`, exact Newton stationary residual `<=1e-8`, max100 steps, no heldout tuning. Uses predicted stage-one X, **never hidden X**, in stage-two inference.
- **Memory-only negative:** all inferred X/Y outputs false; correct source facts by themselves are not enough for relationship discovery.
- **Wrong-binding negative:** cyclically rotate the learned X pair relation binding and the second-stage third-relation binding; same numeric weights, wrong semantic assignment.
- **Oracle-template upper bound:** the hidden latent law may be reported only as an evaluator diagnostic after sealing, not as a fair control.

**Important scientific limitations:** the family of possible relation types and target X/Y predicates is given to all learners. Support labels are supplied explicitly rather than independently discovered by an autonomous agent. The million original facts are artificially isolated in mostly irrelevant distractors; the model does not discover relation semantics in raw natural language, unknown primitive mechanisms, authentic causal interventions, large-world retention, or an AGI substrate. This research checks whether an *iterative direct-weight knowledge-building mechanism* can work at this scale and whether it improves against independently fitted conventional/symbolic controls. **ENGINEERING_PASS does not imply SCIENTIFIC_PASS.**
