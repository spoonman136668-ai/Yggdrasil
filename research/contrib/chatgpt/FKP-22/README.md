## Why this is the next step

FKP-21 [draft PR #1117](https://github.com/spoonman136668-ai/Yggdrasil/pull/1117) inferred 56/64 previously unobserved source outcomes from an explicit lower-order Boolean basis and retained 64/64 physically witnessed corrections. Its exact symbolic control tied. More importantly, paired laws with **identical public observations** but contradictory unobserved consequences proved that passive training cannot always identify a new relationship. FKP-22 tests an actionable response: **select the most discriminating real intervention before spending the next action budget**.

This is *not* a generic primitive-invention experiment or WSP-120 graph-program growth. [WSP-120 draft #1113](https://github.com/spoonman136668-ai/Yggdrasil/pull/1113) continues independently. The mechanism here is bounded tokenless sparse empirical consequence signatures and source-public physical experiment selection, not named graph operators or transformers.

## Prospective source and comparisons

`prereg.json` freezes source cohorts, exact support law signatures, information budget, full controls, the interpretation of nonmatching observations and a deliberately adversarial prior shift **before source and learning code existed**.

`public_active_source.py` creates a new original, public and reviewer-inspectable causal source. Every physically selected four-stage intervention has a visible binary context and three chosen prior actions. A fourth chosen distractor must be applied before the actual terminal ±1 feedback. There is no public rule-class label, hidden mask, future outcome, or unearned counterfactual. Only **TRAIN-family synthetic source** is accessible. Protected DEV `994500..994531`, reserved TRANSFER `994600..994663`, previous held cohorts and accepted native model remain closed.

First, a common **16 support-world corpus** `994000..994015` is physically observed: each world has 12 observed input/output combinations to fit a base low-degree composite rule, then four additionally witnessed inputs `[0,1,2,7]` to discover correlated deviations. These support signatures are delivered equally to all five policies. The new candidate stores compact evidence tuples without class IDs or preselected named operators, then chooses the next physical experiment by balancing remaining observed evidence branches. An independently implemented **exact Bayesian Shannon-entropy information-gain control** uses the same public signatures and observations. **FIXED_0_1** and **DETERMINISTIC_RANDOM_TWO** choose their two experiments without regard to evidence; a **NO_SUPPORT_ABLATION** receives but ignores the support relations. All five use the same source-public training observations and exactly two intervention queries per evaluation world.

A new set of **16 known-family TRAIN evaluation worlds** `994100..994115` uses different base Boolean rules but the same support correlation family. After two publicly chosen and physically applied probes, each model must predict the two remaining previously unqueried outputs **before** those outputs are physically generated. The pre-action score is the number of correct predictions out of 32 across the 16 worlds—not rewards guessed from private source code. The fully informed exact Bayesian control is expected to **tie**, providing a hard test against unique-native advantage.

A separately frozen **8-world source-safe prior-shift diagnostic** `994200..994207` changes which missing consequences are correlated while preserving the same 12 base-learning inputs. This intentionally challenges whether an information-gain policy trained on earlier correlations becomes confidently wrong. The Bayesian control faces the same shift. The source is inspectable and the shifted worlds are still TRAIN diagnostics, **not** scientifically qualified unfamiliar-law transfer.
