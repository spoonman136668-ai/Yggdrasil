## Why this experiment is necessary

CKAD25-Y #1262 [original negative] confirmed that native tokenless Yggdrasil can **actually acquire a previously unknown C source-conditioned numeric causal memory** and cold retain older A/B, but misclassified outside-grammar D in two of four frozen seeds: novel D Brier **0.40625**, **four confidently wrong** outcomes. Y's posterior and action policy matched exact independently fitted 697-rule conventional Bayes; engineering PASS / scientific DEVELOPMENT_NO_GO.

If D and C give identical witnessed consequences on all 12 training interventions, an inference procedure cannot distinguish them on that evidence. Therefore this gate does **NOT** tweak Y's 0.90 posterior threshold, claim magic novelty detection, copy a new controller, or modify the consumed 68011–68059 results. Instead it executes **two NEW actual interventions on previously unqueried action addresses**, stores the source evidence on the SAME Yggdrasil native checkpoint and checks whether the learned numeric relation is contradicted.

The method is part of `NativeCumulativeLearner`: `validate_causal_source_with_witnesses`, no rival model. It filters already persisted numeric source-weight hypotheses conditioned on both authenticated new outcomes. If none remain, it **abstains p=.5** and records the falsification source in another native slot. If some remain, it uses their exact surviving mixture for the two unqueried answers, but that is **NOT proof that unknown structural alternatives are impossible**. The original learned A/B/C sources and slot0 are never erased, reprogrammed from predictions or silently replaced. Even a positive screen remains ordinary **conventional source-grammar inference**, not discovery of unsupplied causal primitives.
