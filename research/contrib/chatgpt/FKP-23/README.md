# FKP-23 — Contradiction-driven prior repair without discarding older relationships

**Research-only, no native Yggdrasil integration, no protected scientific first-use.**

## Why this study exists

FKP-22 [draft PR #1118](https://github.com/spoonman136668-ai/Yggdrasil/pull/1118) showed that choosing physical interventions improved first-unqueried predictions on a familiar synthetic family (**32/32** vs fixed **16/32**) but tied an independent exact Bayesian control (**32/32**). Under a correlated relationship shift, both fell to **8/16**. Its scored evaluation ran once and printed source-SHA-pinned aggregates, but its original evidence audit failed due to confusing one distinct surviving signature with four repeated support observations; **full per-world archive was not retained**. That source is consumed; **do not rerun it**, change its code or retune its thresholds to create a pass.

FKP-23 tests the next distinct mechanism: **learn contradictory relationships from actual consequences, preserve the earlier ones, and distinguish the two in new worlds without private family labels**. This must not be represented as scientific superiority, unrestricted novel-operator invention, or first-use on genuine owner-hidden law families.

## Preregistration-first and protected boundaries

The **first and sole original research commit** `53185e1e0df4ecb7ce45b57379ded7d387b63a16` froze the hypothesis, source family, all cohort boundaries, intervention budget, strongest independent comparator and full expected results before source, policy, tests, scoring or post-result inspection. Exact parent is FKP-22 qualified draft `65801e5777c9d399cdd49d919bcd4428d3cad951`. Do not edit the frozen prereg after physical evaluation, regardless of outcome.

The new, independently authored source `public_repair_source.py` contains these **synthetic inspectable TRAIN-only** roles. No learner receives a source seed, hidden family ID, private polynomial mask or unrealized future result:

- **16 SUPPORT worlds** `995000..995015`: each provides physically observed residual signatures from `{0,3,12,15}` (four repeats each).
- **8 later UPDATE worlds** `995100..995107`: shifted physical relationships `{0,5,10,15}` (two repeats each). Signatures `5` and `10` are **genuinely new to the previously witnessed support set**.
- **16 fresh SHIFT evaluation worlds** `995200..995215`: new lower-order base-law masks, shifted-signature distribution; each arm must predict an unseen effect after three selected probes.
- **16 separate RETURN evaluation worlds** `995300..995315`: new base-law masks, relationships returning to the original support distribution. This tests whether updating discards old knowledge.
- Original FKP-23 held DEV `995500..995531`, transfer `995600..995663`, and ALL earlier consumed/held FKP sources remain inaccessible.

Every individual intervention consists of a public context bit, three **actually selected** earlier binary actions and a fourth distractor action. All early rewards are **zero**. Terminal ±1 feedback appears only after the last action was physically applied. There is no source oracle, alternate imagined action reward, or model-accessible hidden cohort. Each world starts by fitting the existing independent compact FKP-21 degree≤2 GF(2) basis to the same **12 actual public source interventions**; source-independent learner code does not import this source. The four residual inputs `[0,1,2,7]` may then be physically probed.

## Candidate, controls and causal evidence

`prior_repair.py` creates a bounded **SPARSE_CONTRADICTION_REPAIR** policy. It stores original source-visible signatures, admits a new sparse relationship only after an actually witnessed signature contradicts the prior set, then chooses physical actions that split the remaining supported hypotheses. It retains *all original* and *all new* evidence across a canonical SHA-verified JSON cold checkpoint. It is a compact non-gradient/non-transformer event-relation learner, but its finite four-input residual representation is an explicit **inductive bias**; the experiment does **not** establish general causal operator invention.

The strongest control is **EXACT_BAYES_ALL_HISTORY**: an independent all-evidence Shannon expected entropy-gain implementation, with identical support and update source facts and the same 3-query budget. It is expected to **tie**. **FROZEN_OLD_PRIOR** receives the identical 24 public source records but deliberately ignores the eight new ones, to test shift adaptation. **RECENT_ONLY_PRIOR** receives the same records but deliberately ignores the original 16, to test forgetting. **NO_MEMORY** receives the evidence but discards relationship information, to measure chance performance. Comparators are distinct, source-independent and qualified against the same physical intervention ledger.

The original source run must physically observe **24 prior worlds ×16 inputs ×4 actions = 1,536** source actions once. On fresh evaluation worlds, each of five independent arms receives the same 12 physical base interventions, then chooses **three** distinct physical residual queries conditional on witnessed outcomes, and finally predicts **one still-unqueried** consequence before executing its four physical actions. Thus the prospective total is **1,536 + 32 worlds ×5 arms ×16 inputs ×4 actions = 11,776 actual source-selected actions**. The scored outcome is not allowed to update the model. Every arm's original prior evidence, each chosen action, actual observation, posterior distinct-law count, source trace digest and bitwise cold restoration must be retained.

Preregistered **expected** (not observed) unqueried correct predictions per 16-world cohort:

| Arm | SHIFT | RETURN |
|---|---:|---:|
| Sparse contradiction repair | 16/16 | 16/16 |
| Independent exact Bayes all-history | 16/16 | 16/16 |
| Frozen old knowledge | 12/16 | 16/16 |

**A candidate/independent exact Bayesian tie is not scientific superiority.** The candidate's constrained compositional rule selection, prior novelty detection, and historical retention would be known-family development only. A failure to reach prespecified expectations is a measurable negative to preserve, not grounds for adjusting the source or controls. The 10,000-bootstrap, seed `2323` intervals are descriptive, separately clustered by cohort. Process wall/CPU and per-arm costs are measured but not claims of better general intelligence or native throughput.
