# CSRR-01: bounded causal structural regeneration (development research)

This independent, **non-native**, deterministic source-free experiment tests a public action-consequence hypothesis tournament plus reversible local structural exceptions after a world law changes. It is the first bounded continuation of the RS05 active-probe negative/mixed result; no active selector is duplicated. It tests *storage and recovery of contradictory rules*, not first-use causal discovery in real-world benchmarks.

The candidate begins with a hard-coded `a XOR x` rule. For each observed 3-bit `(action a, context x, context z)` it records at most 8 public mismatch witnesses. If 5 of a minimum of 6 disagree with the old rule, it creates/activates a local exception. When at most 1 disagrees, it revives the old rule, keeping the exception available. This is a constrained hypothesis/routing mechanism, not unknown-category causal law invention.

The harness changes the exception's causal location twice and returns to older rules. It shares identical actions, public contexts and consequences across every compared method. Predicted Brier is scored *before* the actual public outcome is revealed; evaluator-only source probabilities are never input to learners. A deliberate strong symbolic comparator knows the possible exception locations and receives identical observations. Cold checkpoint restore is checked for identical future predictions; tampered checkpoints and label-bearing prediction input are rejected.

**Prerequisite:** the committed `prereg.json` + `study.mjs` SHA must predate the primary study. After prereg commit, run `node study.mjs > result.json` and reproduce in a separate Node process. Do not change thresholds, seeds or control rules after seeing results. Save `result.json`, `provenance.json`, and exact prereg/source Git identities in a later commit.

**Engineering:** isolated Node developer exercise only. **Scientific:** no matched real independent causal families, pretrained donor, unknown mechanism discovery, or native retention qualification. **Deployment:** none.
