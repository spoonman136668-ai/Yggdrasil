## Question and direct weight programming

Can direct source-blind weight assignment recover *unprovided complete* 3-way and 5-way Boolean causal interaction laws from 32 actually observed effects, compared with the strongest unchanged original WSP135 two-pair 17,640-template numeric learner and a fully fitted depth-six conventional CART?

The proposed candidate creates a generic **63-feature raw-input conjunction dictionary**: feature 0 is constant1; feature masks 1..62 are the AND of corresponding raw six input bits (max input degree five). It learns which at-most-three binary coefficients (weight=1) XOR to explain **all 32 paid effect outcomes**. It selects the fewest included terms, then lowest total conjunction degree, preserving ALL equally minimal consistent direct-weight vectors. Predict an unseen x only when every surviving best vector agrees; otherwise abstain.

A **separately implemented equal-information symbolic** solver uses a different collision-indexed search but the same generic primitives, sparsity, simplicity and unanimity rules. Their every output must tie. A tie means NO specifically numerical-weight advantage. Neither solver is supplied the complete family laws, source generator, seed, hidden latent mask or true held effect; the AND/XOR feature primitives and maximum 3-term grammar **are supplied**, so this is NOT autonomous invention of AND/XOR.

## Source-safe fixed protocol

- Eight known worlds 240000..240007: private 2-term XOR (pair conjunction and singleton), sometimes extra constant.
- Sixteen prospective novel 3-way worlds 241000..241015: private three-way conjunction XOR overlapping pair XOR singleton, sometimes extra constant.
- Sixteen prospective rare 5-way worlds 242000..242015: private five-way conjunction XOR pair XOR singleton, sometimes extra constant.
- Eight off-family negative worlds 243000..243007: privately seeded unstructured 64-bit truth table.
- Four same-law new-opaque-ID zero-source-effect cold relabel worlds 244000..244003. All previous WSP and sealed original CausalGym/MDP/DTR first-use data unavailable; all other seeds denied before RNG.

**Exactly 48 new source worlds ×32 unique actual fixed-schedule effect actions =1,536 source effects**, shared with all models. Existing SHA256 WSP135 schedule immutable. 32 remaining typed x are genuinely unseen. The evaluator chooses 16 of those after all 64 predictions are frozen with an evaluator-only per-seed SHA256 sort, identical for every model. Also report all 32 withheld, confident errors, abstentions, each independent world's scores, cold relabels and complete action/provenance digests.

**Preregistered support criteria:** >=10 percentage point future correct-answer gain on **both** novel interaction families over the BETTER of WSP135 original or CART, <=1% candidate confident wrong for each new family, coverage >=85% three-way and >=65% five-way, known score no more than5pp below strongest original, <=2% off-family confident errors, source exact budget, independently implemented symbolic exact parity and 256/256 cold zero-effect relabel prediction identities per method. Any failure = `DEVELOPMENT_NEW_CAUSAL_COMPOSITION_NO_GO`, permanently preserved. No new queries, family exclusions, threshold tuning or rerunning exposed worlds to rescue it.

**Crucial limitation:** optional independent constant XOR can demand four polynomial terms, beyond candidate's <=3-term sparse cap. A rare five-way conjunction may never activate in the 32 observed contexts. Both are deliberately falsifiable limitations; do not hide them or rewrite the source after a failure. Six-bit synthetic AND/XOR rules are not verified causal laws outside this benchmark. Even an accepted engineering result remains development only, and same-expressive symbolic superiority is a distinct claim this experiment does not make.
