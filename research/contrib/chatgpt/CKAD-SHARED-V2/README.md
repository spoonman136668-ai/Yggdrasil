# CKAD-SHARED-V2 — tokenless cumulative causal operator transfer

**Distinct, prospectively frozen, source-free DEVELOPMENT experiment.** This corrects the V1 research limitation: storing independently learned causal laws in separate slots does not by itself teach a transferable causal principle. In V2, sixteen new training worlds share an *unknown action-conditioned context conjunction*, while each world has different private XOR coefficients and bias. The actual shared gate is never passed to the learner; an explicit bank of 15 possible gate structures and 128 local linear/bias combinations is supplied. The shared operator is inferred by marginalizing local coefficients over **real witnessed consequences** from each of the sixteen worlds. It is then frozen before learning any of the sixteen separate transfer, sixteen shifted-family, or sixteen corrupted-evidence worlds.

**What is different from prior research:** WSP149 learned coefficient frequency and gained nothing over no-memory on new worlds. ST7 learned a quadratic map shared by its training worlds and tied an exact conventional learner, while failing shifted rules. V2 specifically isolates operator-level transfer versus a model that gets the *same target-world eight observations*, plus an independent exact symbolic shared-learning control. Identical performance with that symbolic control is not a new mathematics claim. No WSP149 or prior V1 private scoring data is reused as source training.

Native source: `yggdrasil/native_shared_operator_memory.py`; research: `campaign.py` and `prereg.json` frozen **before** implementation at `4e0a135db9efb477d97de9dc638e68e4e1d1c0e0`. Numeric-only candidate bitweights; not a transformer or next-token model. Six public input/action bits, 32 source-pool masks and 32 strictly unseen held masks. FIT worlds 701–716 receive sixteen source-free effect calls each. Evaluation worlds 717–732, 801–816, 901–916 receive eight calls per independently choosing policy. Shifted worlds use a third-order conjunction outside the provided grammar; corrupted worlds flip two initial four observations before true corrective observations. All held outcomes remain unavailable until all arm predictions are sealed.

Arms: shared native active; no-memory on *identical* actions/outcomes; full-grammar active without historical memory; shared memory with own random actions; rotated-prior negative; independent symbolic **same-information shared operator**; and fully trained conventional CART on the same target observations. The independent control must reproduce learned gate support and every prediction. Global memory and 16 previous world readouts remain unchanged after all later worlds, restored byte-exact across fresh process and platforms. All source effects, audit hashes, candidate counts, wrong/confident rates, CPU/wall time and checkpoint bytes are recorded.

Primary frozen threshold: >=10pp shared benefit over same-actions no-memory, paired 95% bootstrap lower>0, >=60% target coverage, zero in-family wrong; SHIFT and CORRUPT wrong among answered <=5%. **If any fails, DEVELOPMENT_NO_GO; do not retune on these source-free worlds.** A favorable result still has `scientific_pass=false` and `accepted_native=false` because the grammar and all worlds are synthetic, with a strong exact symbolic control. No original protected source first-use, deployment, merge, accepted state, new controller/scheduler/runner, or paid API.
