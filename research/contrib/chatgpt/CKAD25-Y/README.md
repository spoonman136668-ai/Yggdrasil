# CKAD25-Y — **native unlabelled causal-state acquisition**

Status: source-frozen research candidate. **No result has been interpreted as scientific acceptance.**

CKAD25-W and -X successfully retrieved some learned causal memories but did **not** create new causal source memories during unknown-world encounters. CKAD35/36 external donor-analogy and active probing missed their frozen gains. WSP163’s separate learned public history regressed under rapid switching. CKAD25-Y tests a distinct change: the **same tokenless `NativeCumulativeLearner`** creates a *new* source-conditioned causal memory from actual unlabelled do-action/outcome evidence, cold-restores it and later retrieves it after other worlds and pressure learning.

## One learner, native writes only from true witnessed source

The new opt-in `incorporate_causal_world(records, source_sha256, source_ref)` uses only supplied source-certified synthetic intervention outcomes, never model-generated guesses, hidden world labels or evaluator-held truth. It computes source-conditional exact fractional likelihood for existing *native* persisted numeric causal committees, with the fixed conventional unknown-world prior p=.5. If some existing committee's posterior exceeds the prespecified .90 threshold it returns the unchanged learner and learned source slot. Otherwise, twelve *genuinely revealed* interventions produce a **new native source slot** using the original `observe(8)+observe(4)+compile_causal_relations` training pipeline. Four insufficient observations only permit recognized recall or abstention, never synthetic new-state programming. An unknown world's supplied three-term GF2 class may be inadequate: zero source-consistent committees are retained and must return conservative half probability, never a confident claim of primitive invention. No existing slot is silently overwritten; old source checkpointer restores byte-exact. This is an **ordinary conventional Bayesian source-memory policy integrated into actual native cumulative training**, not discovery of its own algebra or native scientific superiority.
