## Novelty relative to KNOW13

KNOW13 supplied a numeric public task-phase bit. KNOW14 **does not supply phase as a native input**. A fixed public mode cue `P960` and **four unordered candidate regime cues** `P961`–`P964` are source-visible binary factual attributes. For each seed a hidden generator chooses exactly one cue with a constant value 0 in A / 1 in B; other cues vary independently 8/8 within each mode and task/split. The hidden cue ID is never passed to fitting; knowledge source facts do not contain causal-outcome truth. Actual observed binary action→reward outcomes for both actions on the 32 FIT entities per task are separate source records. The scientific test is whether **witnessed contradictions** eliminate noncausal cue hypotheses when applied cumulatively to a single existing native memory slot.

Instead of fabricating a new accepted learner, run a **bounded four-member temporary hypothesis portfolio**. Each member is the original `NativeContextAccumulator(context_bits=2)`, updated at **address 0** on A FIT evidence and again on B FIT evidence. Public input is `mode_bit | (candidate_regime_bit << 1)`, with the cue numeric bit entirely derived from source-typed Q/P/Q lookup. Update B merges native sufficient constraints rather than replaying A's events. Only an **exactly unique** model that remains consistent with both phases is eligible; 0 or multiple survivors **ABSTAIN**. Once identified, the surviving model's A predictions must equal its prior A readouts after B and independent cold restoration.

## Frozen controls and interpretation

- **Evidence budget:** 1,920 synthetic direct Q/P/Q facts, 384 separate FIT action outcomes, 384 held entity/action outcome forecasts across six task-seed cohorts.
- **Native controls:** full original basis refit on both action batches using same discovered cue, exact original symbolic conditional counts, fully fitted conventional binary decision tree on all three public bits. These have identical disclosed source facts, actions, outcomes and capacity to fit the frozen linear rule.
- **Negative controls:** mode-only outcome fitting (no regime cue), facts-only uninformed 0.5 prediction; zero discriminating cue must reject all four hypotheses and duplicate equivalent cues must abstain, not pick arbitrary first. Conflicting facts, missing records and owner-authenticity forgery must also abstain.
- **Engineering criterion:** three uniquely identified cue roles, nine rejected inconsistent alternatives, native old-A fingerprint unchanged after B and cold, full held coverage, held Brier 0, historical facts preserved, exact pinned archive, qualified dual-OS source/regression/atlas and actual historical compatibility.
- **Scientific criterion:** native beats **every** equally informed fully fitted symbolic, conventional and full-refit baseline by at least 0.01 Brier on independently admissible original-world data with zero retention loss. A tie means **DEV_NO_GO_STRONGEST_CONTROL_TIE**, irrespective of successful synthetic cue identification.

This **does not prove** the native model invents an unfamiliar causal ontology, chooses its own interventions, transfers to real unknown worlds, or adds training to the canonical Yggdrasil model.
