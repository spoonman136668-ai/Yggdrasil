**Difference from KNOW16:** The original real native `NativeContextAccumulator(context_bits=1)` now **learns a utility rule from 36 separately witnessed one-action exploration episodes**, at address 0 across two input batches (16 +20) with `stage_update(max_degree=2)`. Each training episode resets the public four-role candidate set, chooses from a fixed *non-oracle exploratory query schedule*, takes a real synthetic action, receives its consequence, then labels public query usefulness 1 iff that consequence rules out at least half of prior role alternatives. No hidden role labels are supplied to native training; only observed source bits and witnessed consequence-induced candidate elimination.

The native **input feature** is an explicitly engineered binary indicator that the public source query would partition the present role set equally, plus the proposed binary action. This feature is **NOT learned**. The posterior update on observed consequences remains the **same analytic role-consistency filter** used by KNOW16. The only newly learned function is whether this public balanced-cut feature and action are worth querying. This limited experiment does not prove autonomous invention of new interventions or of a new causal state representation.

TRAIN seed A `1301`: 16 single-action witnessed episodes. TRAIN seed B `1403`: 20 more, two batches in the SAME native address with old utility forecasts unchanged and exact cold restoration. There are four support inputs, so both fully fitted exact-symbolic utility lookup and conventional two-input decision tree are strong *equally trained* controls using **all 36** original witnessed outcomes and source features. Analytical oracle provides an explicit upper bound; random/passive and zero-action source-only controls provide negative comparisons.

Every TRANSFER counterfactual world has 16 source-visible probe patterns, 16 untouched held patterns, opaque role-independent entity/object IDs and identical Q/P/Q source for all four hidden causal roles. Each arm chooses at most **two** interventions, sees only its own action consequences and updates its public candidate set. Measure native learned query-selection success on all 3×4=12 held causal roles, query budget/accuracy/cost, and compare to independently fully fitted symbolic/tree/analytic/rand/passive controls. **All** original factual source and Amalgam weights remain immutable.
