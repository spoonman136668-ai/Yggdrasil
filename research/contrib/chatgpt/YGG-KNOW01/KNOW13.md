# KNOW13 — Cumulative causal acquisition in one native slot

**Independent Yggdrasil knowledge contributor; the Unified Causal Intelligence Amalgam Work chat / PR #1278 is sole model coordinator.**

Frozen prereg **before implementation**: `ffc8d9d27b4fe4fd6b9442e76f6364e38c2cb857` with seed cohorts `707/808/909`, comparison arms, retention GO/NO-GO and no source first-use. This is a source-free synthetic trial; not owner-accepted Yggdrasil training.

**Difference from KNOW12.** KNOW12 blind-selected a causally predictive factual attribute out of four candidates but stored A/B in two native addresses. KNOW13 reuses the existing `NativeContextAccumulator(context_bits=2)` API to **update one existing address 0 twice**, first for A then B. The public task phase bit is predeclared; the causal factual role must still be selected from separately witnessed FIT outcomes without passing generator-private roles to the learner. Two source bundles of 256 synthetic typed NKR08 direct facts per seed remain in the original immutable historical image's separate candidate overlay; causal outcomes are independent witnessed FIT records and never inferred from source Q/P/Q edges.

**Frozen trial:** 3 seeds × 2 worlds, 64 entities each (32 FIT, 32 disjoint HELD), 4 candidate predicates, both actions per FIT and HELD entity. Thus 1,536 synthetic direct facts, 384 FIT action consequences and 384 held action outcomes. World A: reward iff action matches hidden mode; B: reward iff action differs. The phase bit is public and means the native XOR-family can represent both worlds in one two-bit context. Its knowledge accumulator merges previously learned GF(2) sufficient constraints rather than replacing A. Exact source and original archived Amalgam state remain unchanged.

**Comparisons:** the same-information native full refit across both batches, independently fully fitted exact symbolic conditional probabilities, fully fitted binary depth-three conventional tree, native replacement-only fit from B, phase-aware action-only, and facts-only 0.5. Measure A-before/B-after/A-return across the identical address and cold restore, source abstention, strong-control Brier and complete process cost. **Engineering PASS** requires six unique blind role selections, zero held native Brier on synthetic XOR, old A readout fingerprint identity after B and cold restoration, 100% original factual recall, immutable source/model checkpoint and exact dual-OS full regression.

**Scientific GO is not automatic:** native must exceed each matched fully fitted strong control by at least 0.01 held Brier on independently authorized original-world data while retaining A.
