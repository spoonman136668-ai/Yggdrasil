## Frozen verification

Replay *exact original* 64 public A/B training observations for each of the three arms, independently cold-restore 2/4 actual C/D/E/F common challenge trials for each of original `mechanical:alpha/beta/gamma` strings and evaluate original 12 x/goal pairs with real actions, maximum two interventions and own consequences: 24 conditions ×12 =288 paired independent episodes **per model**. Fail closed unless all 3 actual achieved rewards AND exact goal success values reproduce original source AAI-11D to 1e-6. The original model `calibration.py` blob `49f7de063e3577ef8f0b4e42043a24581e6cd09c`, original evaluator `dev.py` blob `ce807c4fa3b7742b4299580087dc41b68359533e`, original benchmark and conventional baselines are **UNCHANGED**.

**Private evaluator-only calibration:** At each frozen after-challenge source checkpoint, query each unchanged learner's forecast at all 64 possible public x inputs. Privately compare against known hidden-law mediator truth to measure factual Brier score (lower better), log loss and five fixed forecast/observation bins separately by mediator. Privileged truth is *never* passed to any learner or used as a new training observation, action or policy update. Posterior-only and posterior+risk forecasts **must** match bit-for-bit on all 64 x per condition, or invalidate the experiment.

**First-action risk suppression:** For each independent paired episode, present all three arms exactly the same public start and record the original learner's first ACT or STOP before any intervention. Count `posterior ACT / risk STOP` and the reverse, different first actions with both ACT, and compare the independent actual final reward, goal success and action count. Only for a risk-suppressed posterior ACT, the private evaluator additionally computes whether that first actual do-action would improve reward in one step and whether a *best-possible subsequent second intervention* could have improved reward over STOP. These are retrospective privileged diagnostic values and are NEVER passed to either learner.

The preregistered decision label is `SUPPRESSION_WITH_POSITIVE_TWO_STEP_HEADROOM` if >=3 suppressed first actions and >=50% have useful best-two-step headroom, else `MOSTLY_ACTION_REPLACEMENT` if >=3 differing active first actions outnumber suppressions, else `LOW_POLICY_DISAGREEMENT`. Report **all** measured values, including nulls, regardless of label. Even a suppression count is an explanatory synthetic diagnostic, not proof that changing the action rule would improve independent science.
