# CKAD-PORTFOLIO-V1 — cumulative tokenless causal hypothesis learning

A native, non-transformer **source-free development** mechanism that maintains a bounded portfolio of possible causal expressions as integer hypothesis weights and updates it with actual fabricated action–consequence observations. The model knows the general operator grammar, **not** the chosen world law, family label, private coefficients or held outcomes. Candidate hypotheses are eliminated by witnessed consequences. When remaining hypotheses disagree on a query the model abstains.

This directly addresses the A3 overconfidence/coverage failure, without repeating WSP109's externally supplied 36-labeled candidate laws. Its 1,920 expressions are **still a supplied inductive grammar**, not primitive discovery or general intelligence. The persistent state holds 64 world slots, survives sequential new-world learning without overwriting older slots, and is restored byte-exact in a separate process. All input/action masks are numeric bits, not language tokens. No tokenization, transformer or next-token model is introduced.

The frozen preregistration is `prereg.json` at commit `1a2a5da33e4a743042ff747d67b1363d8b214c2c`. Fixed synthetic cohorts: 32 in-family (701–732), 16 unknown higher-order shift (801–816), 16 initial-label corruption (901–916). Every policy gets 8 identical initial and 8 additional synthetic **do** observations; true outcome/coefficients stay private until all held predictions are sealed. Intervention decision rules are tournament hypothesis-split, two-step expected-version-size planner (stronger control), input-feature rank2 (A2-style), and matched random; also report a fixed-degree A3-style audit and fully fitted CART.

The **frozen primary bar** requires >=5pp tournament gain over both rank and random with lower-bound-positive paired bootstrap, >=60% held coverage and zero in-family wrong. Out-of-class shift/corruption false confidence may fail development acceptance even if in-family gain passes. The independent symbolic expression enumerator must match all 64 native input predictions in every condition; conventional CART gets same observed data. Both platform runs seal source, negative-control proof, checkpoint SHA, wall-clock cost and all failed cohorts. Final exact candidate must pass root regression, NKR-05 and G29 on Linux and Windows.

**No source first-use or original-world interventions.** This is a bounded synthetic causal-program experiment; scientific_pass=false and accepted_native=false regardless of score. No PR, merge, Forge/controller/scheduler authority, paid API, or external workstation required. The owner CKAD02–12 draft PR #1182 remains unchanged.
