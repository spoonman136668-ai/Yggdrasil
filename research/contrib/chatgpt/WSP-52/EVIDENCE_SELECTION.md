# WSP52 — evidence-gated readout (SELFTEST only)

## Scientific status: post-hoc development hypothesis, NOT pre-registered

This diagnostic follows the negative WSP52 direct-writer and fixed order-invariance
SELFTEST results. The selection rule was designed with prior fixture results known.
Therefore testing it on the same SELFTEST seeds **cannot** validate prospective
scientific benefit, and it must not be compared as a new preregistered PRIMARY arm.

Original parent WSP47 9e6374119602ea57e479a1b36a35a5c0e932b4e1 and WSP52
preregistration 8cea083b5c230663b9a9dccfc8089a77f1c4c729 remain unchanged.

## Mechanism and bounded exposure

- Use exactly 36 phase-A acoustic/action observations then exactly 6 phase-B
  observations. Both readouts consume the **same** numerical associations.
- Two supplied candidates: original position-sensitive readout and deliberately
  human-defined, commutative order-invariant readout. Neither is grammar invention.
- After the six B observations, run six leave-one-out folds, each fitting to all
  36 A plus the *other* five B records. Each fold predicts the left-out B
  consequence using each fixed readout, with target used **only for selection**.
  Never use a heldout A/B evaluation target, source hidden roles or grammar.
- Select invariance ONLY if it correctly predicts at least two B experiences the
  slot baseline misses, has strictly more decisive wins than the slot baseline,
  and has zero confidently wrong B validation predictions. Otherwise default to
  position-sensitive predictions. This is source-limited empirical model selection.
- Retain observations for validation and deterministic restore. Charge 42 unique
  environment actions **plus** 246 additional internal writer replay operations,
  12 readout-validation predictions, and full serialized persistence. Do not claim
  matched-compute or matched-capacity efficiency.
- The model is frozen after selection; it cannot use protected PRIMARY or registered
  DEV cohorts through its fixture wrapper. Tests cover abstention, false confidence,
  phase caps, cold restoration, and the untouched phase-A baseline readout.

## Limits

The source's destination/verb meanings are not individually identifiable.
If the selector improves B, it still does not prove that it *discovered*
language invariance: the alternative invariance rule was explicitly provided.
If it does not improve B, preserve this result and prioritize a learner that
discovers transformations causally from new, order-sensitive evidence.

No actual registered DEV/PRIMARY learning, fully trained conventional comparator,
strong independent symbolic comparator, matched computation or scientific
acceptance has been performed. No integration, merge, schedule or deployment.
