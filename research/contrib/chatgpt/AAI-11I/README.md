## Falsifiable causal mechanism

The previous `posterior_planner` estimates public mediator probabilities from the last eight actually observed input/mediator pairs. The common original `controls.plan` chooses a two-action sequence by summing forecasts as if the second action were fixed **before** observing the first action's consequence. But the benchmark executes **real action-consequence learning between the actions**. A first intervention may be valuable because its public outcome distinguishes causal rules and changes which **second action** should be chosen.

AAI-11I's new `causal_feedback_expectimax` arm retains exactly **the same eight observed public rows**, original 45/45/84 XOR/AND/OR grammar, fixed .9/.1 public-likelihood posterior, and original cold checkpoint semantics as the original `posterior_planner`. At the **first** decision only, it calculates the model's own joint probability distribution for each of 8 possible three-bit mediator observations resulting from each of 12 legal first `do(x_i:=bit)` interventions. For every possible observation, it performs an **imagined public Bayesian update on a scratch copy**, correctly evicting the oldest row under the fixed eight-row window; then evaluates the optimal subsequent STOP or one real action using the posterior consistent with that hypothetical observation. It selects the first action maximizing mean terminal reward **after** a possible informative first outcome, against the known current STOP reward. It does not actually ingest, observe, or pay for hypothetical events; after the first **real** causal consequence, it updates only with actual public data and uses the original `controls.plan` unchanged for the final remaining action. Only the first-action policy differs; the representation, storage, prediction, real data, action allowance and observation budget are exactly matched.

The exhaustive outcome branching is model-internal, not a privileged simulator action or scientific oracle. No `world.intermediates`/hidden true-law labels, no `world.exact_oracle` calls in the model, no future feedback or learned donor weights. The evaluator uses true causal laws **only** for retrospective oracle scoring and exact goal reachability, never as learner input.
