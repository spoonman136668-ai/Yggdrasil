# AAI-11H — genuinely independent structural run-length causal posterior

**New, source-only tokenless substrate experiment**, stacked on the corrected oracle-relative [AAI-11G benchmark PR #1070](https://github.com/spoonman136668-ai/Yggdrasil/pull/1070), frozen head `2f1a0d8e73465081d24c8d7364883d9836ba69d1`. The new structural-learning proposal was **preregistered before implementation** as commit `b174bae590f451426b9b4f513ac995989e6f09c0`. All predecessor code/results, including failed 11A/11B/11D and their old impossible 60% raw goal gate, remain untouched.

AAI-11H tests a different learning mechanism: **causal run-length inference under law changes**. Rather than discarding all but the last 8 observations or protecting hard law slots, it stores **only 16 most recent PUBLIC observed input/mediator pairs** and assigns a Bayesian probability to three candidate windows of **4, 8, or 16** observations. Each window fits the same original causal operator hypotheses (45/45/84 XOR/AND/OR), using public observed upstream mediators to score downstream rules, with Bernoulli right/wrong likelihood 0.9/0.1. The new mechanism compares each window's *integrated structural law evidence relative to an independent fair-coin null*, with uniform prior across windows; makes a fully probabilistic mediator forecast by averaging all run-length and operator hypotheses. The aim is automatic context-dependent attention to recently changed intervention outcomes. There are **no hidden simulator labels or teacher counterfactuals**, no transformer or tokenization, and no paid model. Public action consequences provide the learning signal.

Crucially the **`fixed16_posterior_ablation` stores exactly the same 16 rows**, uses the same 45/45/84 grammar and Bayesian hypothesis fit, but applies only the 16-row window (no run-length mixture). The unchanged original `posterior_planner` (last 8 rows) and original strongest `graph_recent8` are independent additional controls. **All four models use the exact unchanged original two-action controls.plan**, only actual self-chosen do-action outcomes for online updates and their own cold independent episodes. A new candidate must demonstrate value from *run-length adaptation*, not simply more public memory or access to private true laws.
