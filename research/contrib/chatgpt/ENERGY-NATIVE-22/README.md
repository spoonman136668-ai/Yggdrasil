## Direct semantic mismatch — integration is not authorized

**The synthetic studies:** Gate21's source creates 5-bit action-context variables `x` covering **32 directly selectable input combinations**, observes a Bernoulli outcome generated by an XOR mask/bias or a nonlinear AND perturbation, and evaluates model change inference after 16 context probes. The representation uses an independent 32-element intervention domain with latent truths known only to the simulator.

**Native Yggdrasil:** The source-pinned interface exposes one `NativeCausalAmalgam.observe_experience(identifier, views, row, *, source_sha256, packet_sha256)` update. An admitted public row is `{s1,x1,s2,x2,y}` with two staged *actions* `x1,x2`, an *observed* intermediate state `s2` and an *observed* reward `y`. Paired public views are each two binary bits and are validated before admission. In `StagedPublicReadout`, `first_action` performs a prediction **before** `observe_transition`, and `second_action` predicts after the visible transition but **before** `observe_reward`. Training occurs only after the final witnessed consequence; no hidden source law is injected.

**Evidence-based decision:** There is **no verified semantics-preserving translation** from arbitrary directly intervened five-bit XOR inputs to staged, externally observed two-action native episodes. In particular **`s2` is an observed transition outcome, not another freely set intervention bit**. Encoding hidden XOR state or source truth into `s2`, reward, or a paired view would change the scientific task and invalidate native action-consequence evidence. The current synthetic gains are therefore **not transferable by direct checkpoint or parameter import** on the available evidence. This is *not* a theorem that no lawful adapter can exist; an owner-qualified native test may define a new valid mapping with original source semantics preserved.
