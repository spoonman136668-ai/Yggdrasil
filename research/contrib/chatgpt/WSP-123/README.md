# WSP-123 — Unknown causal-factor association from action consequences

**Status: isolated engineering development only. No original scientific first-use, native admission or merge.**

## Distinct question

WSP-111 already recovered effect-derived relation categories over one million
synthetic facts but tied symbolic and fully trained controls. ST7 inferred
unknown coefficients inside a supplied quadratic class but failed transfer to
new law families. WSP-121 and WSP-122 found model-class ties against equal
information symbolic systems. All those original or frozen evaluations
remain intact; none are rerun here.

This successor tests a different *mechanism capability*: directly programmed
numerical state discovers per-domain left/right causal factors from observed
consequences, then applies those factors to never-before-seen opaque actions
and entity identifiers. It explicitly tests catastrophic interference across
four separately learned domains and reports a cross-factor negative family.

## Frozen information, actions and controls

Exactly four independent domains, each with eight left and eight right typed
relations, have 64 potential action combinations. Hidden three-bit causal
effect labels follow an unknown `u(domain,left) XOR v(domain,right)`. The
**XOR-separable representation hypothesis is supplied**; the correct factor
values and 64 effect outcomes are not. The engineering source is source-only
`source.py`; neither `weights.py` nor `symbolic.py` imports it.
This is an inspectable synthetic source, not independently sealed custody.

An outcome-free numerical intervention plan queries 15 anchor relations per
domain: eight in row zero and seven remaining in column zero. Those source
effects identify all 64 combinations under the supplied factor family.
Strong independent symbolic graph constraint inference receives the same
15 observations in the same order. A fully competent symbolic passive
comparator gets 15 different, randomly ordered *legal* interventions and
may abstain for unconnected causal factors. Memo-only receives the active
observations but cannot map unseen opaque entity IDs. A no-update control
abstains everywhere. Each arm has an independent source instance and
one-time held-out aggregate scoring receipt; trained conventional comparator
is **outstanding** and required for any eventual scientific claim.

First, four fit worlds use 60 total source calls and score 64 disjoint withheld
pairs. Then 256 unfamiliar-entity worlds (64 per domain) require **zero**
new source calls and score 16,384 held interactions. Finally, 64 deliberate
off-family worlds add a new nonlinear cross-factor interaction unobservable
from the fit anchors; with no new actions allowed the model cannot know it.
The 4,096 off-family predictions must be reported as positive/negative
including confident errors; tuning after seeing these engineering negatives
is prohibited. This distinguishes *within-known-family transfer* from
genuinely unknown-law transfer.

Numerical factor weights: 16 signed int32 slots per domain, 64 slots =
256 allocated bytes **excluding** Python objects, the recorded evidence
ledger, source/score infrastructure, snapshots and whole-process RSS.
All 60 source observations are retained; SHA-256 snapshot digests are
consistency checks, not authenticated independent source evidence. Cold
restoration replays evidence, recomputes direct numerical weights and
rejects both simple and digest-repaired weight forgeries.

## Stop rules

Expected matched numerical-versus-optimized-symbolic prediction parity is
**not unique numerical discovery**. The source's factorization grammar,
three-bit effect width, domain identities and left/right input relation
vocabulary are already supplied. No unprovided abstract computation
primitive has been discovered, and this experiment does not establish open-
ended knowledge, language reasoning, native integration, RSI or AGI.
Wrong confident outcomes on the off-family cohort disqualify any claim of
general unfamiliar-law transfer, even if in-family transfer is perfect.

The original WSP123 123000..123063 cohort and reserved 123800..123863,
plus WSP122/121/120 protected cohorts, remain unopened and unauthorized.
A scientifically accepted next-generation learner would need separately
qualified first-use, stronger causal-composition controls, fully trained
conventional comparison, independent source and data lineage, cost and
memory evidence, unknown-primitive intervention tests, cold retention and
interference metrics, and frozen paired-world thresholds.

The exact preregistration commit precedes code. Final engineering
qualification is the existing branch-scoped GitHub CI, Linux and Windows
at the same final archive tree, including all inherited WSP117–123 suites
and the full repository root regression. No scheduled task, controller,
new runner, paid API, accepted-main mutation, merge or deployment.
