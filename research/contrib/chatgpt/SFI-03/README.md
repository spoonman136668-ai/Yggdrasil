## Actual public synthetic source

New fixed PUBLIC worlds `880300..880331` each contain one hidden combination of four bitwise causal forms (AND, OR, AND-NOT, NAND) and eight XOR offsets. Public actions are 0..7; earned feedback occurs **two steps after** the credited intervention and depends on observable predecessor actions and context. Three consecutive positive delayed consequences produce a real `done=true` goal and the source resets that episode. The private law/shift and action counterfactuals are never included in the six-field public transition.

A complete source-owner geometry check enumerated all **128** `(previous action, older action, context)` combinations against SFI-02's **4,096** old fixed expression programs. **All 32 source laws fall outside that older program class.** This was checked using a reconstructed interpreter whose `_op`, `_catalog` and `execute_program` definitions were cross-checked against the original GitHub file. No source law label was passed to a learner.

The **expanded** microfeedback learner is granted a generic per-output-bit 4-entry Boolean truth table, for 4,096 possibilities × eight XOR offsets = **32,768** hypotheses. It keeps hypotheses consistent with actually earned positive/negative delayed public outcomes and votes on action before its consequence arrives. The separate conventional exact symbolic control receives the same 32,768 possibilities and identical public actions. **This new grammar contains the test source laws.** The result tests induction *relative to the prior grammar*, **not invention of arbitrary operators outside the newly allowed grammar**.
