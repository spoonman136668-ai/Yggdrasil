# CKAD25-AC — Action-identity reassignment falsification of cumulative native intervention learning

**Status: prospective isolated source-only development; no original result yet.** Preserved Yggdrasil's independent nontransformer, nontoken `NativeCumulativeLearner` and prior CKAD25-AB positive development evidence.

## Why this is the next distinct experiment

In CKAD25-AB (<https://github.com/spoonman136668-ai/Yggdrasil/pull/1270>), one authentic source-trained native learner cold retained witnessed causal failures and used them to choose 2 more useful interventions. On 16 frozen seeds with 96 shifted targets, source-history policy detected **75/96** vs fixed **50/96** and random **49/96**, with 21 vs 46/47 confident held errors. Full native Linux+Windows regression 364/364 each passed on exact final `791c67f0afee62a3b9de695277c625783b099da5`. The independently coded **conventional Beta-binomial memory policy tied exactly**. This is real learning of **persistent location-specific anomaly frequencies**, but it is not transfer when a recurring causal role moves to an unfamiliar visible action label.

**This experiment makes that limitation falsifiable without copying any new controller, changing existing native source weights, reusing the consumed CKAD25-AB cohort, or retuning its policies.** We reuse the same native learner/methods and the same independently coded conventional 697+Beta control on fresh frozen seeds. History is learned from genuine source-pinned do/outcome packets and cold restored; target intervention choices are made **only from those previous real action consequences**.

### Counterfactual same-information experiment

Each fresh seed generates A/B/C source functions and trains their numerical posteriors in the same learner. Three earlier worlds provide 2 genuinely observed hidden-change-location action consequences each. Four new visible action addresses remain withheld from initial C source learning. In the target phase, a hidden causal fault **role** either remains assigned to the previous visible identity (**STABLE**), or is reassigned by an **entirely unobserved uniformly random bijection** of the four candidate addresses (**REASSIGNED**). Source C's underlying prediction at every unchanged public address is deliberately kept the same, so this tests **identity of the change location**, not complete causal-action semantics remapping, new grammar induction, causal graphs, language models or unfamiliar physical objects. This is an *adversarial abstraction-transfer negative control*.

Each of 8 future worlds/seed (6 shifted, 2 stationary) is paired across STABLE/REASSIGNED on the same latent changed role and charged 4 actual diagnostic source actions. All five policies pay 2 further genuine unknown-address intervention consequences per world and predict 2 never observed address consequences. Visible fault location, generator-only role/bijection, held target truths and evaluation results are never passed to the model. Hidden permutation does not change any of the first 12 source addresses, so the four common do observations cannot reveal the mapping.

When the new bijection is unobserved, **all 24 mappings are initially equally possible**. Even a fully trained and perfectly remembered nonuniform prior over historical latent fault roles marginalizes to **exactly 1/4 expected fault probability at EVERY new visible address**. A learner that only memorizes old public addresses has no information to prefer a particular new label. The original native source policy is therefore expected **NOT** to transfer; an exact independently recomputed 24-permutation Bayesian marginal is the strongest available same-information reference for this restricted decision problem. Predicting target fault role using its hidden mapping would be leakage.

### Frozen decision

Stable control must reproduce at least +0.08 detection advantage over both fixed and independently seeded random among 96 shifted targets, with zero stationary false contradiction; source/history retention, exact cold restore, original action budgets and disjoint held truth must all pass.

**True transfer** requires that, on 96 REASSIGNED shifted target cases, native detection still exceeds both fixed and random by at least **0.08 absolute** and drops no more than **0.08 absolute** from its STABLE detection rate. This is expected to **FAIL** on causal identifiability grounds (unobserved independently random mapping). If stable passes but reassignment fails, freeze `DISTINCT_IDENTITY_TRANSFER_NO_GO`, not an infrastructure excuse or a threshold retuning opportunity. Both conditions must exactly tie the independently source-trained conventional 697+Beta control; analytic permutation-marginalized Bayes must report 1/4 at each new visible action.

No success can prove general unfamiliar-world transfer or native algorithmic superiority because the source GF2 grammar and latent-role remapping family are supplied. Scientific_pass=false in every outcome. If negative, stop this mechanism and require source-genuine new sensor/affordance evidence to make action identity alignment identifiable before pursuing a more complex architecture.
