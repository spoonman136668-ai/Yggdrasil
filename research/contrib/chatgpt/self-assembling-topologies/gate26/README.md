## Actual cold-restart test

24 new synthetic seeds, 301000–301023. For each seed, three completely separate child Python interpreters run and terminate sequentially: (A) train a fresh native `PublicCausalCells` and persist its versioned, SHA-256-protected **164-byte** checkpoint, (B) restore that file in another process and learn conflicting new action consequences in active contexts while leaving 5 independently retained contexts untrained, (C) restore B in a third process and read actions, Wilson confidence choices and exact integer action contrasts. The independent parent reproduces the *same labeled experiences* without process restarts and demands byte-for-byte and decision-for-decision parity.

In stage A, each of ten known addresses (five active and five retained) sees 24 public outcomes for **each action** (480 feedback events per seed). Stage B changes the preferred action in the five active contexts, exposing both actions 64 times each (640 more). The other six native addresses receive no feedback. A new domain-separated set of withheld outcomes (16 per trained context/action choice) measures whether retained/updated decisions still predict public consequences. The native cells receive only observed address, action and consequence, not the true preferred arm. The untouched standalone source module is a conventional **counter control** with no topology edits.

Independent controls: an equally informed Beta(1,1) action/outcome count rule implemented separately from the native counters, fresh untrained cells, A-only frozen checkpoint, 50% chance outcome baseline and never-observed contexts. No matched-CPU/energy claim; no simulator agent-selected actions.
