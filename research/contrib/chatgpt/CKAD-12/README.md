# CKAD12 — evidence-selected native representation

CKAD11 showed that more native witnessed knowledge did not repair the frozen
strict-gain learner, even though an existing native solver and a conventional
tree solved the unfamiliar majority combinations. That failure stays frozen.

This separate method lets the existing native exact constraint solver choose
the lowest generic polynomial degree consistent with fitting observations.
The class search stops before calibration. A single calibration check must
identify and correctly answer every withheld calibration observation; otherwise
the whole hypothesis abstains. No higher class is tried after calibration fails.
No named relationship family, held truth, original source generator or low-degree
parent coefficients enter the candidate interface. The supplied degree ordering
is an inductive bias, so all outputs remain provisional research predictions.

The preregistration covers204 trials over ALL48 earlier fixture instances and
three original native property worlds: widest exposure first, reduced exposure,
label shuffling, independent exact control, fully trained conventional controls,
memorization, cold restoration and unchanged parent-state checks. Exact controls
and previous failures are reused by matching source/view hashes. Source truth
for scoring is previously consumed synthetic evidence, not fresh science.
