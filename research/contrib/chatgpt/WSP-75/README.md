## Frozen novelty policy and independent controls

For each of four possible action channels at the current physically reachable state, compute *both frozen teachers'* forced four-bit output predictions. Rank actions by the following exact fixed score:

```text
  +8  if (current actual state, candidate action) never physically charged
  +4  if primary predicted next state never physically observed
  +4  if secondary predicted next state never physically observed
  +2  if teachers' predicted next states differ
  +2 / (1 + action count in real Phase B so far)
```

Pick the maximum score, break exact ties by SHA256 of experiment/seed/B-step/action, **execute exactly ONE real action**, pay the actual physical consequence and update observed-context/visited-state sets. No adaptation of score terms after results. Model-predicted novelty is not truth: log actual uniquely encountered input/action contexts, newly visited states, channel counts and CPU.

Independent arms: (1) the exact WSP-74 **max-Hamming-disagreement** policy using the same frozen Stage-A teachers, and (2) a separate SHA-seeded **uniform random** B policy. Each gets its own no-reset paid 48-action future. **Same action count does NOT mean matched information**; evaluate actual paid context diversity and subsequent learning. The physics source function cannot be imported by selectors or neural model.

## Identical direct neural weight edit and strong baselines

- All arms run **exactly unchanged WSP-74** gradientless 4-coordinate ±0.5 hidden ReLU input-weight finite-difference search on their own paid A+B evidence. Eight source-blind candidate hidden neurons are selected from B training residual, then up to four genuinely existing numerical hidden weight coordinates may change. Finally, all actual 144 charged A+B public observations numerically reprogram the four-output neural readout/covariance via recursive-ridge rank-one edits (lambda 0.5). No gradients, symbolic physical rule compiler or uncharged heldout physics, and no additional neurons/capacity.
- Same novelty-arm physical A+B ledger **readout-only refit** with NO hidden coefficient edits, and same-ledger **random hidden-coordinate ±0.5 edits** with identical numeric refit. These distinguish experimental action selection from actual useful representation change.
- Same novel paid ledger **exact state/action memory lookup**, separately fitted depth-four tree, cold neural-only snapshot restore/tamper, frozen Stage-A old-knowledge receipt.
- **Strong independent baseline**: conventional fully trainable 8-input→32 ReLU→4 sigmoid MLP, 3 seeded Adam restarts and max 6000 steps each, using **exactly the same 144 paid novelty-arm observations**. It must reach ≥95% exact charged-training accuracy for a fully trained comparison; report its confidence-gated and forced physical heldout scores, CPU and actual gradient update steps. Fully trained ordinary learning is not dismissed even if its confidence differs.
