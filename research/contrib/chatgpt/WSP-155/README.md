## Exact projection

The caller **declares** which of six raw factors is the action bit and which is an omitted nuisance factor; the code does not choose those roles after seeing hidden effects. The remaining four bits are mapped, in ascending factor position, to a native four-bit context.

Every one of the 64 six-bit masks must have a unique source-labeled *actually observed* outcome. For each of the 16 contexts and two actions, both nuisance=0 and nuisance=1 results must agree. A **single collision is a complete refusal**. A SHA256 trace reference binds both source witnesses, and NKR-04's unchanged candidate compiler stages exactly 32 observed native context/action outcomes to the **existing** bounded numerical/exception memory. There is no accepted-state write and no new memory bank.

The compiled native checkpoint is read back cold. On the fixture's 16 contexts, its witnessed action pairs must match an independently evaluated direct lookup of the original 64 effects; neither the model nor its tests may call the unobserved true law. Checkpoint and witness digests, ignored duplicate count, and all provenance states are explicit. Prior existing native checkpoint updates remain atomic and deterministic; conflicts or corrupted state fail closed.

This is a deliberately **high-information** experiment: 64 source effects are required for 32 native evidence coordinates. Because every six-bit combination has already been observed, a favorable answer here cannot establish unfamiliar causal transfer, low-example generalization, autonomous discovery or unique numerical intelligence. Strong independent symbolic and fully trained conventional *scientific* comparisons remain required for a distinct prospective study.
