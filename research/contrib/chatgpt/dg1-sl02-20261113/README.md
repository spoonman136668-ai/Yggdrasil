## Frozen development result

24 deterministic worlds (eight each A→B→A, stationary-majority, unfamiliar-cubic) with exactly 48 charged physical actions per world. Online and sleep learners received **the same** physical observations. Offline replay was scheduled every eight steps without access to phase labels or evaluator audit values.

Final 64-state/action audit × eight worlds per cohort:

| Cohort | Offline replay correct / wrong confident | No sleep native correct / wrong confident | Conventional online correct / wrong confident |
|---|---:|---:|---:|
| Return A | **161 / 101** | **189 / 79** | **189 / 79** |
| Stationary majority | 363 / 0 | 394 / 0 | 394 / 0 |
| Unfamiliar cubic | 224 / 39 | 163 / 32 | 163 / 32 |

**Outcome: NEGATIVE_DEV / primary NO-GO.** Replay did not improve return-to-A retention, degraded stationary coverage, and increased confident errors. The precommitted online replay control tied the offline learner exactly, preventing an interpretation of benefit specific to sleep timing. This does not refute sleep mechanisms in general: it falsifies only this bounded, deterministic replay repair design.

Source/focused tests: five local tests PASSED using Python 3.13.5 on Linux x86_64. Full inherited regression, independent scientific qualification, and Windows exact-source verification remain separate and are **not claimed** by these local results. The rule grammar is fixed and shared with the world generator; neither novel rule induction nor AGI is demonstrated.
