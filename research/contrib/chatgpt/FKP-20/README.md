## Frozen study, no post-result tuning

**Preregistration was the FIRST/ONLY file in first commit `70f636b34a9ca86b6371068e04c7b0c1368dd62b`**, before this source, learners, strong comparators, tests, or any 16-world score. It locks 16 known TRAIN seeds `992100..992115`, 32 full-factorial exploration episodes plus 16 policy-selected scoring episodes per independent arm/world, **four actually selected actions per episode**, same 32 physical exploration tapes and seed/context schedules, 8 arms, fixed pair hypotheses and feature expressions, logistic convergence and 10,000 paired world-cluster resamples (seed `2020`). Source-protected FKP-20 DEV `992500..992531`, TRANSFER `992600..992663`, original FKP17 held and previous consumed cohorts are inaccessible. No first-use authority is inferred from tools or PRs.

`public_pair_source.py` supplies ONLY physically committed phase0→phase1→phase2→current-distractor phase3 observations. Phases0-2 deliver **zero feedback**; after phase3 is selected, the physical source emits ±1 depending on the parity of **two of the previous three interventions** and current public context. Which two parents matter and their polarity vary by world, but are *not given through the public model API*. The source is transparent to reviewers, so this is **known-family, nonblind synthetic development**, not independent held science. Frozen exploration covers all 2^5 combinations (context × previous three actions × current distractor); distractor has no true effect.

`pair_credit.py` implements a sparse, tokenless, bounded **SPARSE_CONTRADICTION_PAIRS** learner. It initially records source-public unary evidence. Conflicting rewards for apparently identical unary conditions trigger allocation of candidate two-parent interactions across prior action-time positions. Its score arises entirely from matched, physically observed intervention contrasts; it learns which of three predeclared possible pairs, rather than copying the source's private law. FKP18's original `SparseTemporalTrace` verifies the four-step public event order on every observation. No-gradient, no-transformer, no natural-language tokens, <=64KiB conceptual learned-state budget with SHA-verified cold JSON restore; Python RSS is not measured. **This is only selection of a parent pair from a fixed capacity family; arbitrary new operator invention is NOT proven.**

Two independent *strong* informed controls use the **same public 32 exploration episodes**: `EXACT_VERSION_SPACE`, a six-hypothesis discrete symbolic Bayesian-style version-space enumeration (three possible pairs × two signs), and `FULLY_FITTED_INTERACTION_LOGISTIC`, a conventional gradient-fitted nine-feature context-dependent pairwise-interaction model. The logistic must converge to **BCE <=0.05 within 512 frozen epochs** at step size 1; otherwise the result is INVALID rather than a selectively omitted control. Neither may access source-private law parameters or counterfactuals. Four weaker matched-info negatives: `UNARY_ONLY`, `NO_CONTEXT`, `CURRENT_DISTRACTOR_ONLY`, and `TIME_PERMUTED_CREDIT`, plus `NO_UPDATE` to expose trivial reward dependence.

`run_known_train.py` independently resets one physical source per arm/world, logs all actual policy-selected scored action/outcome hashes, checks equivalent exploration hashes, enforces no scoring parameter update, captures exact model state and paired bootstrap with strongest informed comparator reselected **inside each resample**. Measured process wall/CPU and per-arm fit/inference costs are tracked; no claim of GPU/whole-research speedup is warranted. `test_pair_credit.py` and `test_prereg.py` contain source-action and delayed reward negative controls, full-factorial parity, protected seed denial, genuine same-info conventional fitting, candidate cold replay, source independence, private field rejection and original prereg isolation.
