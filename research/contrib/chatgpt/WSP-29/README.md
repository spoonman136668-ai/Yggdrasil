# WSP-29 — actually acquired module composition: frozen hypothesis NEGATIVE

A numerical router learned useful combinations of actually acquired modules and
preserved the base skills. Its unobserved composed outputs were **4,000/5,760**
correct (69.44%), versus **3,740** with composition disabled (64.93%). That is a
**260-answer / 4.51 percentage-point gain**. The frozen primary requirement was
288 answers / five points, so the hypothesis is **SCIENTIFIC_NEGATIVE**: it misses
that requirement by 28 answers. Do not turn this into a pass after seeing results.

Other frozen conditions passed: observed target fit 8,760/9,600 (91.25%, required
90%); all base-bank retention, cold restoration, same-evidence and symbolic checks;
competitive heldout accuracy versus both genuinely trained reused-feature controls.
The result is useful partial evidence, not independent SCIENTIFIC_PASS, general
intelligence, complete training or a universal advantage over gradient learning.

All **5,880 gradient fits converged** at the frozen BCE<=0.01 threshold: 120 source

observed target label, while the native restricted language does not. Its better
heldout score here reflects this finite representation/prior comparison, not proof
that conventional training generally fails. Symbolic selection ties exactly.

## What was learned and retained

All 120 actual WSP28 error-routed circuits were reconstructed and matched their
original checkpoints, including all **13 imperfect modules**. No perfect functions
were substituted. Sixty adjacent within-seed pairs form two-module banks. Each
module is a 75-binary-synapse generic NAND graph. Its six actual source observations
are fixed; all 16 possible completions of the pair's unobserved source labels are
included in the evaluator, along with two composition recipes: 1,920 worlds total.

The learner receives the acquired weights and five actual raw target examples.
It never receives the true source completions, recipe, function name or target ID.
A supplied two-stage language permits 12 routings: choose an inner module, an outer
module, and which raw input is replaced by the inner output, including self reuse.
Numerical score and first-winner threshold gates write the seven one-hot route
weights. This learns a composition **instance** inside a supplied language; it is
not invention of a new primitive, unconstrained program or arbitrary architecture.

The same input evidence gives the same predictions under every hidden completion
and recipe, verified in all 1,920 cases. An evaluator-only evidence-group upper
bound is 4,672/5,760 heldout answers, exposing unresolved information ambiguity.
It is a bound for these authored correlated fixtures, not a general-world theorem
or a source of training labels. In particular, missing source knowledge and the
limited routing language can both limit composition; this assay does not isolate
which explains every remaining error.

All 1,920 native banks retained their bytes and all 30,720 base predictions. Every
native checkpoint cold-restored byte-exactly and reproduced all eight target
outputs; the disabled arm also passed 1,920 cold/base-bank checks. This is retention
of base skills. There is only one current composed head per case: retention of
multiple earlier compositions, discovered context routing and lifelong task memory
are **not** demonstrated. WSP17's supplied task-key bank is not silently treated
as learned task discovery or a solved successor.

## Cost, capacity and controls

The native inference state has **158 binary task scalars**: two 75-synapse banks,
seven route bits and one occupied bit. Twelve route descriptors add 84 supplied
static bits, plus the generic Python numerical VM/learning/serialization program.
Native target learning uses zero continuous gradient updates; it scores all 12
configurations on all five actual examples: 460,800 graph forwards / 2,764,800
NAND evaluations over the assay, before inference/cold/retention checks. External
source/target examples and transient scoring work are not free persistent memory.
One canonical native checkpoint is 1,533 bytes; retained Python model size up to
3,510 bytes. Python object/VM overhead is larger than a packed 158-bit state.

The lesion has identical capacity and scoring, but its injection is disabled, so
it can select a single stored module without nesting. All four graph evaluations
still execute per prediction. The exact symbolic baseline uses the same learned
modules, information and 12 configurations, with independent host selection.

Gradient models actually optimize their weights from actual observations using
frozen full-batch Adam. Both reused-feature heads have 20 floating weights and
include eight raw one-hot features, ensuring representable interpolation. The
shared-feature head uses the same native banks; the fully conventional arm trains
its own eight-logit sources on identical six-label observations before generating
composition features. The raw head has eight weights and no reuse. Same information
does not mean equal capacity, inductive prior or optimizer cost. Adam moments,
feature tables, dot/gradient multiplications and actual update counts are disclosed
in `result.json`; transient feature caches are up to 3,520 Python bytes. Predictions
round logits to 12 decimals before the fixed >=0 readout, without rounding updates
or loss. Floating losses need not be bit-identical across operating systems.

The first complete local assay took **50.55s**, including 25.02s native source
reconstruction, 0.26s gradient source training, native/lesion routing, all genuine
heads, feature extraction, serialization and retention checks. Per-arm timed
sections exclude shared validation/serialization overhead, which is included in
the whole assay. These are not comparable full-pipeline speed receipts for each
method. Peak RSS/energy are unmeasured. There is no general efficiency claim.

## Custody and reproduction

`result.json` preserves the complete first result, including all 1,920 per-world
traces. `modules.json` preserves all 120 actual acquired checkpoints. Candidate
checkpoints contain no world identities or truth tables; IDs in these evaluator
evidence files are not supplied to learning. `provenance.json` pins source/data and
prior checkpoint identities. Earlier experiments and all their negatives remain
unchanged.

from the console summary and receipt to avoid printing it twice. The complete

## Next discriminating question

The measured composition benefit is real on this cohort but below the frozen five-
point target. A new experiment should distinguish insufficient source knowledge,
route ambiguity and limited composition language before increasing capacity or
claiming lifelong learning. It must preserve the imperfect-module cohort, strong
converged controls, uncertainty and whole-process costs. No successor has run here.
