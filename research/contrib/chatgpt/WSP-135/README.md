# WSP-135 — exact 32-intervention causal identifiability preflight

This is **an information/experimental-design diagnostic**, not a direct-weight learner, scientific first-use, native deployment or proof of general intelligence.

## Why this is different

WSP-134's generic integer-weight causal graph retained its state but made 400/1,024 confident errors on unfamiliar compositions. That result also exposed an intervention-visibility mismatch between the prereg and implementation. WSP-80 and NKR-15 already researched contradiction-triggered repair, causal intervention histories and conservative unsupported predictions. Rather than duplicate them, WSP-135 asks a prerequisite: *would any source-informed ideal observer have been able to identify those unknown effects from a 32-query budget?*

## Frozen before code

The isolated first commit contains **only prereg.json** and fixes all development seed bands, method, score thresholds, source API and scientific classification. The exact parent is the WSP-133 qualified research SHA c33f8dc10f9b2bfe809d6e2f75d0dbb770fb1d7d. Accepted main remains unchanged.

Sources are fresh public synthetic worlds: 64 known (178000..178063) and 32 unfamiliar (179000..179031). Source-only two/three-stage Boolean operations use hidden permutations, pairwise gates and majority compositions. The oracle is given the **entire general grammar** but is never told which particular world, hidden roles or gate labels generated the effects. All public six-bit candidate actions **and their opaque IDs are available before selection**; consequences are revealed only after a paid query. No contradiction with the source API.

Every arm gets 32 paid effects per world, leaving 32 held. The adaptive oracle chooses actions maximizing candidate-class disagreement. Fixed32 and independently seeded random32 oracles use the same full general source grammar, and NO_UPDATE abstains. The oracle can release a withheld prediction only if every candidate still consistent with the 32 real effects agrees. A separately implemented scalar evaluator must match the bit-parallel oracle's complete hypothesis bank.

## Frozen gates and meaning

**Identifiability under supplied grammar:** adaptive oracle must uniquely predict >=95% of withheld effects in **both** 64-world known and 32-world unfamiliar cohorts, with 0 confident errors and all 96 real hidden laws represented. If not, the budget and acquisition policy are insufficient to identify the family even under this strong prior. If it does pass, that is a positive **information sufficiency** finding, not learned representation, task-general causal discovery or numerical-weight superiority.

**Active selection value (separate):** adaptive oracle must uniquely determine at least 5 percentage points more unfamiliar effects than the better of fixed32 and random32 under the same actions budget. This can FAIL even when information sufficiency passes; preserve both decisions.

Archive known/unknown correct, errors, abstentions, remaining candidate counts, fully charged source query receipts, cross-platform SHA-256 digests and CPU/wall/traced-memory resources. No retuning of WSP-134 scores and no source-first-use, native model, scheduler, accepted main, paid API or independent cross-project modification.
