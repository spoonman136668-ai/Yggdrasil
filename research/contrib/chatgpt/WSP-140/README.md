## Bit-parallel mechanism

The WSP-137 generic latent prior enumerates **17,640** two-pair structural hypotheses and prioritizes them in SHA256 rank order. Each hypothesis maps each of 64 typed public interventions to one of 16 latent output cells.

The new selector constructs **64 × 16 rank-ordered bit masks** once from immutable public structural templates: a mask bit is set for hypotheses that assign a particular public input to a particular latent cell. For any two already observed action outcomes with opposite signs, candidates assigning them to the *same* latent cell cannot be correct. Compute an integer-wide conflict mask as the OR of the 16 same-cell mask intersections. Update the surviving candidate bitset with a bulk bitwise AND-NOT operation. There are no source-class-specific hypotheses or missing primitives added. When selecting a new action, enumerate precisely the SHA-ranked first256 survivors using lowest-set-bit operations, reconstruct only their ledger cells from **actual previous public effects**, and apply the **original WSP-137 candidate-vote/unknown, tie-break, first four, fallback**. The original downstream WSP-135 numeric fit, prediction confidence, canonical learned snapshot and public effect receipts are reused unchanged.

Source-independent mask creation is included in the **optimized candidate's first timed selection**, and the cached masks and pair-intersections are included once in candidate structural memory accounting. The original common generic bank is shared and not misleadingly charged solely to the candidate.
