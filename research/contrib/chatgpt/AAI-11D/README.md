### Falsifiable question

AAI-11C reproduced the original reward gap: the previously proposed intervention-contrast learner scored 2.084722222 versus qualified `graph_recent8=2.134027778`, while a privileged perfect causal forecast supplied to the **unchanged** common planner achieved the exact oracle 2.448263889. This suggests inaccurate/overconfident causal forecasts or decision calibration, rather than search horizon, is a useful new falsifiable direction. The research does NOT claim that any alternative will improve learning or transfer.

Two independently frozen new arms use the exact *same* last-eight public input/mediator observations and public 45/45/84 XOR/AND/OR grammar as strong `graph_recent8`, with the same 64 common initial A/B training observations, 2/4 exogenous real do-action challenges, independent 0–2 consequential do-action episodes. They differ only in decision calibration.

The **`posterior_planner`** arm predicts each unseen mediator from the uniform-prior, mismatch-count weighted graph posterior with public Bernoulli(.9) rule likelihood and exactly the original AAI-11P `controls.plan`. The **`risk_calibrated_planner`** arm uses the *identical posterior* and two-action exhaustive search but subtracts **0.5 × sqrt(sum of p(1−p))** from the expected terminal bit-matching reward for epistemically uncertain interventions; STOP always uses the true public current reward. Both are tokenless compact causal-graph computation, not pretrained donor weights; the posterior arm is a matched conventional control to isolate any benefit of risk. No true-law label, private oracle action, unchosen outcome, extra observation, higher action budget, paid API or new model pretrained data enters a learner.
