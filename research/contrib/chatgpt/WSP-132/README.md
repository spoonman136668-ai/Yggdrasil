# WSP-132 — bounded confidence repair R1 after WSP-131's preserved negative

**Source-safe public synthetic DEVELOPMENT only. PR #1169 proposed bounded repairs
but is not merged; this contribution uses a fresh preregistered successor
rather than pretending that an unmerged policy authorizes scientific changes.**

## Why

WSP-131's frozen parent, [draft PR #1167](https://github.com/spoonman136668-ai/Yggdrasil/pull/1167)
at `bee103460bb4bd9591a07694ee71d33d34ba922a`, recovered **14,336/14,336**
familiar variable-permutation effect predictions and preserved old learned weights.
But it predicted **240/7,168 unfamiliar GF2-shear effects confidently wrong**
(3.348%) and rejected only **28/32** incompatible worlds. That scientific
failure stays recorded. A frozen result must not forbid future bounded repair.

This experiment asks whether a **source-blind confidence-release revision**
can reduce the genuinely wrong predictions, without extra data, abandoning
useful familiar effects, overwriting accepted knowledge or inflating claims.

## Before any new source or outcomes

The first WSP-132 commit contains only `prereg.json` at

most THREE targeted experimental algorithmic edits under this successor's
declared envelope. WSP-131's exposed cohort is **diagnostic only**; new
target seed bands are independently frozen for **prospective public synthetic
development testing**, not external scientific first-use.

The edit does NOT change existing WSP-130 coefficients, WSP-131's 720-bit
permutation learner, its original intervention selection, original score,
existing source files or thresholds. The 32 paid consequence calls per world
are identical, with the repair performed after source acquisition.

## The repair

The previously learned causal truth defines a readout under every one of
the 720 known six-role permutations. WSP-131's numeric binder eliminates
incompatible permutations using 32 paid effects. WSP-132 adds **21,600
candidate one-shear alternatives** (720 permutations x 30 invertible one-bit
linear shears) as a separate confidence ledger. Every alternative is
tested against the SAME 32 independently paid observations, without hidden
source labels. Only effect values shared by ALL surviving pure+shear candidate
readouts are released confidently; otherwise it abstains. With sufficient
evidence, it can infer a reliable unfamiliar shear readout, not merely veto
predictions.

Because the actual source perturbations belong to this supplied
permutation-plus-single-shear grammar, source-consistent unanimous
predictions cannot contradict the true rule on either family. This
conditional guarantee DOES NOT apply to unmodeled causal relationships or
truly unknown environments, and the model does NOT invent the shear
primitive. Empirical *coverage* and cost remain the decisive tests.

## Equal-budget controls and scoring

- **Original WSP-131 numerical** and separately implemented exact symbolic
  permutation learner; both receive the same 32 charged consequences.
- **Numerical R1 confidence repair** and **independent exact symbolic R1**
  each enumerate the 720 pure + 21,600 single-shear alternatives in
  independently written code, using the original same information.
  Every decision on every withheld case must agree.
- **Optimized fixed 32-action symbolic** comparator; its probes are
  source-blind and billed exactly 32. A fully fitted deterministic CART
  baseline receives the same active evidence; a no-update arm abstains.
- Old WSP-130 causal knowledge is **relearned from 8,192 actual paid
  consequence observations** once per study, never initialized from
  hidden source masks. Its full 64-law snapshot and readouts must remain
  identical; repaired states must be reconstituted from authenticated
  actual source receipts, and forged weight states rejected.

Two cohorts are deliberately separate: WSP-131's **exposed** 64 familiar +
32 shear worlds are exploratory repair diagnostics, not independent evidence.
The **new prospectively frozen** 64 familiar +32 new shear worlds use
WSP132|MAP SHA256-seeded hidden role assignments and fresh 256-opaque-subject
views in disjoint bands 165000..165063 and 166000..166031. The source
does not reveal conditions or solutions to models. The first 16 prospective
familiar worlds are re-presented under fresh opaque IDs with **zero
consequence calls** to test cold readout stability.

The precommitted prospective success gates (from `prereg.json`) are:
**>=95% correct and ZERO confident wrong** across 14,336 held
familiar effects; **<=1% confidently wrong AND >=25% genuinely correct**
across 7,168 unfamiliar-shear withheld effects; zero-source re-label transfer
**4,096/4,096 correct**; all original knowledge and exact symbolic
decisions retained. A gate that avoids errors just by always abstaining
is a FAIL. Independently qualified trained conventional deep baselines,
genuinely foreign causal grammars and whole-process energy parity remain
outstanding.
