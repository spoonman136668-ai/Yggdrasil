## Source-free interface and frozen development rule
See [identity_gate.mjs](identity_gate.mjs) and [focused fixture tests](identity_gate.test.mjs). The utility itself **does not load donor weights or data, invoke a teacher, execute environments, train native Yggdrasil, or perform model checkpoint writes**. It takes externally supplied probabilities from already-authorized frozen predictors:
- `raw` = frozen raw-identity recipient prediction, `donor` = independent frozen donor-feature recipient prediction, both probabilities in [0,1].
- `key` = audited, pre-action, public-context bucket; `id` = unique source witness identity. Labels `y` appear only in designated FIT and VALID rows, not in prediction-time observations.
- Required disjoint partitions: `FIT`, `VALID_OLD`, `VALID_NOVEL`. Duplicate row IDs, out-of-range probabilities, malformed keys, wrong splits and invalid binary labels fail closed. A future source owner must independently enforce source identity, time-consistent observations and cohort separation: caller-supplied `split` strings are **not proof** of custody.
- Up to **16** correction cells, ordered by descending FIT row support then lexical key; each shift is `clip(sum(FIT_y - FIT_raw)/(count+20),-0.1,+0.1)`. No donor or validation labels are used to fit corrections. Unknown keys have shift **zero**. No adaptive repetition or post-result parameter search.
- Candidate probability is `clip(raw + capsule[key] + gamma*(donor-raw),0,1)`; gamma candidates `[1,0.5,0.25]`. For each gamma, require **VALID_OLD** Brier drift vs raw no greater than `+0.02`, **VALID_NOVEL** improvement vs raw at least `0.005`, and donor incremental gain vs *raw plus the same fitted capsule* at least `0.002`. Choose the lowest novel-validation Brier among passing candidates, tie-breaking toward smaller gamma.
- **Atomic reject**: if none passes, return gamma **zero** and an **EMPTY active capsule bank**. Keep proposed capsules only for developer diagnostics, never attach them to the accepted predictor after rejection. Unseen context with no active correction reduces exactly to the unchanged raw probability. Independent previous native state remains untouched.
- This utility has no authenticated checkpoint envelope or independent novelty verifier; those remain obligatory before native use. `VALIDATION_ADMITTED` means **only this development rule passed its own validation data**, never scientific promotion, benchmark acceptance or owner approval.
