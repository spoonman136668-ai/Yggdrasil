## Fair public evidence and action protocol

Training consists of 16 actual one-action trials under A, then 16 under B. Each trial yields a public pre-action state and the public consequence of one actual do-action. All actors receive the **same 64 rows** without a law ID or transition-boundary label. After B, every learner creates a canonical frozen checkpoint. Each A-return, B-hold, unfamiliar C and unfamiliar D branch cold-restores an **independent** model and sees the **same** 0, 2, 4 or 8 common exogenous do-action trials (2 public rows each) before evaluation. No operator labels, hidden simulator formulas, oracle calls or unchosen-action outcomes are exposed to a learner.

Each evaluation context is an independent episode starting from the challenge checkpoint; a learner sees its own real public initial observation and can make zero to two interventions, learning only its *own* actual consequence before deciding a second intervention. All methods have identical action limits and initial observations, but action-contingent experiences legitimately differ. The 16 selected x/goal contexts are unique per evaluation condition. Since there are only **32 possible (x,goal) contexts**, “held-out” here means evaluation namespace and separate cold fork; it does **not** guarantee no overlap with training input/goal combinations. This finite benchmark **cannot alone establish open-world AGI**, and oracle headroom vs wrong stale policy is not evidence of headroom over best trained conventional controls.

The **one-slot** AAI-10C ablation uses its original immutable 96-row model cap. Its maximum evidence per episode is 64 training + 16 challenge + 3 own evaluation rows = **83**, so it is no longer deprived of observations as in the AAI-10C 128-row mechanical speed test. No extra training budget, oracle label or privileged counterfactual is allowed.

Negative control uses *pairing corruption*: on independent challenge trials, cyclically swap only public post-action mediator outputs across distinct contexts, keeping the mediator-output multiset, action states and number of public rows constant and recomputing public reward. This is a deliberate, clearly labeled **broken x→outcome association**, not a physically self-consistent simulator rollout or an alternate causal law. Only the challenge evidence is corrupted; evaluation outcomes remain actual simulator consequences. This is diagnostic for learning real causal associations, not by itself a novel-transfer gain.

## Frozen scoring and no-leak guards

A separate primary cohort executor must collect terminal public reward and two-goal success for C/D at N=2,4, return A and hold B, 64 world-paired TRANSFER cases, plus 32 NEGATIVE cases and independent whole-process cost and peak memory. Select the strongest of the **seven fully trained eligible conventional controls by achieved C/D reward**, not by being an easy baseline. Bootstrap over complete world IDs, 2,048 draws and fixed seed 39092. Candidate-superiority requirement is >=+0.08 reward with 95% paired lower bound above zero; compact versus **full-budget one-slot** >=+0.05 lower>0; oracle headroom over strongest >=+0.15 lower>0, plus strongest below 95% max reward. Unfamiliar exact goal success >=0.80; return-A and B-hold both >=-0.02 vs strongest; preserved A-slot retrieval >=0.60; clean-vs-corrupt negative >=+0.10 lower>0; whole-process candidate <=2× fastest matched. If any relevant rule fails, **NO PROMOTION**. `classify_primary` is only a transparent mathematical score helper and explicitly returns `SUMMARY_ONLY_NOT_QUALIFIED_SCIENTIFIC_RESULT`; it does not run or qualify science cohorts.

All source-only tests use **only** `handcrafted:one` and `handcrafted:two` mechanical fixtures, no reserved world seeds. Both run public-only methods and controls, cold checkpoints, actual actions, negative perturbation, non-contaminating independent forks and bootstrap test arrays. Their outcomes are **never** interpreted as scientific evidence.
