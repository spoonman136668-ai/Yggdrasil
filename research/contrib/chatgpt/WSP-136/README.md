# WSP-136 — same-world causal-grammar oracle versus source-blind learning

**Public synthetic diagnostic only; not native Yggdrasil scientific first-use or general intelligence.**

## Why this is the next gate, rather than another solver

Two independently developed experiments both used the label "WSP-135" but examined **different** things:

- [PR #1179](https://github.com/spoonman136668-ai/Yggdrasil/pull/1179) established that a **privileged exact oracle supplied all 7,062 candidate causal truth tables** can infer the original heldout effects in its distinct synthetic worlds; that does not measure how a new operator would be learned.
- [PR #1180](https://github.com/spoonman136668-ai/Yggdrasil/pull/1180) built a **source-blind numerical latent-factor learner** and independently coded equally expressive symbolic control, achieving strong but incomplete confident coverage in its distinct worlds; symbolic tie blocks numerical superiority.

**Those two historical score sets cannot be subtracted** to infer how much information versus representation learning limits the system. WSP-136 is a new fixed-cohort SAME-EVIDENCE comparison to make that gap measurable.

- Source-blind candidate is **unchanged** pinned WSP135 `LatentInducer`; equal-knowledge independently coded `ExactSymbolicFactor` and fully fitted greedy CART are imported unchanged from qualified WSP135 branch files.
- Privileged `oracle.py` is **an exact copied Git blob** from PR #1179 at source `0102bb52a9d48fbdfff421682212f3cca46e25cb`, SHA (blob) `8a3b7f350608884bec4524b8acb9a55f0c69e20a`. Its supplied complete causal grammar is unavailable to the learner and is **not** an equally informed control. It receives no true per-world law identity/seed and makes no additional actions.
- Source-only membership checks after evidence: each actual source law must be an oracle candidate; full bank size 7,062 and cold receipt replays required. New identity views make no source calls; exact source-blind readout identity and full trained state cold restoration checked.

## Frozen interpretation

**Information sufficient under full grammar** requires >=95% correct held outcomes and 0 wrong-confident separately for known and unfamiliar world groups on the *fixed common action schedule*. The result cannot be extrapolated to every intervention policy.

**Development representation gap closed** requires the source-blind learner to achieve >=95% of privileged oracle's unfamiliar correct predictions, <=1% confident error, cold retention, equal-symbolic parity and all custody checks. Report oracle minus candidate on same source, group by group. A fail is a preserved negative; no post-result tuning of this cohort.

Neither development outcome proves inventing an unprovided causal primitive, native Yggdrasil science, or direct-weight superiority over the equally informed exact symbolic control. The oracle is granted stronger structural prior by design. A genuinely novel causal mechanism not representable by either supplied basis requires a future, independently sourced experiment with owner-qualified first-use custody; that authority remains absent.
