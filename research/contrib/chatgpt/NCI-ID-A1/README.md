# NCI-ID-A1 — Cached-witness structural identifiability

**Independent source-free engineering diagnostic; not a new learning model.** The parent CKAD-12 and CKAD-09 original results are frozen. This branch tests 24 previously consumed native-witness instances (12 higher-order and 12 lower-order controls) at observed-evidence budgets 384 and 512, with generic degrees 4 and 5. It enumerates 1,536 not-yet-witnessed **input masks** per case to count structurally identified outputs; **no held outcomes are read and no interventions are performed**. Prospective masks are only input-rank suggestions.

Explicitly limited: even if complete degree-5 basis remains underdetermined, an appropriately grounded sparse-prior learner may predict more. Model-class consistency, rank deficiency, and data identifiability are different from causal truth and general intelligence. No scientific pass, acceptance, owner first-use, original source generator, new model training, or new source effects.

Frozen source preregistration: `prereg.json`. Reuse CKAD-08 sealed native checkpoints, with 512-row identity verified against CKAD-12's existing 48 pinned full-view receipts, and never import a source generator. Fail on any source/receipt drift.
