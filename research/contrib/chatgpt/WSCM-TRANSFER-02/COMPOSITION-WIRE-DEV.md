## Mechanism

The native learner already has `observed_external_fixture_value(view, external_action_id)`, returning a bit only after all four binary input conditions are individually witnessed. The research readout queries two such **completed primitive signatures**, then filters four *predefined* possible feed-through wirings between their stages against 2–16 caller-provided public intermediate-view traces. Only **one** consistent wiring and an **unwitnessed** query produce `HYPOTHESIS`; otherwise it abstains or rejects inconsistent inputs.

The trace source IDs are syntactically pinned but **not independently authenticated chain receipts**. Neither the library nor this readout establishes that an observed intermediate view arose from a controlled sequential intervention. The readout uses a **known four-wiring grammar**, not autonomous discovery of arbitrary causal structures. The strongest equally informed symbolic control has the same prediction on the development fixture. No new unseen action ID is learned without sufficient public evidence.
