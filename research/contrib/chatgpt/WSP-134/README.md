# WSP-134 — Generic compositional causal structure induction

**External, source-safe development only.** This experiment is deliberately not native Yggdrasil qualification, original scientific first-use, or proof of an AGI mechanism.

## What is new relative to WSP-133?

WSP-133 identifies a hidden member of a supplied set of 22,320 variable transformations. WSP-134 tests source-only two/three-stage causal compositions whose *specific operations and wiring* are not provided to the numeric learner. It grows an integer-weight binary split graph directly from actual action consequences, rather than receiving a hand-enumerated candidate list for the world.

This **does not** mean inventing a new mathematical primitive: generic Boolean inputs, integer split nodes, confidence-by-leaf-support and a universal decision-tree representation are supplied. The new majority-gate source family is excluded as a named model primitive, but is expressible by the generic graph. Identifying a source-unknown composition must not be relabeled "unsupplied computational primitive discovered."

- Each model is charged exactly 32 effects per target world, leaving 32 unqueried effects. Each transfer view has 64 predictions, **zero** new effects.

- The learner never imports the evaluator or receives seed/family/wiring/gate labels. The visible object has opaque IDs and the corresponding typed six-bit input.

## Compared methods

DIRECT_GROW dynamically allocates integer-weight split nodes based on source evidence and chooses each action from public graph uncertainty and separation from previous queries. INDEPENDENT_SYMBOLIC separately computes a generic symbolic split graph on identical observations and must make identical choices and withheld predictions. FULLY_FITTED_CART uses a depth-six greedy conventional tree fitted until no beneficial split remains from the same 32 effects; records remaining training error. FIXED32_DIRECT uses 32 deterministic source-blind interventions in an equal-cost arm. NO_UPDATE abstains.

**Critical caveat:** Fully fitted greedy CART is a legitimate conventional tree control, not an independently compute-matched, fully trained deep model. Numeric/symbolic parity proves no unique numerical representation superiority. No independent unknown-world or real-world scientific acceptance can be granted by public synthetic development.

## Decisions, retention and failures

Frozen familiar correct coverage >=65%, unfamiliar correct coverage >=35%, unfamiliar confidently wrong <=15%, no old-world output drift, 1024/1024 identical prediction transfer across opaque identifiers with zero effects, independent symbolic parity, 32 effects per arm per world, and source-cold-replay integrity. This is a deliberately hard development test of generic composition rather than a post-result threshold tuning exercise.

Both successful and negative outcomes are preserved. A negative does not authorize a retrospective third repair or reusing unopened original data. Preserve original WSP-131 confident errors, WSP-132 R1 coverage collapse and WSP-133 within-family support unchanged.
