# NCI-NOVEL-01 — executable source-free developmental causal relation screen

Independent Yggdrasil contributor, not a native Amalgam owner or integration coordinator.

## Purpose and scope

This provides **source-free native-style cognitive development evidence** for previously unencountered, typed public-variable/action-role causal relationships. The learner receives genuine synthetic public first-action→intermediate-state→second-action→reward observations, without evaluator truth, without a preselected target expression, and without old checkpoint replacement. Candidate is a bounded minimum-description-length **MAP** Boolean program search over at most four 2-input gates per stage. Exact matched-grammar symbolic Bayesian **BMA**, full contextual Beta, subset contextual Beta, and a fitted first-order state-space conventional control receive the identical fit/public feedback. Reward-greedy, same-grammar information-gain and random held action policies are measured separately. This is a finite Boolean grammar, **not arbitrary operator discovery**.

Original prereg and first action-cap correction: NCI-NOVEL-01 documents on PR #1210 at `9a9d4c592b0478a87d574e8142daf92bcb1a6098` (frozen before development implementation). This directory holds an **append-only pre-primary correction**: engineering preflight used and exposed seed `481201` for two families, replaced with previously unused `481283`; held score/policy split is 32+32; the candidate and exact symbolic control have the *same* prespecified admissible grammar. Do not reuse the preflight seed for the principal comparison. Primary cohorts are `[481223,481247,481269,481283]` if independently scored later.

Source-free test code and matched controls are frozen here **before** all primary scores. SHA-256s of source files and prereg are in `source_manifest.json`; a full commit SHA/tree is the immutability provenance. The `preflight_final.json` is a **pre-score engineering fixture**, not independent scientific evidence.

## Run

On the checked-out source directory (Python 3.10+ standard library only):

```
python -B -m unittest -v test_contract.py
python -B trial.py --preflight-only --output preflight_repeat.json
python -B trial.py --output primary_result.json
```

The final command generates/consumes previously unexposed **self-authored source-free development** episodes. It must not be invoked until this source commit has been independently pinned. This work does not use Causal-Gymnasium or protected held source. No paid API or external model is used.

## Qualified meanings

- **ENGINEERING**: deterministic source, fixed typed source IDs, no private labels in learner inputs, idempotent source IDs, byte-pinned cold restore, old-bank SHA immutability, public action-consequence ordering, regression tests and fixed-footprint cap. A synthetic fixture copy is **not** a verified owner-held cumulative checkpoint.
- **SCIENTIFIC**: report actual held-Brier and action reward, per-family/seed standard and negatives, comparison against validation-selected strongest control, and real per-arm CPU/memory. If matched compute, neural conventional baseline, true source novelty or independent original first-use are incomplete, mark SCIENCE UNVERIFIED/NO_GO, not SCIENTIFIC_PASS. Preserve nulls and losses.
- **DEPLOYMENT**: NONE. No merge, native weights, model owner, runtime, queue, scheduled task or first-use mutation. The sole central model integration coordinator is **Unified Causal Intelligence Amalgam Work chat**. Source owner issue #426 still forbids protected original-world first-use.

## Known scientific limitations

A 3-bit boolean truth signature within an enumerated grammar is not a genuinely open-ended causal ontology. OLD and NEW are separated by explicit synthetic source IDs rather than a verified persisted Yggdrasil owner checkpoint. Model fit/forecast stage1 and stage2 have known public input roles, although target laws are hidden. A strong exact BMA may tie or outperform. Action reward evaluation is only synthetic stochastic Bernoulli observed outcomes; counterfactual truth remains evaluator-only.
