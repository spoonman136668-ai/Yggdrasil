Independent research contributor to the existing Yggdrasil draft ENERGY archive PR #1210. **Not an owner checkpoint, canonical learner or integration destination**. Source-free Python stdlib only. The sole coordinator is Unified Causal Intelligence Amalgam Work, PR #1278.

## Distinct hypothesis

The previous NCI-NOVEL-02 model recognized four manually included new-variable functions but falsely identified the physical operator in two out-of-grammar development worlds. A **public-data-only model criticism rule**, evaluated on a separate calibration tape after equal NEW_FIT evidence, compares the complete prespecified Boolean-grammar BMA to a separately fully fitted full-context Beta table. When both frozen calibration likelihood and Brier advantages for the full table exceed thresholds, flag the entire trained grammar as unsupported; return `UNKNOWN_OUTSIDE_GRAMMAR`, **not an invented operator**. Use the full-context fitted predictor as a non-causal fallback. This does *not* create a new causal operator, demonstrate intelligence improvement over exact Bayes, or prove a real-world unknown world can be reliably detected.

## Comparisons and limitations

* Existing fixed Boolean grammar exact BMA prior/masks, **unchanged** from original NCI-NOVEL-02.
* Fully fitted FULL Beta(1/2,1/2) over all public contexts, **independently fitted** all-subsets BACKOFF Beta over the same public interventions.
* A previously fitted frozen OLD grammar bank retained byte-identical across NEW; no real lifelong owner training occurred. Source-declared new factor identities and action roles; two true observed interventions per synthetic episode. All source-private true-world formulas remain evaluator-only.
* ALARM requires `mean_logloss_BMA - mean_logloss_FULL >= 0.08` **and** `mean_Brier_BMA - mean_Brier_FULL >= 0.025` over 256 independent public-calibration outcomes; never tune from the held result.
* Frozen goal: identify >=10 of 12 out-of-grammar worlds and zero false positives across 20 in-grammar/unchanged/unidentifiable worlds; held OOD Brier must not exceed best of BMA/FULL by >0.015.
* All results are **synthetic development** and must be compared to fully trained conventional alternative OOD detectors before any SCIENTIFIC_PASS. Different planning compute, no matched neural/RNN baseline and separate per-world learners prevent a cognitive superiority claim. Source-owner issue #426 still blocks original-world first use.

The older NCI-SOURCE-01..07 and NCI-NOVEL-01..02 evidence and negatives are preserved verbatim. No model/owner merge, training restart, protected source use, automation, or deployment.

The original and amended pilot outputs are preserved separately with hashes. **No primary seed was run during this correction.** The sole primary source and code are the sealed post-correction versions.
