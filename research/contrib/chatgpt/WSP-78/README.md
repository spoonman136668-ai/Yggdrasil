## Direct numerical learned weight mechanism, without backpropagation

- Fixed, fully public source-independent numerical circuit prior with **132 ReLU monomial detector hidden neurons**: each of six action channels and each of 22 Boolean sensor monomials degree 0, 1, or 2. A detector computes `ReLU(onehot(action) + sum(selected actual bits) − term_size)`. Its output is 1 exactly when action and monomial match, 0 otherwise. This grammar is a deliberately STRONG source-aligned inductive bias, not an independently acquired feature language.
- For every paid before/action/after physical row, derive action-specific causal *change* bits `before XOR after`. Incrementally update six per-action source-blind packed GF(2) linear equation systems relating 22 public monomials to six observed bit-change outcomes. Detect inconsistent paid rows for any action. Unknown coefficient choices deterministically zero-filled; paid rank is a compressed numeric evidence statistic. No source oracle, known rule role or evaluator truth enters training.
- **Program ACTUAL neural numerical weights**: six output ×132 coefficient matrix (0/1) maps fixed ReLU detectors to per-bit integer causal effect counts. Apply a second real-valued ReLU sawtooth parity circuit `parity(c)=c + Σ_{k=1}^{22} 2(−1)^k ReLU(c−k)`. Finish with numeric XOR `next=state+parity−2ReLU(state+parity−1)`. Heldout inference is **numeric ReLU forward only**; no symbolic GF2 solver, training examples, private physics or polynomial interpreter called during inference.
- Compile mathematical identifiability (public state/action monomial vector lies in actually PAID equation span) into an independent **numeric ReLU confidence head** formed from fixed PUBLIC state/action identity detectors for all 384 enumerable input patterns. The detector weights are learned from rank/paid evidence only; no heldout truth or output labels. This confidence head may be large and is not a scalable open-world uncertainty method; full learned weight count and covered/confident prediction count must be reported, including abstentions.
- Preserve a real numeric Stage A snapshot after 96 charged actions, acquire 48 more physically paid B consequences on the SAME trajectory, then update learned numerical causal coefficients/confidence WITHOUT replaying old raw paid examples. A live compressed GF2 rank statistic supports updating; cold-only inference snapshots contain numeric matrices, count and hash, **no ledger, private source, or symbolic equation basis**. Check all previously truly correct confident A predictions remain so after B.
