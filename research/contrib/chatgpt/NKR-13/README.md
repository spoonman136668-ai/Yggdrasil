## Scientific question

On 12 synthetic worlds with unknown context conjunctions, the native signature made **23 confidently wrong predictions** (121/192 correct) while a separately implemented full-conjunction symbolic control scored **129/192 correct, zero incorrect, 63 abstentions**. NKR-12 also demonstrated that four isolated single-bit sensor errors were not sufficient evidence for a permanent relationship change.

NKR-13 answers the next **mechanism** question rather than repeating knowledge-image scans: can the native research substrate generate action/context conjunction candidates from observed context features, require more than one contradiction, retain every source-consistent operator, and **abstain** where they disagree? Can it improve on NKR-11 without falsely claiming to outperform an equal-information conventional operator-search baseline?

## New mechanism

`yggdrasil/native_operator_discovery.py` is a **separate opt-in native integer candidate**, not an accepted Yggdrasil model change. It accepts only the existing versioned canonical SHA-256 pinned `engineering_fixture_only` **observed-intervention** bundles. It **preserves** the complete prior NKR-11 warm checkpoint immutably, including its source identity/bytes.

To qualify a change, at least **two** distinct public outcomes must contradict the frozen warm predictor. One inconsistent sensor measurement is not a new mechanism. The learner infers a context parity baseline from the action-zero outcomes on x=0,1,2,4,8 and checks all eight visible contexts; this proposal cannot simply ignore contradictory observed baseline data.

The learner then proposes *all input-derived nonempty bit-conjunction masks* (1..15) and retains **every** mask consistent with observed differences between actions 0 and 1. This extends beyond NKR-11's fixed action-bit parity class and does not insert hard-coded *world IDs* or *actual hidden masks* into model code. But the candidate **operator grammar** (four-bit conjunctions) is specified in advance: this is **bounded operator search**, not unrestricted scientific discovery or proof of new causal language.

A cold prediction is emitted **only if every evidence-consistent operator agrees**; otherwise `UNKNOWN_ABSTAIN`. Mask ambiguity is not forced into one confident wrong choice. Every prediction is marked `UNVERIFIED`, `native_accepted=false`, `scientific_pass=false`, with no write permissions for historical fact storage, YPC1 counters or owner causal events. SHA-pinned immutable checkpoints bind the original warm evidence and every public repair row; cold restoration re-derives the proposed masks and rejects tampered source, mask, record or accepted status.
