## Why this gate is different from CB4

CB4 provided one named mediator channel with known interpretation. It established that charged public bit-flip interventions break the non-identifiable CONTENT/GATE role symmetry from CB3, but a model still **knew which observable was the mediator**. CB5 instead exposes **eight unlabeled sensor channels**; six change in response to a distinct pair of four known-relevant state bits, while two are unrelated distractors. Only one of the six responds downstream to a direct `do(sensor=value)` intervention by reversing the **earned binary action consequence**. The agent receives no identity or hidden causal parent labels. It must observe four charged upstream interventions and then actually choose/test sensor interventions to distinguish causal effect from correlation.

The architecture deliberately reuses CB3's frozen generic four-feature learned public relation and a separately implemented conventional exact four-feature symbolic learner, not another new native controller or source-private source. Both arms have the **same public intervention interface, actual source observations, binary-action opportunities, reset baseline, cost accounting and max eleven charged actions/world**.

## Actual intervention and earned-outcome comparison

**Source:** 32 new public worlds, eight uint4 source-state registers, two actually attempted binary actions 0/1 within the eight-action FKP-17 field. Feedback at time `t` is the earned +1/−1 outcome of an action taken at time `t−2`, rather than a hidden law label. In each of four fixed source families, the rewarded action depends on two CONTENT and two GATE state bits, but the bit identities and causal sensor permutation live in `public_source.py` and are inaccessible to either learner. The learned four-feature set is not supplied; each model fits it from **515 common public training actions/world and 512 actually credited delayed consequences/world**.

**Charged mechanism diagnostic:** Four individual public-state bit flips show which of the eight binary sensors change. Six channels appear related to a pair of relevant state features, deliberately confounding mere correlation. Each arm then pays for one actual baseline action (action 0) and tests candidate sensor channels in ascending order. A sensor is identified as causally downstream-relevant only when forcing its bit value causes the actual earned binary action reward to reverse relative to the paid baseline at the **same reset source state**. An exact conventional discrete posterior sees the same public before/after data and real consequences, and independently removes hypotheses that fail to reverse the reward. The hidden source-private channel identity is used only *after* choices for final scoring.
