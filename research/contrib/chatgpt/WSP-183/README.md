# WSP-183 — public physical intervention dataset, source-safe offline development

This isolated branch reuses WSP182 source-free engineering, but its primary data are **real pre-existing wind-tunnel experimental measurements**, not fabricated world trajectories. Frozen protocol: `prereg.json` first commit `7bfdfe8a976f3812f9216d14132622ed498fce56` predates opening any archived measurement rows. No original-world simulator import/reset/step, original causal first-use, or live Remote Lab call.

**Source/custody:** Gamella, Peters & Bühlmann, *Causal chambers as a real-world physical testbed for AI methodology*, Nature Machine Intelligence (2025), DOI 10.1038/s42256-024-00964-x. Public data repository `juangamella/causal-chamber@967d59a42956872f37463cc561ecf6e9ceab9364`, dataset `wt_changepoints_v1` CC BY 4.0, upstream published MD5 `7e9f26d192674f2aaa6481f4415007eb`. Source README blob `66ab8d597ead7b0ffd828a722d97b8ba83579a4e`, variables blob `2078166de5ce0bf8d1fc8497f05de6f5cae3fa8d`, generator blob `8ca83af2102a415d0ccc581644fff2fd7d466223`. Archive SHA256 and per-run content hashes are reported after verified download. No raw data copied into this repo; preserve CC BY attribution.

**Protocol:** The original wind-tunnel generator performs ten random load changes (levels 0.01,0.1,0.2,0.5) per run, repeated for ten source runs `load_in_seed_0..9`. Rows contain actual after-SET marker `intervention`, publicly chosen actuator `load_in`, and sensor outputs `rpm_in` and `pressure_intake`. Each segment's predeclared steady readout is **measurement positions 15..79**, not fabricated paired counterfactuals. Runs 0..5 exclusively FIT, 6..7 VALID, 8..9 public DEV. Never use current target outcomes as current model input.

**Arms:** Direct two-feature recursive ridge weights (intercept and load), fully fitted independent normal-equation ridge on exactly the same FIT/inputs (parity control), 4-load-level smoothed categorical fitted means, fit-only global mean, same-run prior-sensor persistence, and fully fitted conventional four-feature ARX with the same previously completed public event. Development pass 2 adds a single preregistered 0.5 gain correction using the previously completed event residual; it can never access the new event's outcome. VALID-only selection chooses direct/no repair and best conventional; DEV is scored exactly once. Metrics raw RMSE, FIT-scaled normalized RMSE per sensor, mean normalized RMSE, relative gain vs the strongest validation-selected conventional, time, events, archive hashes. Frozen gain bar: >=5% relative improvement on **both** output sensors and retention non-inferiority (not yet authenticated). Zero evidence of truly novel source mechanisms; distinct physical repetitions are not different laws.

**Scientific boundary:** This is legitimate published physical **offline development**, not an autonomously trained native Yggdrasil model, original protected source first-use, independently new family transfer, gold-standard causal-edge identification, true replay-free general-intelligence gain, or SCIENTIFIC_PASS. Source owner #426 still denies protected original-world first-use. Even if a public DEV win appears, report development only. Do not post-result retune; stop after two prescribed passes.

**Execution:** Branch-scoped, exact archive checksum, no network access except the explicitly pinned public source ZIP during the single controlled real-data run, no subprocess/lab API, no paid APIs. Compare on original real measurements only; source-free unit tests exist to qualify parser/leakage and arithmetic, NOT as scientific evidence. Historical synthetic WSP182 null stays unchanged.
