# Unified Causal Intelligence Amalgam

Extend the integrated CKAD learner. The model keeps the same native tokenless,
non-transformer causal world state, witnesses, uncertainty, repair records and
checkpoints. Its existing six mechanisms share that state. Additional learned
specialists consume matching public views, actions and witness history and
propose predictions, interventions, representations or bounded updates. The
existing decision and learning path owns action choice and evidence admission.

Passive observations can support invariant-view learning, hypothesis proposals
and predictive tests inside their observed support. Keep their provenance
separate from directly witnessed interventions. Require interventions or a
separately justified identification design for causal weight updates. Planned
and dreamed outcomes remain model predictions. They never enter the witness log.

The context tournament supplies competing explanations and uncertainty. The
existing two-stage consequence planner simulates choices from the accepted
forecast. A specialist can propose a forecast or a probe that would distinguish
explanations. Preserve the current native choice when evidence is weak,
contradictory, unsupported or out of distribution. A decision to use, suppress
or consolidate a specialist must be reproducible from recorded evidence.
Simulator family labels, held outcomes and unrevealed counterfactuals stay
outside the learner.

## First integration result and continuation boundary

`shadow_preflight.py` restores actual CKAD26 native checkpoints and both trained
JEPA2-03 checkpoints. The paired-view, action and history interface is exercised
through the existing two-stage planner. Specialist heads read history from the
CKAD26 checkpoint. Each donor's own witness history is used to verify its saved
weights and remains in its original source archive. The probe enumerates public
input shapes, checks default native plan parity and checks both source
checkpoints for byte changes. There is no scoring or source interaction.

The linked CKAD26 snapshots are at the 1,024-episode capacity. Extending cumulative
training requires a bounded growth qualification on the retained state. Preserve
old witness bytes, ids, hypotheses, weight readouts, quarantine and source pins
through the codec change. The inherited 1,024-capacity result remains a test for
the frozen checkpoint format. Verify a cold descendant learns one authorized
next receipt and matches warm continuation before any scored experiment.

## First combination to qualify

Use the complete descendant native state and existing saved JEPA heads.
Test a prospective switch based on prequential, matched-input loss on
previously revealed receipts. Select between native and an eligible head
for each supported prediction target. This exercises the existing planner
without a fixed cross-specialist average. Update specialist weights only after
the same native evidence transaction succeeds. An unsupported or harmful
proposal stays in shadow. Save selection, calibration and provenance together
with the complete native state, and verify replay after cold restart.

Freeze the full experiment before scoring: exact source and starting checkpoints,
paired inputs, training and validation cutoffs, held seed families, intervention
and compute budgets, selection threshold and rejection tests. Compare native
only, each head alone, native plus one enabled candidate, the fixed blend
negative, shuffled views, gate disabled, and the combined mechanism, with fully
fitted dynamic Bayesian/change-point and online conditional controls. Exact
equivalent controls remain required. Score unfamiliar-family causal error,
interventions to reach threshold, prequential Brier, reward, transfer, confident
errors and abstentions, familiar return, full-state restore, interference per
seed, wall time and parent/child resource usage. Preserve failures in the same
repository and qualify final source independently on Linux and Windows.

This is a draft native integration track. Wingless and TTT-Hybrid remain
independent. Source authority and protected first-use stay with the existing
owners. The current gate is compatibility of learned components. The first
combination experiment and its performance gates are still pending.
