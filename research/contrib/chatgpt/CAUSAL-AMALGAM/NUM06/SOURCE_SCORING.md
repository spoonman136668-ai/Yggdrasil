# NUM06 source and scoring contract — prospective, fixture-only

The immutable original prereg remains unchanged. This implementation defines
an authored alternative numerical family (integer ticks, within-quadrant
nonlinearity, cross-coordinate effects, action-specific coefficients, bounded
discrete noise). It is not an independently obtained real world. FIT/VALID
and null boundaries are specified before use in REGISTERED, held boundaries
match the original prereg. Random block lengths (20/40/60) and shuffled
factorial coverage do not supply a private phase-clock field to learners.
All reserved seeds and listed NUM05 seeds are hard-denied, even partial
previews. No code in this patch admits them. Two distinct numbered fixture
seeds are outside all registered rosters.

The fixture harness uses all eleven preregistered arms, identical public
packets and prequential forecasts; it records separately the late unfamiliar
and familiar return windows and averages the two MSEs with equal window
weight, not event-count weight. The exact original NUM05 class is unchanged.
Cold restore occurs before the first return observation; conventional
controls rebuild only from their previously observed evidence. The score
reports old-bank hash retention and last-48 pre-observation selection;
stationary null checks are diagnostic, not qualification.

Each arm is independently reconstructed for an identical stream and measures
predict/update/cold CPU nanoseconds and explicit serialized state bytes.
Shared-process fixture RSS is deliberately NOT reported as per-arm RSS.
No result can be science-eligible: independent process peak RSS,
fit/validation selection receipts, prospective source/roster custody,
owner admission, single-use sealed evaluation and matched budget
qualification are still missing. The fixed fixture parameters are not fitted
registered settings. No candidate, comparator or threshold is tuned from
fixture score values. No reserved source generation or owner action occurs.
