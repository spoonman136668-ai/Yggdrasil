# NUM05 — Five-action numerical causal memory (isolated development)

**Research contribution only**, stacked on the existing native Amalgam [#1278](https://github.com/spoonman136668-ai/Yggdrasil/pull/1278) parent `86264b41a08d49f558418c0fba367f3a2636befa`. ## Why this is not a repeat of CKAD47

[CKAD47 #1312](https://github.com/spoonman136668-ai/Yggdrasil/pull/1312) used four discrete actions/four-state XOR-invariant compositional effects. Its frozen development science was **NO_GO** against exact Bayesian and unrestricted tabular controls. NUM05 instead takes **five distinct interventions**, two continuous public coordinates, a numerical actual next observation and scalar reward. It allows *state-dependent non-XOR action consequences*, preserving original witnessed action and reward units rather than inventing a binary two-intervention episode. It is a separate source-only research arm, not a successor that mutates or replays CKAD47.

## Implemented native-independent candidate

`num05.py` has a bounded single persistent numerical evidence ledger (up to 512 one-step events), source-blind five-action context-conditioned three-head learner for (delta-x, delta-y, reward), exact source-free checkpoint cold replay and fail-closed duplicate/conflicting evidence checks. A second archived memory bank is created only on three consecutive observed prediction contradictions after initial competence; old bank is frozen while the candidate learns the new regime. A three-witness public error comparison can select the old bank again without a private task/phase label. Memory mode never sees source family/truth, unseen outcomes, a privileged task ID, or a proposed intervention not witnessed.

Every event retains a local **synthetic** source provenance tag `num05.synthetic-public-dev.v1`; this is not an upstream actor signature or a MetaHighwayEnv adapter. Neither code imports external simulator, synthesizes CKAD binary rows, writes accepted checkpoints, nor authorizes actual source first-use. The native owner must independently qualify any future numerical interface.

## Frozen separate controls and source

`prereg.json` was committed FIRST at `182b7a01687d3bfbaa31472148d1f62ae8034bac`, before implementation and all reserved DEV outcomes. The synthetic source has five public actions, four public numerical state quadrants, genuinely sampled noisy numerical next-state/reward consequences, and unseen A→B→A phases of 160/160/96 events. Phase source identity is evaluator-private; all arms receive precisely the same 416 actually observed public event packets, in fixed order, score before training. An independent A→A→A null trial checks false mode creation. DEV 520117/520131 and null 520211 are reserved, *not to be read in any fixture or engineering smoke test before admission*. Pilots 520311/520331 and primaries 520411/520431/520451 remain unconsumed.

Strong same-data baselines: fully refitted full-history per-action state-quadrant means; last-80 and last-40 versions; exact 8-nearest-neighbor source-state models (whole history and recent-80); full-history per-action **ridge linear regression**; no-memory zero control; and single-bank no-archive ablation. Baselines and native candidate are unoptimized Python, with unequal compute: **no claimed inference speed, efficiency gain, low-energy advantage, scientific transfer or native model improvement**.

The frozen two-phase score uses actual prequential three-output MSE, averaging last 80 unfamiliar and last 64 familiar-return episodes. To pass development **both seeds** must beat the strongest conventional control by at least 0.005 pooled, preserve the old bank byte-exact across B, retain separate stage guards, and return to the old bank for at least 80% of the last 48 familiar episodes. Null source must never create B. All other outcomes are **DEV_NO_GO**; no post-score tuning or same-seed rerun is permitted. Even DEV feasibility is not SCIENTIFIC_PASS and grants no native integration.
