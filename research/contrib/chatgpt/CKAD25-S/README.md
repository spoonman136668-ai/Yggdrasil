# CKAD25-S — Prospective unfamiliar-family test of the *real* native learner

**Stage:** First source-frozen synthetic development qualification. Native source code remains unchanged. This is NOT the original protected CausalGym environment or accepted Yggdrasil scientific first-use.

## Why this is distinct
CKAD25 physically trained two cumulative native stages and persisted an exact cold checkpoint, but its original four held forecasts abstained. CKAD25-R's conventional minimum-support sparse repair recovered 4/4 **previously evaluated** held assignments without additional data; that is only retrospective. YNCA-13's closed table-memory approach failed on unseen MUX. Neither establishes novel-family native transfer.

This experiment restores the **actual CKAD25 native learner checkpoint**, then uses its pre-existing `observe`, `repair_sparse`, and `restore` methods to learn four law families in **four of the existing native slots of one learner**. The learner receives only numeric action/context/outcome rows, not rule labels. Each law gets 12 public synthetic interventions (8+4 incremental stages), with four separate hidden assignments. We use three fixed input-split seeds. The four mathematical laws are fixed and encoded only in the source generator; the 12 seed-law cohorts **are not 12 independent causal families**.

The same training rows go to fully trained CART, random forest, logistic ANF, exact small sparse ANF Bayes, fitted frequency and uniform controls. The native sparse-repair mechanism itself invokes conventional GF2 minimum-support MILP: beating the uniform or weak controls cannot demonstrate superiority over that conventional solver.
