# AAI-08A — returning causal laws in official NS-Gym Bridge

Frozen external contributor experiment: learn **actual stochastic action-consequence transitions** from an identical 72-probe official environment stream under an A→B→A regime switch. The associative candidate has two mutable bounded Beta memories and a five-outcome likelihood-gated recall policy. A separate conventional one-slot ablation, full stationary Beta, fully fitted 1200-epoch logistic, eight-outcome sliding window and knowledge-rich Bayesian two-law HMM comparator receive the same official observations and test action budgets. HMM's known parameters are an *expert reference ceiling*, not a matched-prior innovation control.

**Source custody:** original prereg `db263b1de02fdaaec2152b44947a1e11b5305262`; explicitly documented pre-first-use amendment `57e8933f0376c226a62ab7252bb395482fa41eb2` corrects an uninformative within-phase shuffled-feedback negative to a global history-permuted negative *before this evaluator was written or any science cohort consumed*. Frozen all seed splits, budgets, hypotheses, success thresholds and provenance in the prereg chain. Official NS-Gym upstream `127df4b714fe4fcf680721d8e9278a96090acd7e` (MIT); no upstream copy or patch.

The observation-only adapter routes three fixed, safe actions to the Bridge junction and uses the official `DistributionStepWiseUpdate` and `NSBridgeWrapper` for the fourth-action slip law; action choices RIGHT/UP have substantially different real hole/death reward under A and B. Each episode has a scoped snapshot/seed/restore of NumPy's legacy process-global random generator, as previously qualified on Linux/Windows in AAI-08P. Private change notifications, exact law parameters, source grid and raw diagnostic info are never given to learners.

**What it can prove:** whether a bounded learned causal regime cache actually improves official downstream reward and resumes correct decisions when a formerly observed law returns, relative to strongest fully trained recency and stationary controls.

**What it cannot prove:** model-native cognition, never-seen primitive discovery, autonomous route learning, natural exogenous nonstationarity, or AGI. A result that merely duplicates the conventional solution is a scientific NO-GO for native integration.

All primary worlds are disjoint from mechanical tests. One source-locked first-use run, complete raw world records and bootstrap CI on GitHub only; no user library files.
