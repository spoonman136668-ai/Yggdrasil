# AAI-11C — Why is intervention-contrast learning still losing?

This is an **independent read-only diagnostic**, not another candidate, retuning of AAI-11B or scientific cohort experiment. It is stacked on frozen, unmerged [AAI-11B PR #1061](https://github.com/spoonman136668-ai/Yggdrasil/pull/1061), exact SHA `425747038824324c161c4de5e960117c6be31145`. **Preregistration was committed before diagnostic code** at `9125ddf77c74db6818d37ac927e8e4711f21ce1f`; the original learning models, planner, AAI-11P causal simulator and thresholds remain byte-for-byte unchanged.

AAI-11B improved its source-only synthetic reward from AAI-11A's 1.769965278 to 2.084722222, but failed the fully trained, same-grammar `graph_recent8=2.134027778` control and scored only 36.8% exact 3-goal success. Rather than adjust the new learner's causal-flip penalty or its learning rule based on this failure, this source-only tool separately measures whether it can **predict** novel causal laws correctly and whether **the exact shared intervention planner** is at fault.

## Frozen diagnostic logic

All evidence stays public to the two original learners: 64 public A/B training rows, then 2 or 4 common public do-action challenge trials for each unfamiliar C/D/E/F structural law, on only `mechanical:alpha/beta/gamma` fixtures. Each method independently cold-restores into 12 original held-out `(x,goal)` episodes per condition (288 paired episodes total), with 0–2 real self-selected actions and only its own actual consequence feedback. The frozen original `graph_recent8` is the **only** re-run conventional learner; the earlier 11-control qualification is reused.

The diagnostic evaluator—not the learner—may inspect privileged true-law outputs for **64 unseen-input forecast checks per condition**, **64 x 12 do-action effect checks per condition**, and a separate diagnostic *perfect predictor* injected solely into the exact unchanged shared planner. At no point are privileged outcomes or original hidden-law formulas given to a learner or used to update weights/mismatch counts. These are evaluation probes, not fair learner training data, and cannot establish general intelligence.

The output reports mediator-by-mediator factual accuracy, intervention-flip prediction accuracy (including and separately excluding do-actions that do not change x), graph-rule selection disagreements, retained true do-action pairs, achieved terminal reward vs true-law two-action exhaustive oracle, perfect-prediction shared-planner reward, exact 3-goal completion and per-episode reward wins/losses/ties. Deterministic state/action/score SHA256 and original trained checkpoint SHA256 are read back; aggregate rewards must reproduce **AAI-11B=2.084722222** and original **graph_recent8=2.134027778** on both OS within 1e-6 or the entire diagnostic is invalid.

**Frozen classification:** if a shared planner with a perfect privileged forecast still loses >0.05 to exact two-action oracle, classify planner-limited; else if candidate factual or causal-flip bit prediction falls >=0.01 below baseline while terminal reward loses >=0.03, classify hypothesis-selection-limited; else if both predictor accuracies match within 0.01 but reward is >=0.03 lower, classify policy/calibration-mismatch diagnostic; otherwise mixed/inconclusive. These are bounded *explanatory diagnostics*, **not proof of causal attribution**, because models may choose different actual do-actions and receive different subsequent feedback. They are not scientific selection or promotion gates.
