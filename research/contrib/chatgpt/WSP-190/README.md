# WSP-190 — real interventional causal-contrast modules (new original public physical source)

**Why:** WSP189, an independently frozen FIT/VALID/DEV run using real `lt_walks_v1` historical light data, showed the 2D learned residual-state adaptation strongly **lost** to fully trained conventional streaming/persistence controls. Its source, negative scores and draft PR #1279 remain immutable. WSP190 tests a different hypothesis: **causally informative do-interventions** may identify modular source-to-sensor effects that extrapolate to unseen physical intervention strengths, beyond ordinary pooled regression. No WSP189 data reused.

**First freeze:** `prereg.json` SHA `222e14e657da5e7b41041d14860483c45a0481b9`, committed before any numeric observations from new `lt_interventions_standard_v1` opened. Independent physical source `juangamella/causal-chamber@967d59a42956872f37463cc561ecf6e9ceab9364`, publisher ZIP MD5 `476664d024f88e8b7640998bb5e9ee33`, CC BY 4.0 data, Gamella/Peters/Bühlmann, Nature Machine Intelligence 2025, DOI 10.1038/s42256-024-00964-x. Original upstream README and intervention source generator pinned by Git blob SHA in prereg. These are actual historical randomized interventions in the single same light-tunnel hardware, NOT active original-world or general unfamiliar mechanistic transfer.

**FIT** 8,000 first physical source rows from `uniform_reference` plus 1,000 each from actual `uniform_red_mid`, `uniform_green_mid`, `uniform_blue_mid`; **VALID** reference records 8,000–9,999; **public DEV** actual `uniform_red_strong`, `uniform_green_strong`, `uniform_blue_strong` and `uniform_pol_1_mid`, first 1,000 historical real measurements per source. Source must have AT LEAST frozen count; any extra rows are counted but numerical extras are never parsed. All file names/selection/prefix/scores locked before observation. Fit-only reference z-score 11 current public actuator fields and 3 sensor outputs. No current sensor target, source identity or hidden `flag` at prediction.

**Candidate:** learn 3 × 3 RGB→vis source-effect slope matrix from **actual single-target MID do-shifts of physical source group means**, uncertainty-gate each edge at 2 standard errors, and FIT nuisance effects for 8 other visible actuators with normal equations and ridge regularization. This is structurally different from residual memory and from conventional pooled predictor; it is a frozen perturbation-invariance hypothesis, not a proven identifiable causal graph.

**Matched strong baselines:** Fully FIT pooled 11-feature ridge; fully FIT high-capacity 26-feature quadratic ridge; fully FIT **intervention-group-aware** centered ridge using exactly the same FIT group labels as the candidate; and reference-mean null control. Independent **misattributed RGB slope permutation** negative control with same capacity and re-fitted nuisance, to distinguish actual intervention identity from arbitrary module routing. All baseline/candidate arms see the same source FIT and same current public input at DEV. Conventional comparator is selected by untouched reference VALID only; report oracle best-scored baseline per sensor too, without using it to select promotion.

**Falsification:** On three strong ORIGINAL RGB interventions, candidate needs >=5% gain in mean FIT-normalized RMSE against VALID-selected best fitted conventional, nonregression on >=2 of 3 groups, no >5% decline on any group/sensor, >=5% improvement over shuffled-module negative. A genuinely unfamiliar original polarizer-target intervention also has a <=10% regression veto. Otherwise record DEVELOPMENT_NO_GO, no tuning on scored DEV. Report exact per-group metrics, module gates, FIT/model SHA and process CPU, full dual-OS regression, independent G29. No new physical original-world actions, native Yggdrasil integration, paid API, controller or merge/deployment. Original source-owner issue #426 still DENIES protected first-use; using independently public CC BY 4.0 historical data does NOT change that.
