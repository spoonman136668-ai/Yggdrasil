## Actual new deliverable

`research/contrib/chatgpt/CVH-10/dtr_public_bridge.py` maps the **original documented API** to the *unchanged* six-field binary public policy interface, without creating, importing, constructing, resetting or invoking any original source.

1. Stage 0 begins from `(S1, opaque_reset_info)`, and only S1 goes into the policy. Original `do()` callback `(S1)` must match the reset observation. The policy chooses X1 **before** any subsequent observation is available. Accept exactly the stage-0 public response `(S2, reward=0, not_done, not_truncated, opaque_info)`; emit `PublicConsequence(S1,X1,0,S2,False,False)`.
2. Original stage-1 `do()` callback `(S1,X1,S2)` must exactly match already-observed first-stage public S1, chosen X1 and public S2. The policy receives only S2 plus the *already-witnessed* six-field prior event, and selects X2. Accept exactly the stage-1 response `(None,Y,True,False,opaque_info)`, Y binary, then emit `PublicConsequence(S2,X2,Y,0,True,False)`.
3. The terminal `after=0` is **only an explicit no-source-observation sentinel**. It is never a source claim that the final state was 0 and is never used for a third decision. The terminal flag closes the original unchanged model's episode. Without the sentinel and explicit terminated flag, the existing CVH02/CVH08 binary public API would reject legitimate DTR final observations.
4. Reset private info, stage 0 and stage 1 result `info` are **never read or passed to policy**. The source-actor callback may reference historic public S1/X1/S2 *only* to validate the same already witnessed public transcript, not to reveal confounders, source internals or action alternatives.
5. Every action is sealed *before* result; a malformed return, duplicate callback, source state mismatch, missing confirmation or outstanding action is **fail-closed**, with no uncertain-effect retry. The bridge is not an execution actor or a secure process sandbox. A real qualifying process must also own a durable no-replay journal, verified virgin seed ledger and source private/public isolation, which do NOT exist in this branch.
