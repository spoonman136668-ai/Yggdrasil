## Mechanism: 16 pure + 16 adversarially informative actions

All 64 existing WSP130 public synthetic causal functions are first learned from **128 genuine consequence effects/law (8,192 warm actions/arm)** under their source-only custody. No learner gets original hidden source coefficients as weights.

For each of 64 new known-permutation worlds and 32 new nonpermutation single-shear worlds, under new source-only SHA256 mappings and opaque subjects:

1. First **16 paid consequences** use WSP131's proven source-blind 720-permutation active selection, preserving its ability to recover known variable roles.
2. From the actual 16 observed outcomes, separately construct all consistent **22,320** hypotheses: 720 pure permutations plus 21,600 invertible one-bit GF2 shear compositions.
3. Spend the final **16 paid consequences** on actions maximizing disagreement across ALL remaining explanations, dynamically updating hypotheses with each observed result. If all hypotheses already agree, use unused source actions in deterministic order to complete the frozen budget.
4. At final evaluation, release only the value on which every surviving candidate agrees; else abstain. Never invent or modify the initial GF2 primitive, exceed 32 paid actions, use future labels, or claim universal unknown-law safety.

**Independent source-blind optimized exact symbolic** implementation reconstructs the same 720+21,600 space, chooses every next intervention independently from the same prior and must match the numerical choice and every prediction exactly. Other matched controls on the SAME new 96 causal worlds and exact equal 32-action budget: WSP132 R1 conservative confidence release on the previous pure-action policy, original WSP131 numerical learner, optimized source-blind fixed symbolic, fully fitted conventional CART on R2 actions, and no-update. No numerical superiority claim over equal-information exact symbolic is permitted.
