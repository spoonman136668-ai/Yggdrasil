# NKR-16 — Does actively choosing an intervention help?

This continuation replaces repeated fixed-rule demonstrations with a falsifiable **information acquisition** test. It probes a foundational limit: when every unseen action effect is an independent binary unknown, no strategy can infer it from the other effects without a structural prior, even if the strategy is called “active.”

## Native research functionality

`yggdrasil/native_active_intervention.py` is a separate, opt-in native **integer/no-token** planner over canonical SHA-pinned observed intervention bundles. It receives 16 initially visible public `(context,action,outcome)` observations (both arms at 8 context IDs) and never the 8 withheld outcomes. Each policy proposes `(context, action=1)`, the evaluator then executes that action, and the planner receives only its *selected* public outcome. Every receipt is immutable; cold reconstruction validates source bytes, exact choice, number of actions, unique refs, source kind, source ID and candidate updates. Any unselected, repeated, corrupted or over-budget event refuses mutation. No accepted Yggdrasil YPC1/DG1 memory or historical factual ledger is written.

Two different **assumption classes** are tested, never conflated:

**Track U — Unrestricted binary action effects** (12 previously studied NKR-14 worlds). There are 16 possible context inputs, one arbitrary binary action-effect output for each. Eight action-effect bits were initially seen, leaving exactly `2^8 = 256` complete functions that agree with all visible evidence. Every unobserved context has **exactly one bit** of expected information gain; an active entropy-maximizer has no preference beyond a deterministic lowest-ID tie, while a seed-pinned random arm chooses among the same remaining contexts. Each policy executes **four** actions in each world. The remaining version space must be exactly `2^4 = 16`, exactly four effects directly observed and four other effects STILL UNKNOWN, regardless of whether actions were “intelligent” or random. No public measured action is scored as a generalization to a previously untouched context. The separately disclosed four-bit **action-zero parity baseline** is scored at eight cold contexts (96 possible baseline predictions). Action-one predictions at unprobed contexts are forbidden.

**Track S — Frozen conjunction-family active information** (12 original NKR-13 synthetic worlds). Assume the exact **15 known positive conjunction masks** of four context bits, filtered to those consistent with the 16 initial observed outcomes. Active planning chooses the next of eight unseen context IDs with **maximum binary entropy of the candidate operator vote**, ties lowest context. Random planning uses a deterministic SHA256-fixed seed derived from the same initial public source and round number. Both execute **exactly two** public action-one probes per world, irrespective of expected gain. After the two actions, only **the six unprobed context-action effects** count as transfer/generalization; directly observed two outcomes are not scored as unseen. A separate **independent, fully fitted symbolic** entropy controller implements candidate filtering/selection from scratch; it must match the native planner on all selected actions, remaining operator masks, and predictions. Both models know the same conjunction family in advance.

This is a fixed-grammar learning experiment, NOT proof that the model discovered Boolean algebra or generalized causal operators beyond known templates.

## Frozen metrics / null handling

Both policies have matched action budgets, same initially visible evidence and the same source-observation interface. Report:
- Track U: 4/8 newly acquired effect bits/world, 4/8 still hidden, `256 -> 16` candidate truth tables, 48 direct action-one observations across 12 worlds per arm, zero extrapolated predictions on the other 48 action-one queries, and 96/96 conditional action-zero baseline predictions. **Expected active-versus-random information gain delta = 0**, so a tie is the correct scientific outcome under unrestricted effects, not a failure needing new parameters.
- Track S: 2 selected action-one probes/world, **72 unprobed effect queries** across 12 worlds per policy, safe consensus correct/covered/wrong counts, candidate support, and action receipts. **DEV_POSITIVE** only if active correctly identifies at least **four additional unprobed** outcomes over fixed-seed random with zero confident wrong predictions and full independent symbolic parity. Otherwise record **NO_ACTIVE_ADVANTAGE**; never switch seeds, worlds, sample positions or thresholds post hoc.
- Original prior action memory is tested for **384/384 retention per policy per track**, complete cold checkpoint reconstruction, no source replay, no additional owner or accepted checkpoint effects, and original root regression on exactly the final candidate SHA/tree.
