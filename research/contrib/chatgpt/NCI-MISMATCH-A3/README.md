The exact independent A2 synthetic simulator and its fixed 7-input degree-2 native GF(2) learner are reused unchanged. New simulation seeds are IN_FAMILY 300–331 and SHIFT 400–431. A third condition corrupts the first 24 FIT labels in each in-family world but requires the final audit observations to be genuine. All held 64 input outcomes are protected until all predictions have been produced.

Per audit arm: 8 common initial source effects + 16 active fitting effects, train and seal provisional native state; select 8 fresh audit inputs without seeing their outcomes. The targeted selector favors FIT-model *identified* inputs and generic degree-3 input-feature novelty (declared monitoring prior; NOT true family oracle). Random audit controls use SHA-frozen random input order. Gate requires 4 identifiable effects, no contradiction, and a consistent ordinary native refit on all32 observations. The separate unvalidated baseline uses precisely the same targeted 32 observed outcomes. All methods and decisions, including failed candidates, are retained.

The preregistration freezes strict safety and utility thresholds. Results are descriptive synthetic development, not general causal discovery; exact independent symbolic GF(2) inference must match native predictions on all128 inputs. Conventional CART is fully fitted on identical witnessed rows and reported separately, not equal-compute superiority. Each native output restores cold in a separate Python process.
