# CKAD25-AB — learning where to intervene from earlier causal contradictions

**Prospective research-only native training experiment.** **No primary result yet.** Accepted Yggdrasil `main` stays unchanged, this branch is not owner/Forge execution authority.

## Distinct gap and mechanism

CKAD25-Z #1266 showed the SAME tokenless native learner can actually witness novel causal consequences, falsify a stored numeric hypothesis and retain its prior learned source memories. But two fixed probes cannot detect a different law if its deviation lies elsewhere; four D2 cases failed and independent exact conventional 697-rule Bayes tied the native method. CKAD25-X and CKAD25-U previously compared information probes and missed gain vs strong fixed/random conventional controls. AAI-12R independently tried active operator induction but failed fixed decision-value gates.

This next experiment **does not repeat any of those source seeds** or retune their thresholds. It asks a narrower, falsifiable question: **after genuinely witnessing changes in three earlier worlds, can the one existing `NativeCumulativeLearner` use its *retained source intervention outcomes* to spend two new do actions more effectively in new worlds?** The candidate adds `propose_source_change_witnesses`, an opt-in method of the same native model; it reads its own persisted history slots12–14 (two genuine source witnesses each), evaluates whether each earlier witness contradicted the actual learned source relation, computes a conventional Beta(1,1)-smoothed mismatch score per public candidate address, and picks the two highest. No generator state, world label, fault location or future reward enters the method. Negative source ledger, A/B/C numeric posterior committees, original source/properties and cold checkpoint all survive. The paid new target consequences are stored in source evidence slot15 by the existing native falsification method. **No rival controller or standalone learned substrate.**

This is deliberately a **narrow same-address recurring change-location prior**. It cannot detect an adversarial change at a never-probed address with certainty, cannot discover new algebra or generalize to new action identities, and the inference formula is ordinary frequentist/Bayesian estimation. A conventional implementation with the same history **must be exactly equivalent**. Scientific superiority is explicitly impossible on this protocol.
