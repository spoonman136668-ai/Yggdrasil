## Scientific question and alternative hypotheses

NLD-03 *supplied* source task A/B to its learned policy. Does the same saved one-bank 20-cell policy support **selecting an applicable context from a short history of legal public probes and delayed success**, when the task ID is **withheld at evaluation**? This tests inferred *task selection between already learned candidates*, **not** autonomous formation of new latent concepts, causal composition, unfamiliar task-family transfer or unique native superiority. Compare the native model to equally informed trained conventional cue-perceptron and cue-episodic memory models, a same-capacity cue-blind control, and a **privileged supplied-cue oracle benchmark** clearly labeled unattainable without context. The source A/B laws can conflict on 8/16 four-bit inputs; no response from a nondiagnostic probe can identify a task.

## Prospective bounded protocol (immutable)

- Use **only previously exposed R9 smoke seed 3**: old unchanged FIT_A and FIT_B (128 public actions and 128 two-step delayed feedback each, exact NLD-03 original trace hashes); native 20-cell cue-aware and 20-cell cue-blind learners plus cue-aware and cue-blind conventional perceptron and episodic controls all trained independently on the same FIT_A then FIT_B public events. All source generation and previously frozen fitted models stay unchanged. Never use old R9 original 101/211/307, H1/H2, or Alchemy first-use.
- At evaluation, use existing role **DEV_A_RETAINED** for A and **VALID_B** for B with exactly **64 public source observations each**. The task label may exist inside the private evaluator but is *never provided* to the inference method or learner. **First 8 observations are unscored diagnostic probes**, with legal fixed public action `(sum(sensors)+tick)%2`, same as NLD-03 public FIT. Each action's public success is delivered **exactly 2 ticks later** and recorded by immutable token; disallow duplicate/early/late, secret labels and hidden source target in the context selector. Flush the two final delayed outcomes before freezing the context estimate, without requesting additional source observations, then score only the remaining **56** observations, with no learner updates during probes or scoring.
- The context selector uses only **two frozen, learned counterfactual action predictions** `model.choose(public_sensors, cue=-1/+1)` for each diagnostic probe. The learner predicts whether each of the two known contexts would have selected the public-success-implied action. Increment an integer mismatch score for each cue; choose the smallest mismatch. **Deterministic ties choose A**; abstention/uncertainty rate and count of diagnostic probes where the two learned cue policies disagree must be recorded. No hidden source A/B decision, full evaluation role, or true family label is exposed to this selector. This selector is a simple supervised-hypothesis comparator; it does **not** learn a new native context model or search/optimize actions, and cannot establish model superiority.
- Evaluate the *same* 56 scoring observations for native inferred-cue, native cue-blind, native explicitly true-cue (ORACLE, non-deployable), conventional inferred-cue perceptron and episodic, their cue-blind controls, explicit always-A policy and erased/untrained native. Record correct counts (integer numerator over 56), diagnostic mismatch totals for all selector models, history hashes, inferred cue vs hidden evaluator context only in a **post-evaluation audit field**, matching 256 public FIT events for each trained arm, SHA256 checkpoint identity/restore of 32 cue×sensor decisions before/after diagnostic and no-update tests.
- Count all eight diagnostic probes **as exploration cost**, outside the 56 scoring opportunities. Report 8/64 public steps spent acquiring context, exact latency, model serializations and resource accounting limitations; never call score costless. Prospective hypothesis outcome is descriptive positive/negative/null contrast of inferred-cue native to cue-blind and the supplied-cue oracle; *no universal threshold* and no post-hoc choice of probe length or tie rule after outcomes.
- A/B task identity is learned neither from the public four sensors alone nor from model-provided label; inference is from **public interaction outcome history** but within **two predeclared task hypotheses** and hand-designed cue×feature map. Unseen transfer, independently learned causal abstraction, interepisode persistent task inference and cross-environment general intelligence **not tested**. Representation, retention, context identification and transfer reported as separate axes.
