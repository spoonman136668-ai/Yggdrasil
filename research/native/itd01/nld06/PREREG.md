NLD-06 removes that reset from the *learner and router*: deliver **256 consecutive observations/actions and two-tick-delayed outcomes** with one uninterrupted global tick/token space; privately splice the exact already-published FIT_A (128) then FIT_B (128) source sequences. ## Mandatory falsifiers and interpretive limits

Freeze before seeing development outcome: **warmup 64 / window 16 / threshold 6 / capacity 2 / source A 128 then B 128 / delayed 2 / eval probes 8, scored 56**. A false alarm before source switch is *failure of selective surprise detection*. A trigger only after observed B feedback is consistent with causal detection; zero triggers is a negative; old-context forgetting despite trigger is a retention failure. If conventional trained algorithms detect equally well, this does **not** establish unique native advantage. Different reset events between A and B are forbidden for learner/router, but **source generation itself necessarily retains separate internally seeded original FIT_A/FIT_B roles**. Separate evaluator roles create new testing sessions after training and so are *not* evidence of continual deployed execution across test source boundaries.
