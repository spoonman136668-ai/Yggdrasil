## Falsifiable objective

Test a locally plastic **action-aware** native cellular state that learns delayed outcomes associated with its own/public interventions. The underlying hidden action-success rule is visible only to the *source-free generator*, never to the learner. The learner and every conventional baseline receive identical public cue vectors (four boolean sensors), public family ID (A, B, C), explicit public binary chosen actions, and the binary public action-outcome event **only after two subsequent steps**. No rule label or target action is given before the decision. Local update is after the delivered event, with token-bound credit assignment and a cold-restorable learned state. Success after adding an action input is not evidence that previous native R7 could perform the task.

Three source-free families are *hand designed* and disclosed up front: A succeeds for action equal to `sensor0 XOR sensor1`; B for `sensor2 XOR sensor3`; fresh C for `sensor0 XOR sensor3`. C is a novel **pairing within the same synthetic generator**, not an independently sourced unfamiliar environment. No credit for genuine out-of-distribution family transfer absent independent source birth. Full public sensor/action interface is identical across learner types; context label A/B/C is public and intentionally supplied (strong task-specific prior). No stochastic label noise, so paired controls receive exact equal evidence.
