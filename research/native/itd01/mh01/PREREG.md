## Literature and distinction
Najarro and Risi, *Meta-Learning through Hebbian Plasticity in Random Networks*, https://arxiv.org/abs/2007.02686v5, evolve synapse-specific activity-local rules, allowing reward-free within-lifetime adaptation in locomotion/visual control. MH-01 is **not** a replication: R7 uses public outcome-supervised correlations after a two-step feedback delay; the MH-01 rule also receives this completed public outcome and the genome is a very small shared rule class, not 450K synapse-specific parameters. An outer search using rewarded fitness chooses the rule. Call it *meta-selected local Hebbian predictive plasticity*, never the paper's reward-free lifetime learning.

## Hypothesis
A common fixed-footprint eight-cell predictive learner whose genome encodes local fast correlation gain, decay, slow consolidation gain and bounded neighbor influence will recover damaged **phenotype weights** within 96 completed public feedback events per context and retain pre-existing A knowledge across B learning, **while exceeding the strongest equivalently informed fixed-rule or conventional trained control**. Efficient outer optimization is a separate open question. Outcomes can be negative.

## Frozen protocol
- Source-free public R7 generator as-is; preserve its source exact. Distinct FIT seeds `181,191,193`; one validation seed `197`; untouched development evaluation seeds `211,223,227`. No replay of consumed R7 `17,31,47`. World law is R7's fixed known A/B mapping; this cannot establish genuinely unfamiliar-family transfer.
- Every learner gets exactly the same public context, four sensory bits, prediction opportunity and completed public outcome with `delay_steps=2`, never private generator state, hidden law, task truth, post hoc predicted test labels or more feedback. All arms get the same 240 A episodes then 240 B episodes, then interleaved A and B recovery feedback through 96 events **per context**. Fresh, independent, withheld score-only data: 160 A after training A; 160 A and 160 B after B; after lesion at 0, 8, 32, 64 and 96 recovery events per context, 160 A and 160 B each checkpoint. Evaluation observations never update weights. A/B task IDs are explicitly public, so context separation can mask actual catastrophic interference.
- The phenotype contains eight pairs of fast/slow weights, as in R7. All arms suffer the same deterministic hard lesion of exactly three fast+slow synapse pairs, indices **A0,A2,B1** (3/8=37.5%); target includes both causal and nuisance features. Genome/rule coefficients remain intact. No checkpoint rollback or copying undamaged reference weights. This is **phenotype damage, not loss of the genome**.
- Genome grid fixed ex ante: `fast_gain in {0.5,1,2,4}`, `decay in {0,0.01}`, `slow_gain in {0.005,0.02}`, `neighbor_gain in {0,0.03}`: **32 candidates**, one deterministic lexicographic tie break. Local update on completed feedback `fast := clip((1-decay)*fast + fast_gain*signed_sensor*signed_public_outcome, -512,512)`, `slow := (1-slow_gain)*slow + slow_gain*fast`. Predict by local fast/slow signals + fixed bounded nearest-neighbor influence. No hidden-model oracle, output-label based routing or gradient-through-time. Note: zero initial state; strictly opt-in source-only research implementation.
- Outer fitness: macro-average **A/B postlesion accuracy** across checkpoints 8,32,64,96 and all three FIT seeds. Select max single genome by FIT only. VALID seed is reported without altering choice. Evaluate selected genome once on three EVAL seeds, without tuning. Worst-case and full distribution of all genomes remain visible.
- Controls: original unmodified R7 colony; same-capacity fixed local Hebbian variant with genome `(1,0,0.02,0.03)`; a conventional trained online perceptron with independent public-context heads and matched train+recovery examples; zero-learning sham; untrained genome/corrupted-feedback negative control. Report both matched-capacity differences and differences in number of free parameters; stronger control sets comparator floor. All models experience identical lesion of the corresponding indexed fast/slow or learned weight coordinates, preserving method differences. Restore trained snapshots in an isolated new Python interpreter and compare predictions, not merely bytes.
- Record each arm: A-before-B / A-after-B / B-after-B, accuracy at all 5 damage checkpoints, **first recovery checkpoint** reaching >=0.75 on both public contexts, and any per-context never-recovered; training-feedback counts, genome candidates, model/checkpoint bytes, CPU time for outer search + all training/inference/validation, and memory (whole-process RSS when actually available; otherwise mark UNVERIFIED).
