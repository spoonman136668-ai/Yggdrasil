## Hypothesis and information audit

**Known confounder:** The R9 public generator already supplies task/family context `A` or `B`; NLD-02 intentionally withheld that task cue from inference. A requires sensor0 XOR sensor1 and B requires sensor2 XOR sensor3; identical sensor vectors conflict on 8/16 patterns. It is **not** reasonable to demand joint perfect task performance under a cue-blind interface. The cue is *not* an independently learned representation or an automatically inferred latent context; it is a prespecified, openly supplied task ID.

**Prospective narrow question:** Does restoring that **already publicly observable** cue permit one physically shared learned local state to preserve A predictions after fitting B when controlled against an otherwise identically parameterized but cue-blind state? Competing explanations: (1) supplied task information resolves representational aliasing; (2) disjoint dedicated memory might be necessary; (3) matched conventional learners achieve equal/better retention, so the native mechanism adds no transferable cognition.
