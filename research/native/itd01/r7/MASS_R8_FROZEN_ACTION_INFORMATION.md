## Hypothesis: action is an omitted causal parent

R7's actual public learner interface is `predict(context, 4 public sensor bits)`, then `learn_completed_public_feedback(context, same sensor bits, public outcome, delay_steps)`. It never receives its previously chosen **action**. An actual intervention/credit assignment task must make `P(outcome | action, state)` identifiable from a learner's public input history. Two causal worlds with differing underlying action-success laws can be interventionally distinguishable to an equally informed **action-aware** agent, while yielding byte-identical learner inputs to an agent that discards public actions. No amount of local-state learning can resolve that indistinguishability without an added interface, action observation or other information.
