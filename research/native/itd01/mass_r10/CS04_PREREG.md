## Primary causal-bottleneck question

Can a finite-FIT learned policy use **one retained, PUBLIC observed cue bit** and a later PUBLIC fork image to choose the correct exit, when *all navigation actions are legal and derived solely from public MiniGrid observations*? Does cue erasure or removing history destroy this gain, and does any fitted model outperform equally trained conventional memory-bearing episodic/tabular learners? Strictly distinguish:
- public, hand-engineered cue extraction and route-planning (NOT learned perception or navigation);
- trainable learned fork action/reward association (YES trained from native original reward);
- automatic memory representation formation, long-term episodic generalization, source-unfamiliar transfer and Wingless/Yggdrasil native architecture (NOT tested).

## Frozen real-source public-only navigation contract

`MemoryEnv(size=13,random_length=False,agent_view_size=7,render_mode=None)`. No policy code may read `env.agent_pos, env.grid, success_pos, failure_pos, agent_dir, step_count, max_steps`, internal renderer or source-private outcome. Allowed are only `env.reset(seed)`, `env.step(action)`, returned public image, public direction/mission, and source-owned action enum. The agent begins facing east (public direction must equal 0), turns twice left to west; while the first cell ahead in original 7×7 public image is **not wall** (public OBJECT_TO_IDX), walks legal forward; then turns right to north, extracts the unique publicly visible key/ball cue bit; turns right east and walks until public forward-cell wall, then turns left north to the fork and extracts the upper exit object from the original public image. Reject any missing/multiple cue, wall/non-forward inconsistency, early termination, wrong observation shape, source-native action timeout or >32 pre-fork steps. **No privileged position** is available even to a normalizer; public camera is the only navigation input.

All arms use **exactly the same publicly scripted, nonlearning navigation**; model choice is only made at the fork, with the cue from earlier public view available solely to memory-bearing arms. Success defined from native original terminal reward >0; preserve shaped native reward separately. Fork choice is upper (no extra turn, forward) or lower (two left turns then forward), using only original legal actions. No evaluator/private `success_pos` target consulted for action or scoring.

## Frozen public source roles and budgets

Independent public development replicas r=0,1,2, distinct ORIGINAL source resets:
- FIT = **192** seeds `950000+1000*r+i`, i=0..191, one genuine source-native episode per seed using **noninformative alternating upper/lower fork exploration** (`upper` iff i even), fixed *before reward*. Shared exact same public FIT tuples `(cue,upper_object,chosen_fork,terminal_success,shaped_reward,step_count)` for **all** trained arms.
- FIT_VALID = **64** seeds `960000+1000*r+i`, i=0..63 **per trained/evaluation arm**.
- DEV = **128** seeds `970000+1000*r+i`, i=0..127 **per arm**, one scored immutable public DEV pass. No retuning/retraining after FIT, no reused CS03 seeds, every arm starts new original environment on same paired public seed. All model states frozen before VALID and DEV.
- Six source-native comparator/evaluation arms: (1) **learned history-conditioned public cue table**: Laplace(+1/+1) reward counts on 2×2×2 public cue/upper/fork, learned from FIT and stored one-bit cue at action time; (2) **learned history-conditioned logistic**: 8 binary public interaction features `[1,c,u,a,cu,ca,ua,cua]`, weights zero, fixed 12 chronological passes, eta 0.08, L2 0.003, no hidden source law; (3) **trained episodic exact-context nearest-three**: retain all FIT examples, score each action by mean terminal success from 3 closest `(cue,upper,action)` examples using Hamming distance then original FIT index for stable ties; (4) **trained current-frame-only table**: Laplace reward by `(upper_object,action)`, no cue state; (5) **candidate-state-erased ablation**: copied trained candidate table, overwrite retained cue to fixed zero immediately before fork decision, NO retraining; (6) **fixed-upper** baseline, zero FIT updates. All candidate and conventional arms share same FIT interaction information *at training*, but input-visibility constraints at deployment differ by design. True equal-memory-capacity parity is **not** achieved because the current-frame-only model is intentionally capacity-limited.
- Require each FIT table cell `(cue,upper,action)` has >=3 observations in every replica **prospectively**, else insufficient exploration source coverage, fail closed. No selective seeds or adaptation after outcome.
- At inference choose highest **fitted expected terminal success**, ties choose upper. The memory-bearing models must not contain source-native reward/target law as a hardcoded rule. Frozen logistic model can fail; preserve negatives.
