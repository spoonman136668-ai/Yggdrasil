## Frozen candidate / equally fitted controls

All arm FIT inputs come from the same 256x30 experience tuples/replica and models initialize from zero or stated Laplace priors. Public state `S∈{0,1}`, legal action `X∈{0,1}`, observed reward `Y∈{0,1}`, next state `S'∈{0,1}`. Inference uses only currently public S, not source equation, privileged U or source state internals.

1. **Logistic state-and-action reward learner (candidate REFERENCE, not native Wingless/Yggdrasil).** Predict `P(Y=1|S,X)` with weights for [1,S,X,S·X]; 5 passes through same FIT transitions in chronological order, initial zeros, eta=0.08, L2=0.003; choose argmax fitted expected reward (tie to action 0). Measure updates and serialized parameters.
2. **Contextual trained tabular reward predictor** (strong conventional control): four `(S,X)` cells, Laplace +1 positive/+1 negative prior, fitted to all FIT pairs, choose max estimated one-step reward.
3. **Contextual trained tabular Q** (strong learned control): two-state/two-action Q, zero-init; chronological FIT transitions repeated 5 passes, learning rate 0.08 and gamma 0.95, TD bootstrap `Y+gamma max Q(S')` except final 30th action where target Y. Choose argmax Q. This model may produce poor or comparable decisions; preserve failure.
4. **Context-blind fully trained action-value model**: ignore S and fit P(Y|X) to same FIT (Laplace +1/+1), choose a constant action over entire episode based on fitted FIT observations. This is the properly trained *blind* comparator, not a disadvantaged always-zero reference.
5. **Context-masked logistic ablation:** copy the frozen FIT-trained logistic weights and force public S=0 only at inference, **without retraining**. Observes same legitimate callback but ablates use of current-state content. This is an input/usefulness ablation, **not persistent-memory ablation**.
6. **Fixed action-zero negative control**: zero FIT updates, context-blind, for continuity with source laws.

Model score controls are **not oracles**, and none may import CS01 evaluator-only source equations. FIT "training" must change model parameters (except fixed), and report actual FIT public state/action visitation support and counts. Compare the candidate to best trained contextual tabular / Q, trained blind and masked input on every replica. Report all sign and magnitude differences, no threshold selective winner.
