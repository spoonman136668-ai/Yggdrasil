## Frozen seven models and shared public FIT information

All seven models have the same public access to the **two old source-map FIT histories and the new target-map first n public FIT episodes**; models may intentionally ignore old histories. Baselines target-only are strong precisely because independent constructor maps imply old coordinates carry little predictive information; *ignored accessible information is not withheld*. 1. **`source_warm_prior` (tested transfer candidate):** source-map public covariance matrices `C_sourceA,C_sourceB` each accumulated across 24 original source FIT episodes. 2. **`target_online`:** online additive local 5×20 association from only first n original target FIT episodes, initialized zeros, one update per target FIT record. Same rule as CS10, no old-map bias.
3. **`target_batch`:** conventionally computed batch covariance on exactly the same target FIT n episodes (expected to tie target_online exactly).
4. **`target_raw_episodic`:** full raw retention of n public target FIT five-index CHECK vectors + 20 public original rewards, recomputes conventional batch covariance at decision time (expected to tie).
5. **`source_map_zero_shot`:** copy the highest-scoring original sourceA 24-FIT map index association, **no target map FIT**; test directly on original fresh target maps; no claim of unfamiliar family first-use.
6. **`target_inventory_blind`:** fit anonymous target rock-position counts from first n original target FIT episodes, sample **all five** inferred anonymous positions every DEV episode without using current CHECK signs. 7. **`exit_only`:** no training, no checks, exit immediately at original native +10, with appropriately lower native action count.
