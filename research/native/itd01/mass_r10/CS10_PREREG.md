## Frozen learning arms and full conventional controls

All arms consume the **same exact publicly acquired FIT dataset** (except exit-only fixed strategy deliberately no FIT updates), and share the same held-out 15 source-native CHECK information when applicable. No source privileged index-coordinate map. At test, index i is called **candidate good** iff at least 2 of 3 original public CHECK signs for i are positive. A predicted location may only be sampled **once**; if different indices map to the same coordinate, deduplicate deterministically by lowest index before acting and record it.

1. `online_local_association` — simple locally accumulated native-like (but **not Wingless/Yggdrasil native**) associative 5×20 state, initially all 0. For each of 96 chronological FIT episodes and each index i/cell p, increment weight `W[i,p] += public_check_sign_i * (source_sample_reward_at_cell / 10)`. This is a simple Hebbian-style correlation **fit**, with 96 state updates, persistent cross-episode learned structure. Map index i to legal coordinate with maximum W[i,p]; ties row-major. This 5×20 representation is **hand-designed**, not a new architecture.
2. `conventional_batch_covariance` — strong equally informed conventional trained baseline: compute `Σ_episode CHECKsign_i * SAMPLEreward_at_position /10` from identical immutable FIT tuples using explicit batch array operations; assign i to coordinate maximizing accumulated covariance (ties row-major). This is mathematically equivalent to the local associative method; it should **tie exactly** (fail closed if not) under identical histories and thus forms a **proof of no algorithmic advantage** in this bounded mechanism.
3. `trained_raw_episodic_correlation` — strong conventional FIT-trained episodic model retains **all 96** full public FIT check vectors and 20 cell rewards; at inference compute the same association weights from stored FIT records, not from a precomputed 5×20 state. It must also infer the identical map; report much larger retained memory in bytes, compute costs, performance. Cannot claim episodic baseline inferior by giving less training data.
4. `association_erased` — copy learned full 5×20 mapping, rotate predicted rock index by one before mapping to a location (at original test only), unchanged learned weights; this probes whether correct index-to-location association matters while retaining the same list of locations. Input three-sensor sign reports retained. This is an **inference association permutation ablation**, not neural state memory erasure.
5. `trained_inventory_blind_goodness` — use FIT to learn anonymous five legal rock locations as the coordinates with most nonzero original sample rewards, but **ignore current CHECK signs** and SAMPLE all five known coordinates every held-out episode, before exit. Same FIT/real source rewards; reveals whether current within-episode rock morality information adds value beyond cross-episode map inventory. It may have more SAMPLE actions; report.
6. `exit_only` — no FIT training, no current CHECK/SAMPLE; move directly via public original position into terminal east column4 for exactly original +10. Retain accurate fewer actions, not equal-check control.

All non-exit arms original-source report **exactly 15 CHECK calls per VALID/DEV episode**, and all policy input state is public original source-returned observations, held-out source-native immediate reward and FIT-earned model state; no optional privileged wrapper.
