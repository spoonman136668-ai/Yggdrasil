**Research hypothesis:** A compact action-specific learned causal feature state, trained from completed action→reward observations, can select better interventions under unfamiliar hidden relationships than strong equally informed source-fitted ordinary learners at equal or lower resource cost. This is deliberately unlike the failed fixed identity/hash carryover and rank-local relevance mechanisms; it tests whether any *learnable* action-linked predictive representation exists at all before native integration. It does **not** assume prior successful zero-shot transfer.

## Before-source protocol

- New stand-alone source-free original internal generator. Six independently observed binary variables, three legal action IDs. Rewards generated from hidden source-chosen sparse causal rules only after the action is taken; no source-rule parameters or hidden counterfactual rewards reach any learning arm. Source generator must not import, introspect or adapt to learner.
- Two different author-defined family grammars: **P** pairwise conditional XOR causal effects; **N** nonlinear gated/interacting triple causal effects. Three disjoint fixed DEV tasks per family (replicas 0,1,2); no previous consumed IDs, no protected H1/H2. Task-family names are audit metadata only, never learner input. This is within-generator unfamiliar *development* variation, not independent external-family transfer.
- Per task exactly **96 original public FIT interactions** using a preregistered uniform-action explorer, with real chosen-action source reward. All learned arms receive the identical chronological observation/action/completed-reward FIT rows. Separate exactly **128 DEV decisions per arm**, from fresh public input draws. Learners' action decisions precede source reward and hidden alternatives are never observed. All arms get identical public DEV inputs. No DEV data may change a learner or control.
- Frozen arms: `sparse_pair_credit` (candidate: fit the best observed two-variable causal reward table per action; only source outcomes update the model), `pairwise_ridge` (fitted conventional linear ridge main/pair feature learner per action), `episodic_hamming` (source-fitted nearest-neighbor episodic memory), `action_prior` (fitted action-only Laplace reward estimate), `random_policy` (preselected deterministic source-blind comparator), `pair_credit_ablated` (same candidate fit with action labels deterministically permuted, destroying correct intervention credit).
- Real original experiment code is written **after** this protocol commit. Canonical public role seed formula: `B=202610230000; task_seed=B+10000*family_index+1000*replica`. FIT input seed = task_seed+11, FIT action seed +17, DEV input seed +29; no model may use any seed to infer source rule. Only one DEV evaluation. No FIT/DEV cross-over or post-hoc source selection.
- Report each original source-selected DEV reward and aggregate reward, true chosen source actions, fit updates, candidate/ablation action disagreements, source reward identity, fitted parameters, training and DEV CPU, wall and peak RSS, persistent model bytes (where measured); flag model-isolated resource measurements as unavailable if not obtained. Energy unavailable unless directly metered. Fail on nonfinite data, missing samples, unexpected source work, hard malformed input or role leakage.
- Advancement for this **development screening only** requires on **both families** >=0.03 absolute mean reward improvement against **every** equally fitted conventional control, >=0.05 mean candidate versus action-label-ablation improvement, no replica losing >0.05 to strongest control, no resource regression on demonstrably comparable measurements, and same protocol repeated independently later.
