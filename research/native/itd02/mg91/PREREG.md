# ITD-02 MG91 — task-reward-grounded public demonstration learning

**Prospective DEV preregistration frozen BEFORE the MG91 learner is written or any MG91 original-world action.**

## Rationale and scientific boundary
MG87–MG90 learned real original-selected observation/shift/landmark graph evidence but each earned **zero original positive task rewards** in source-pinned MiniGrid. Consequently their delayed task-value backups had no signal. The separately frozen hand-engineered conventional planner MG86 earned positive original task reward on 2/3–3/3 original heldout episodes under the same public interface. MG91 deliberately tests a **different learning regime: source-public demonstration/behavior cloning with *real successful reward-to-go***, not unsupported intrinsic novelty. The native learner is trained on independently executed, actual original-successful MG86 **source-public** trajectories. The planner is a human-coded demonstrator; this is **not self-discovered native action semantics, causal discovery or autonomous native learning**. Distinguish teacher-assisted learning from own-action online learning in evidence and in FORGE.
