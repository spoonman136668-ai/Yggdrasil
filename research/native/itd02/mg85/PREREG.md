# MG85 — Public-only spatial positive-control calibration (prospective DEV)

**Registered before MG85 code or original-world action.** MG84 source-public task observations found key/door interactions but no goal visibility, reward, or success after 5,184 actions over 27 episodes. This is **not evidence that native agents cannot learn**; it motivates an independent, deliberately stronger **conventional, hand-engineered model-based baseline** to establish whether a source-public map and goal-directed actions can solve the same original tasks at the current action budget. Do not represent a positive control as native learning.

## Evaluation and disposition
- Primary: original positive terminal reward/task completion, per-role/family/seed; secondaries: post-action goal visibility, visible key and door events, distinct observations, source-selected action histogram, task-relevant events, cell visits, wall seconds, process RSS, source/ledger hashes and cold-restore integrity.
- Engineering acceptance requires exact source/atlas, Linux+Windows native source-only tests, original Farama source qualification and original-world ledgers. Hardcoded map baseline must not rely on privates. Keep original hidden state inaccessible.
- **Scientific verdict:** Positive-control task successes (if any) show only that an explicitly programmed planner can complete the original environment using available public information and known dynamics. They do **not** show Yggdrasil learning, causal discovery, generalization or fairness against conventional controls. Negative control remains evidence of a difficult task and/or flawed baseline design; no approval of native learning either way. For future native candidate acceptance require *equally informed*, trained model-based/Bayesian controls and independently replicated unfamiliar-family transfer. No gate may promote solely from frontier counts or visible keys.
