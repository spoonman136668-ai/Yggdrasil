# CKAD stage development executor — source-owner isolated prototype

**Scope:** An actual one-stage call into NativeCumulativeLearner.observe(),
against *previously consumed synthetic public causal rows only*. This is NOT
original-source scientific first-use, FORGE dispatch authority, production
training, a new autonomous controller, or promotion.

The implementation is in yggdrasil/native_ckad_dev_stage.py. It accepts a
source/tree-pinned typed work order, an exact native checkpoint and a canonical
public consequence packet. It rejects mismatched source, kind, corpus, budget,
first-use, paid API, FORGE dispatch or promotion flags. It executes one native
learning update without resetting old properties/events/unrelated slots, then
cold-restores output bytes in a new Python process. Results include input/output
checkpoint SHA256, packet SHA256, observation count and measured wall time,
plus explicit false flags for scientific validation and external authority.

The qualified tests continue **two successive genuine updates on one model**,
preserve stored properties, cold-restore state and reject replay, contaminated
packets, altered source, unauthorized authority and contradictory evidence
(quarantined by the existing native learner). No held-out science is consumed.

This API is deliberately not an auto-dispatch surface. The FORGE PR #1808
campaign manifest currently pins an earlier CKAD13 candidate, not this code;
its inert next-stage proposals do not authorize execution. A future
Yggdrasil/CKAD scientific-owner permit and source/checkpoint custody adapter
must bind exact current code, persisted original witness and independent
evaluation before F139 can execute continuous training.

The branch is isolated from the CKAD13–23 owner branch and targets that
research branch for review. This stage is a development-only engineering
qualification, not a new experiment proving reasoning, retention, transfer
or autonomous cognition.
