# Yggdrasil — strictly token-free cognitive North Star

**Architecture-specific scope:** This is a written clarification of the Yggdrasil research destination, not a change to DG-1 source or scientific first-use. The authoritative research statement is [`research/architecture/yggdrasil-north-star.ice`](../research/architecture/yggdrasil-north-star.ice).

The native developmental genome/phenotype/cellular substrate must learn, reason, remember, repair, regenerate and communicate **without using language tokens at any cognitive stage**. No tokenizer/vocabulary, token IDs, BPE/subword units, autoregressive next-token target, token-dependent memory indexing, token-step world model or token-generating decoder may be inside the target. Do not disguise a conventional token model behind an adapter or cellular wrapper.

Native continuous/dynamical/event-causal representations, local developmental transitions, learned relational composition, persistent state, resource-bounded growth, selective regeneration and cold recovery remain Yggdrasil's own direction. Raw language can be a perception/communication modality, not a mandate to model tokenizer outputs. Binary software interchange is not the representation on which the system reasons.

External token-based models may be used as explicitly separate, fully trained comparator arms and bounded research tools. They cannot provide the target's native learning, reasoning, memory or generation path. Wingless (independent non-transformer) and Hybrid (independent SSM/attention/TTT operators over non-tokenized learned states) share only a long-term intelligence target and the no-token constraint, not architecture, controller or first-use authority.

**Required scientific outcomes:** progressive native language competence; genuine action-consequence learning and intervention value; compositional and unfamiliar-world transfer; cumulative memory with cold recovery; resistance to interference; resource-bounded structural plasticity and functional regeneration. Freeze baseline training and matched information, actions, compute, seeds/splits, thresholds, ablations, negatives, whole-process cost, stop rules and provenance before new science.

**Existing state:** This documentation does **not** show Yggdrasil already reaches those goals. It does not alter historical science claims, frozen protocols, independent FORGE/Hybrid/Wingless research, runner configurations, accepted refs or deployments. Updating generated ICE indices or accepting this charter requires project-owned qualification.
